# GEO-Industry-Engine

**AI时代企业增长基础设施 | GEO产业导航与交易平台**

GEO产业引擎是一个集企业增长基础设施与GEO（Generative Engine Optimization）产业导航与交易于一体的综合平台。它不仅是AI时代的增长工具，更是企业应对AI搜索时代的战略基础设施。

## 定位

> Semrush（数据分析） + Gartner（行业地图） + Salesforce（客户增长） + Marketplace（交易市场） + AI Agent OS（智能团队）

## 四大核心系统

| 系统 | 描述 |
|------|------|
| **AI可见度增长系统** | 企业AI检测、GEO评分、AI曝光分析、内容优化、增长建议、持续监测 |
| **GEO产业导航系统** | 产业价值链地图、商业赚钱地图、运营流程地图（MECE法则） |
| **GEO交易市场** | 企业需求发布、服务商匹配、项目管理、评价佣金体系 |
| **GEO数据资产中心** | 行业数据库、企业数据库、GEO指数、AI回答数据库、知识图谱 |

## 技术栈

| 层 | 技术选型 |
|----|---------|
| 前端 | Next.js |
| 后端 | FastAPI |
| 关系数据库 | PostgreSQL |
| 知识图谱 | Neo4j |
| 向量数据库 | Milvus / Chroma |
| 搜索引擎 | ElasticSearch |
| Agent框架 | LangGraph / AutoGen / CrewAI |
| 工作流参考 | Dify |

## 开发原则

1. 先设计文档，再写代码
2. 所有模块必须服务商业闭环
3. 所有数据必须可沉淀
4. 所有功能必须考虑未来Agent调用
5. 所有架构必须支持扩展
6. 禁止为了快速完成而破坏长期架构
