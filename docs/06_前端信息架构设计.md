## 二、页面-组件-数据源 完整矩阵

### 2.1 首页

| 层级 | 组件 | 数据来源 |
|------|------|---------|
| **页面** | 首页 `/` | — |
| ├ 区块 | 飞轮视觉（数据→认知→信任→连接→交易→数据） | 静态 SVG + 飞轮各环节计数（analytics API） |
| ├ 区块 | 快速检测入口（搜索框 + 开始评估按钮） | 输入企业名 → `POST /detection/quick` → Decision Engine → 简版GEO身份卡 |
| ├ 区块 | 角色分流区（7个角色卡片） | 前端路由跳转 |
| └ 区块 | 五大系统二级导航（5个系统入口卡片） | 每卡片含统计数字：`GET /industries/count`、`GET /certification/count` 等 |

### 2.2 检测中心

```
检测首页 /detection
├── 搜索区块
│   ├── SearchBox（企业/行业/地区搜索）
│   └── QuickAssessButton（一键评估）
├── 热门评估区块
│   └── TrendingList（最近被评估的企业）
└── 我的评估历史（需登录）
    └── HistoryList

评估报告 /detection/result
├── 身份与位置（第一层）
│   ├── IdentityCard（GEO数字身份卡）       ← GET /context/company/{id}
│   ├── ScoreGauge（GEO得分仪表盘）         ← GET /decision/geo-score/{id}
│   ├── TrustBadge（可信等级标识）           ← GET /decision/trust-score/{id}
│   └── IndustryRank（行业排名）             ← GET /decision/rank/{id}
├── 机会发现（第二层）
│   ├── OpportunityList（机会列表）          ← GET /decision/opportunity/{id}
│   ├── KeywordGap（关键词空白分析）         ← GET /intelligence/opportunity/{id}
│   └── TrendChart（行业增长趋势）           ← GET /industries/{id}/trends
├── 风险预警（第三层）
│   ├── RiskAlertList（风险列表）           ← GET /decision/risk/{id}
│   ├── CompetitorMove（竞品动态）          ← GET /intelligence/competitor/{id}
│   └── DegradationWarning（退化预警）      ← GET /decision/degradation/{id}
└── 行动路线（第四层）
    ├── RoadmapTimeline（战略路线图）        ← GET /decision/roadmap/{id}
    ├── ActionList（建议行动项）             ← GET /decision/action/{id}
    └── AgentReport（Agent分析报告）         ← POST /agent/analyze

企业深度分析 /detection/company/{id}
├── 企业画像（完整版）
│   ├── ProfileHeader                     ← GET /context/company/{id}/full
│   ├── CapabilityMatrix（能力矩阵）        ← GET /entities/{id}/capabilities
│   ├── RelationshipGraph（关系图谱）       ← GET /entities/{id}/relationships
│   └── EventTimeline（事件时间线）         ← GET /entities/{id}/events
└── 证据与数据
    ├── EvidenceList（证据列表）            ← GET /evidence/{entity_id}
    └── DataQualityScore（数据质量评分）    ← GET /entities/{id}/quality

竞争对比 /detection/compare
├── CompanySelector（A/B企业选择器）
├── CompareTable（多维度对比表）            ← GET /decision/compare
├── RadarChart（雷达图）
└── GapAnalysis（差距分析）                 ← GET /intelligence/gap
```

## 四、共享组件目录

以下组件跨页面复用，统一样式和行为：

| 组件名 | 用途 | 使用页面 |
|--------|------|---------|
| `IdentityCard` | GEO数字身份卡（简版/完整版） | 首页、检测中心、认证中心、交易市场 |
| `ScoreGauge` | 得分仪表盘 | 检测中心、数据资产 |
| `TrustBadge` | 可信等级标识 L0-L4 | 检测中心、认证中心、交易市场 |
| `CapabilityTags` | 能力标签组 | 企业深度分析、认证通行证、服务商详情 |
| `EvidenceGallery` | 证据展示画廊 | 认证通行证、企业深度分析 |
| `EventTimeline` | 事件时间轴 | 企业深度分析、认证通行证 |
| `IndustrySearch` | 产业搜索框（自动补全） | 首页、检测中心、产业导航 |
| `GapList` | 缺口/建议列表（按影响力排序） | 评估报告、数据完整度、数据补充 |
| `CompletenessRadar` | 五维度雷达图 | 数据完整度 |
| `TrendChart` | 趋势线图 | 评估报告、资产首页 |
