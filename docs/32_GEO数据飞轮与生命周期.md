## 一、战略飞轮详细机制

### 1.1 飞轮各环节

```
数据进入 (Entity创建/导入/爬取)
    |
知识形成 (Entity+Capability+Relationship+Event+Evidence整合)
    |
产业认知 (Context Engine理解状态+位置+关系)
    |
智能决策 (Decision Engine评分+预测+推荐)
    |
用户获得认知 (知道自己在哪里+有什么机会+有什么风险)
    |
建立数字身份 (GEO Identity = 七个维度的统一表达)
    |
认证建立信任 (L0->L1->L2->L3->L4, 可信度逐级提升)
    |
发现位置与机会 (产业导航: 五张地图)
    |
数据资产沉淀 (我的数据: 完整度+缺口+历史)
    |
生态连接产生 (交易市场: 需求匹配+服务连接)
    |
用户行为与新事件 (使用过程产生新数据)
    |
数据持续增长 -> 回到第一环
```

### 1.2 飞轮加速因素

| 因素 | 效果 |
|------|------|
| 更多企业注册 | 知识图谱更完善 |
| 更多认证 | 信任网络更强 |
| 更多交易 | 匹配推荐更准 |
| 更多Agent调用 | 系统更智能 |

### 1.3 飞轮减速风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 数据质量差 | 评分失真 | 数据质量体系 |
| 认证不严 | 信任贬值 | 严格审核流程 |
| 用户流失 | 数据停滞 | 周期性价值触达 |
| 竞品抄袭 | 差异化缩小 | 持续创新+生态锁定 |

## 二、数据生命周期

### 2.1 数据在各阶段的状态

| 阶段 | 状态 | 系统行为 |
|------|------|---------|
| 创建 | 新数据进入 | 分配geo_id + 初始评分 |
| 验证 | 等待验证 | AI自动审核 + 数据质量五维检查 |
| 活跃 | 正常使用中 | 参与排名/推荐/匹配 |
| 更新 | 有新事件 | 增量重算评分 |
| 老化 | 超过阈值未更新 | 标记stale + 降权 |
| 归档 | 确认无效/过期 | 移入冷存储 |
| 删除 | 用户请求删除 | 30天冷静期后彻底删除 |

### 2.2 Identity Snapshot (身份快照)

每次Decision Engine评估时自动生成快照:
- 记录当时Entity状态/Capability/Relationship/Trust Score/GEO Score/产业位置
- 快照序列是趋势预测和数据资产的基础
- 保留周期: 24个月
