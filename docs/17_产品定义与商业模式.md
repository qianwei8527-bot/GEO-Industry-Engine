# GEO-Industry-Engine 产品定义与商业模式

> 状态：架构设计 | 版本：v2.0 | 日期：2026-07-28
> 关联：01_产品架构PRD.md、CTO长期开发协议.md §商业化

---

## 一、产品定义

### 1.1 一句话定义

GEO-Industry-Engine 是面向GEO产业生态的产业认知、身份、信任、知识、智能决策与生态连接基础设施。

### 1.2 产品形态

| 形态 | 用户 | 价值 |
|------|------|------|
| Web应用 | 企业/个人/服务商 | GEO评估+认证+导航+交易 |
| API服务 | 开发者/集成商 | 产业数据+GEO评分+Agent |
| MCP服务 | AI Agent开发者 | Agent间互通协议 |
| 管理后台 | 平台运营 | 认证审核+配置+审计 |

### 1.3 不是

- 不是单纯GEO评分工具 (而是包含评分在内的产业生态)
- 不是SaaS订阅产品 (订阅只是变现方式之一)
- 不是企业黄页 (而是产业数字孪生)
- 不是招聘平台 (但包含人才流动分析)

## 二、商业模式

### 2.1 变现层次 (按优先级)

```
优先级从高到低:
1. 产业知识资产 -> 用户价值
2. 生态连接 -> 网络效应
3. 商业化 -> 变现
```

### 2.2 收入来源

| 来源 | 描述 | 阶段 |
|------|------|:--:|
| 认证服务费 | L1免费/L2-L4按等级收费 | 初期 |
| 订阅费 | Free/Growth/Pro/Business/Enterprise | 初期 |
| API调用费 | 按量计费 (开发者) | 中期 |
| 交易佣金 | 服务交易5-15%抽佣 | 中期 |
| 数据报告 | 行业白皮书/定制分析 | 中期 |
| Agent市场 | 平台抽佣15-30% | 后期 |
| 标准认证授权 | GEO标准授权给第三方 | 后期 |

### 2.3 定价策略

| 套餐 | 价格(参考) | 核心权益 |
|------|:--------:|---------|
| Free | 0 | 基础评估(3次/月) + 公开数据 |
| Growth | ~99/月 | 完整评估 + 基础认证 + 数据补充 |
| Pro | ~299/月 | AI深度分析 + L2认证 + 交易市场 |
| Business | ~999/月 | 团队协作 + API(5万次) + L3认证 |
| Enterprise | 定制 | API(不限) + L4认证 + 专属部署 |

所有定价配置: config/pricing/plans.yaml (可随时调整)

### 2.4 免费增值 (Freemium)

- 永远免费: 公开评估/产业导航/行业指数
- 免费额度: 3次完整评估/月
- 转化点: 评估后推荐认证 -> 认证需Growth+套餐
- 网络效应: 免费用户贡献数据 -> 数据越多产品越好
