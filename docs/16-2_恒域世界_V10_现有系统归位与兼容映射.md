# 恒域世界 V10 现有系统归位与兼容映射

> 版本：V10-P0 | 状态：已实施 | 更新：2026-08-03

## 一、结论

V10 的“域（Realm）”不是对旧 Node/Entity 的破坏性重命名，而是产品与架构层的正式名称。旧表继续承担事实与权限存储，新层只补齐域生命周期、数据授权、GEO 项目和工具执行的可审计结构。

## 三、兼容规则

1. `Entity/Node/node_id/entity_id` 继续作为 Realm 的代码兼容层，禁止大规模重命名。
2. 数据库新表全部通用，不包含教育、医疗等行业专属字段。
3. `realm_type` 只表示域类型，不改变 Universal Fact 的 `truth_status`。
4. 已发布的 World Version、World State Snapshot、Transition 继续不可变。
5. 新写操作全部经过 `NodeMembership` 权限检查和 `AuditLog` 审计。

## 四、暂缓能力

- 完整 `controller_grants / consents` 治理协议：本轮只落最小授权边界。
- 金融、游戏化、社区、交易市场、支付：仅保留架构入口。
- C8.3 世界状态变化引擎：不在 V10-P0 范围。
- 大规模行业爬取与 AI 自动补全：继续禁止。
