## 二、五张地图交互规范

### 2.1 产业生态地图 (eco-map)

可视化: 力导向图/桑基图

节点类型: 企业(圆形)/能力(方形)/行业(菱形)
连线: 合作关系(蓝色实线)/竞争关系(红色虚线)/投资关系(绿色)

交互:
- 鼠标悬停节点: 弹出身份卡浮窗
- 点击节点: 浮窗固定 + 高亮关联节点
- 双击节点: 跳转企业详情页
- 缩放: 滚轮 (含语义缩放: 放大显示子节点)
- 时间轴拖动: 查看不同时间点的产业关系

### 2.2 商业赚钱地图 (business-map)

可视化: 四栏矩阵 (Sankey/瀑布图)

四栏: 流量来源 -> 转化路径 -> 收入模式 -> 利润结构
每条流: 代表一种商业模式路径

交互:
- 点击栏位: 展开该环节的详细企业列表
- 点击流线: 高亮整条路径 + 展示相关企业
- 右侧面板: 选中路径的详细分析

### 2.3 运营流程地图 (ops-map)

可视化: 泳道图/8阶段流程

8阶段: 需求发现->方案设计->服务交付->效果评估->优化迭代->认证升级->生态参与->价值放大

交互:
- 每个阶段显示该阶段的企业/服务商数量
- 点击阶段: 展开该阶段的能力需求 + 服务商
- 用户高亮: 当前用户在流程中的位置

### 2.4 地域生态地图 (region-map)

可视化: 中国地图热力图

数据维度: 省份/城市 x 企业密度 / GEO指数 / 能力分布

交互:
- 地图点击省份: 放大 + 显示该区域企业列表
- 指标切换: 企业密度/认证率/GEO平均分/行业分布
- 对比模式: 选择2-3个区域并排对比

### 2.5 发展预测地图 (forecast-map)

可视化: 三线趋势图 (乐观/基准/悲观)

三条线: 产业规模/企业数量/技术成熟度

交互:
- 点击趋势线: 展开该时间节点的详细预测
- 调整参数: 投资增长率/政策力度/技术突破概率
- 情景对比: 不同假设下的产业走向

## 三、通用交互规范

- 所有地图可导出 (PNG/SVG/PDF)
- 搜索框在所有地图左上角
- 图例在右下角
- 数据最后更新时间在左下角
- 五张地图之间可通过顶部Tab切换
- 支持URL参数: ?highlight=entity_id (高亮指定实体)
