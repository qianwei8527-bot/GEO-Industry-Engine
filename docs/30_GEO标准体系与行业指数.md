# GEO-Industry-Engine 标准体系与行业指数

> 状态：架构设计 | 版本：v2.0 | 日期：2026-07-28
> 关联：config/scoring/industry_index.yaml、CTO长期开发协议.md

---

## 一、GEO标准体系

### 1.1 标准层次

```
GEO通用标准 (跨行业)
  +-- 行业专用标准 (AI/教育/医疗/制造...)
      +-- 区域标准 (中国/海外)
          +-- 企业自定义标准
```

### 1.2 核心标准维度

| 标准维度 | 定义 | 更新周期 |
|---------|------|:------:|
| 可见度标准 | AI搜索引擎中的曝光衡量方法 | 半年 |
| 可信度标准 | 认证等级与证据质量规范 | 半年 |
| 数据质量标准 | 数据完整度/准确度/时效性 | 季度 |
| 评估方法标准 | GEO Score计算方法论 | 年度 |
| 认证流程标准 | 认证申请/审核/发放规范 | 季度 |

### 1.3 标准制定流程

提案(RFC) -> 社区讨论(30天) -> 标准委员会投票 -> 试行(3个月) -> 正式发布(含迁移期)

## 二、GEO行业指数

### 2.1 指数体系

| 指数 | 含义 | 更新频率 |
|------|------|:------:|
| GEO产业综合指数 | 行业整体GEO发展水平 | 月度 |
| GEO可见度指数 | 行业AI可见度均值 | 月度 |
| GEO成熟度指数 | 行业认证率/能力完整度 | 季度 |
| GEO增长指数 | 行业增长率(企业/投资) | 月度 |
| GEO人才指数 | 行业人才密度/流动 | 季度 |

### 2.2 指数计算方法

```
产业综合指数 = 
  company_density(0.30) + capability_depth(0.25) + 
  event_frequency(0.20) + growth_rate(0.25)

具体权重配置: config/scoring/industry_index.yaml
```

### 2.3 指数发布

- 门户: 产业导航首页展示
- 报告: 季度产业白皮书
- API: 行业指数数据接口
- 对比: 历史趋势 + 跨行业对比

## 三、行业基准 (Benchmark)

### 3.1 基准类型

| 基准 | 用途 | 数据来源 |
|------|------|---------|
| 行业平均 | 个体vs行业比较 | 全行业Entity聚合 |
| 行业Top10 | 领先者对标 | 行业排名前10% |
| 行业Top100 | 优秀者对标 | 行业排名前100 |
| 区域基准 | 地域比较 | 区域聚合 |

### 3.2 基准应用场景

- 检测中心: "你的GEO Score 58, 行业平均 55, Top10 82"
- 竞争对比: 企业与行业Top10的多维对比
- 产业导航: 地图上的行业分区着色 (按GEO等级)
- 投资分析: 目标企业与行业基准差异

GEO标准 v1.0 (2026)
