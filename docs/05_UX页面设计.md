# GEO产业引擎 — UX页面设计需求

## 设计理念

不是后台工具，而是 **AI时代企业增长入口与产业学习平台**。

设计语言：清晰、可信、智能、前瞻、社交

## 一、首页

| 要素 | 描述 |
|------|------|
| **Hero区** | GEO引擎核心主张 + 实时GEO综合指数看板 |
| **核心入口** | AI增长中心 / 产业导航 / 交易市场 / 数据中心 / 生态中心 |
| **快速检测** | 嵌入"免费检测GEO评分"（支持企业+个人） |
| **实时动态** | 产业动态信息流、GEO行业新闻、热门讨论 |
| **地图预览** | 产业生态地图的交互缩略图 |
| **认证入口** | 企业认证 / 个人认证 快速申请入口 |

## 二、AI增长中心

- **Dashboard**：GEO评分趋势图、AI提及热力图、行业排名、**三线预测图**（历史/实际/预测）
- **企业检测**：输入域名 → 自动扫描 → 输出GEO评分报告
- **个人检测**：输入姓名/职业 → AI个人品牌可见度分析
- **AI曝光分析**：按AI平台展示品牌/个人提及、情感分析
- **内容优化**：输入关键词 → AI推荐GEO内容策略 → 生成优化方案
- **监测设置**：监测对象、频率、告警阈值

## 三、GEO产业导航（全新设计）

### 产业生态地图
- 9层价值链的**交互式可视化**（力导向图/径向树图）
- 点击层级展开细分子行业，展示企业/个人/服务商分布
- 每个节点支持：查看详情 / 连接跳转 / 评论 / 收藏
- 搜索定位：输入企业名/人名/关键词，高亮其在生态中的位置

### 商业赚钱地图
- 四栏交互矩阵：买单方 × 产品需求 × 服务供给 × 收入模型
- 点击任一单元展开详细数据、案例、服务商推荐
- 交叉筛选：比如"创业者想买数据产品"筛选出相关供给
- 商业机会热力图：颜色深浅标识机会大小

### 运营流程地图
- 八阶段交互流程图（从左到右布局）
- 每阶段点击展开：工具推荐、案例展示、服务商列表
- 支持按角色过滤（企业视角/服务商视角/个人视角）

### 地域GEO产业生态地图（新增）
- 中国地图+世界地图交互式展示
- 点击地域展开本地GEO产业生态数据
- 地域间连线展示跨地域协作关系
- 排行榜：各区域GEO发展排名
- 时间轴：区域GEO发展变化趋势
- "我要加入"入口：本地企业/个人申请入地图

### 发展方向研究地图
- 技术/市场/生态三个维度的趋势可视板
- 每个趋势点展示：描述、相关企业、研究论文、讨论区
- 社区投票：用户可对趋势方向投票和讨论

## 四、交易市场

- 分类导航：服务 / 工具 / 数据 / 知识 / 人才
- 搜索与筛选：关键词、分类、价格、评分、认证等级
- 推荐模块：AI推荐 + 热榜 + 最新上架（三者并排）
- 发布需求：表单（描述、预算、行业、类型）
- 服务商/产品列表：卡片式展示，支持排序筛选
- 详情页：认证标识、案例展示、评价区、咨询入口
- 项目管理：在线看板、里程碑、文件共享

## 五、数据中心

- 数据概览：GEO总指数、行业分布、数据来源统计
- 行业数据库：多维度筛选、数据表格、对比分析
- 企业数据库：GEO排行榜、搜索/筛选、对比收藏
- 个人数据库：个人AI可见度排行
- AI回答数据库：按平台/行业/时间查询
- 知识图谱：交互式图谱浏览器
- 研究资料库：AI研究报告存档、全文检索、导出PDF
- 地域数据：各地域GEO产业数据看板

## 六、生态中心

- 生态概览：GEO服务商生态、认证体系、合作图谱
- 认证中心：企业认证 / 个人认证 / 产品认证 申请入口
- 认证进度查询：已申请认证的状态追踪
- 认证企业/个人展示：按认证等级排序的展示墙
- 合作伙伴：数据、技术、渠道合作伙伴
- 社区：讨论区、问答、最佳实践分享、活动日历
- 培训中心：GEO课程、认证培训、专家讲座

## 七、后台管理

- 用户管理、企业审核、认证管理、内容管理
- 交易管理、地域数据管理、系统设置
- 平台数据看板、趋势分析、用户行为分析
