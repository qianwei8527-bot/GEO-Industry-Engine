## 三、跨系统关键连接链

```
用户最常走的跨系统链路：

检测 → 认证:
  评估报告 → [申请认证] → 认证申请页(预填entity_id+推荐等级)

检测 → 资产:
  评估报告 → [补充数据] → 数据补充页(预填entity_id+缺口列表)

检测 → 交易:
  评估报告 → [找服务商] → 交易市场(预筛选匹配的服务商类型)

检测 → 导航:
  企业详情 → [产业位置] → 产业生态地图(高亮该企业节点)
  竞争对比 → 点击竞品 → 竞品企业详情

认证 → 检测:
  认证通行证 → [查看企业详情] → 企业深度分析

认证 → 交易:
  认证通行证(服务商) → [查看交易市场] → 该服务商的市场页面

导航 → 检测:
  地图上点击企业节点 → 浮窗 → [查看详情] → 企业深度分析

资产 → 认证:
  数据资产 → [申请认证] → 认证申请页

资产 → 检测:
  数据资产 → [查看企业详情] → 企业深度分析

交易 → 认证:
  服务商卡片 → 认证徽章 → 认证通行证

交易 → 检测:
  服务商详情 → GEO身份卡 → 企业深度分析
```

## 四、页面间传参约定

| 参数 | 传递方式 | 示例 |
|------|---------|------|
| entity_id | URL param | /detection/company/geo-company-042 |
| 来源页 | query param | ?from=detection |
| 预填充 | query param | ?entity=geo-company-042&level=L3 |
| 高亮/聚焦 | query param | ?highlight=geo-company-042 |
| 筛选条件 | query param | ?industry=ai-marketing&certification=L3 |
| 对比ID组 | query param | ?ids=id1,id2 |

URL 参数保证页面可分享、可书签、浏览器前进后退可用。
