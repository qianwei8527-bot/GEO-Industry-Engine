## 一、市场机会

### 1.1 问题与时机

**问题**: AI搜索正在取代传统搜索。企业面临新挑战——如何在ChatGPT、Gemini等AI中被正确引用和推荐？这不是SEO，是全新的GEO(Generative Engine Optimization)。

**时机**: 2026年AI搜索用户量快速增长，但GEO产业仍处于早期。先入者有机会建立产业标准和生态壁垒。

### 1.2 市场规模

| 维度 | 估算 |
|------|------|
| 目标企业数(中国) | 5000万+ (含中小企业) |
| GEO服务市场规模 | 百亿级 (参照SEO市场500亿+) |
| 认证市场规模 | 十亿级 |
| 产业数据市场 | 十亿级 |

### 1.3 增长驱动

- AI搜索用户渗透率持续上升 (目前~15%, 预计2027达50%)
- 企业对AI可见度的认知快速提升
- 从"有没有网站"到"AI看不看得到"的范式转移

## 二、竞争壁垒

### 2.1 护城河

| 壁垒 | 类型 | 可持续性 |
|------|------|:------:|
| 产业知识图谱 | 数据网络效应 | 强 (数据越多越准确) |
| 认证体系 | 信任网络 | 强 (迁移成本高) |
| 配置化引擎 | 技术壁垒 | 中 (可快速复制到新行业) |
| 决策反馈闭环 | 数据飞轮 | 强 (使用越多越智能) |
| MCP/开放协议 | 生态锁定 | 中 (标准制定者优势) |

### 2.2 竞品防御

- vs SEO工具: 维度不同(GEO vs SEO), 他们转型需重建技术栈
- vs 天眼查: 他们做信息聚合，我们做智能评估+认证+连接
- vs AI评分网站: 他们做一次性检测，我们做持续追踪+产业生态

## 三、商业模式

### 3.1 收入模型

SaaS订阅(60%) + 认证服务(20%) + API调用(10%) + 交易佣金(10%)

### 3.2 关键指标

| 指标 | 目标 (12个月) |
|------|:----------:|
| 认证企业数 | 1000+ |
| 认证个人数 | 5000+ |
| 月活企业用户 | 5000+ |
| MRR | 50万+ |
| 产业数据量 | 50万+ Entity |

### 3.3 增长飞轮

```
更多企业使用 -> 更多数据 -> 更准确的评估
    -> 更多认证 -> 更高的信任 -> 更多交易
    -> 更多数据 -> 循环
```
