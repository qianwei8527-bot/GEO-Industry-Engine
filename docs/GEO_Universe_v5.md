# GEO Universe v5.2 — 产业智能生态操作系统

> 替代: GEO_Universe_v5.1.md

## 零、战略定位

GEO Universe 是：**AI时代产业信用网络 + 动态产业世界模型 + GEO产业社交网络 + AI产业导航系统。**

类似：
- 微信朋友圈 → 人与人的社会关系网络
- 抖音推荐流 → 内容与兴趣关系网络
- LinkedIn → 职业与商业关系网络

而 GEO Universe：**产业与AI时代机会的智能关系网络。**

核心不是让用户使用一个工具，而是：
> 让每一个进入 GEO 产业的人，照见自己 → 找到位置 → 看清方向 → 获得路径 → 连接资源 → 拥抱未来。

## 一、三层认知入口（用户第一眼）

```
GEO Industry Universe
        |
   ┌────┼────┐
   |    |    |
当前世界    成长路径    未来世界
```

不是菜单导航，是认知入口。用户进入后第一句话不是"搜索企业"，而是"发现我的产业位置"。

## 二、六层架构 (GEO Universe OS)

```
Layer 0: Rules        — Universe Rules（所有层的底层规则）
Layer 1: Node         — 统一节点 (Company/Provider/Industry/Person/Product/Capability/Resource/Agent/AI)
Layer 2: Graph        — 关系网络 (合作/竞争/供应/投资/能力/学习/交易/社交)
Layer 3: Dynamic      — 动态事件 (融资/技术/人才/政策/市场/AI推荐变化)
Layer 4: Evolution    — 产业演化 (成长阶段 + 价值链 + 未来路径)
Layer 5: Intelligence — Agent OS + Intelligence Panel + Citation + Memory
```

## 三、GEO Intelligence Panel（产业智能面板）★ v5.2 核心新增

产业地图不是可视化图谱，而是**产业认知操作系统**。每个节点点击后打开统一的智能面板。

### 3.1 面板结构（固定7栏）

```
┌────────────────────────────────────┐
│ [节点名称]  [节点类型]               │
├────────────────────────────────────┤
│ ① 当前状态 → GEO评分/排名/阶段        │
│ ② 能力测评 → 重新检测/能力评估        │
│ ③ 发展方向 → 下一步建议/差距分析       │
│ ④ 学习成长 → 课程/路径/认证           │
│ ⑤ 资源连接 → 专家/服务商/工具         │
│ ⑥ 数据资产 → 画像/证据/竞争           │
│ ⑦ 商业机会 → 需求/合作/交易           │
└────────────────────────────────────┘
```

### 3.2 不同节点类型 → 不同面板侧重

**Company（企业节点）**:
企业画像 → GEO评分 → 竞争位置 → 成长路线 → 资源需求 → 商业连接

**Provider（服务商节点）**:
服务能力 → 覆盖行业 → 成功案例 → 认证等级 → 可解决问题 → 匹配需求 → 商业机会

**Person（个人节点，远期）**:
能力等级(L1-L4) → 技能缺口 → 学习路线 → 岗位机会 → 行业连接

**Technology（技术节点，远期）**:
技术介绍 → 应用场景 → 关联企业 → 学习资源 → 未来趋势 → 人才需求

**Industry（行业节点）**:
行业全景 → 企业分布 → 能力供给 → 需求趋势 → 成长阶段分布 → 未来演化

### 3.3 面板核心原则

- 同一套数据库底座，不同节点类型切换不同侧重
- 不是一个面板写死所有类型
- 推荐理由必须连接 Universe Rules（不是自由发挥）
- 商业机会展示 candidates（候选集），不是 winner
- 节点选中后，在所有 View 中高亮联动

## 四、五视图（Five Views）= 一个 Universe + 五种观察角度

```
Universe
├── Ecosystem View（生态视图）  — 我在哪？上下游关系？
├── Business View（商业视图）  — 如何创造价值？钱在哪？
├── Growth View（成长视图）   — 如何提升？学习路径？
├── Distribution View（分布视图）— 机会在哪？区域分布？
└── Future View（未来视图）   — 往哪去？产业演化？
```

核心原则：**不是五张独立地图，是一张 Universe 五种 Camera View。**
节点在任一 View 中被选中，所有 View 中联动高亮。

## 七、开放生态策略（外部AI联动）

### 7.1 核心策略

不闭门造车。利用GPT、豆包、Kimi等外部AI加速产业版图建设。

```
外部AI（GPT/豆包/Kimi）
         ↓
  数据采集 & 分析
         ↓
  GEO Observation Agent 整合
         ↓
  GeoEvent → Graph → Decision
         ↓
  产业地图自动更新
```

### 7.2 外部AI使用场景

- **行业趋势分析**: 调用GPT分析行业报告 → 生成Trend Node
- **企业画像生成**: 调用AI抓取公开信息 → 填充Company Profile
- **竞争情报**: 调用AI对比企业 → 生成Competitor关系
- **学习路径推荐**: 调用AI分析技能需求 → 生成Growth Path

### 7.3 速度优先

快节奏时代，行业一夜之间可能消失。系统必须：
- Observation Agent 每日扫描变化
- 地图自动演化，不需人工维护
- 行业模板快速复制（一个行业验证后，模板化扩展到其他行业）

## 八、Universe Rule Engine（Layer 0）

10条 Universe Rules 驱动所有层的运行。所有评分、推荐、演化、Agent解释必须引用规则。

```
R01: 能力飞轮 — 能力提升→证据→信誉→推荐→机会→数据→再提升
R02: AI推荐逻辑 — 能力+证据+信誉+关系+动态
R03: 地图自动演化 — 新能力→价值链变→关系重组→地图刷新
R04: 企业成长路径 — 学习→实践→案例→信誉→生态节点
R05: 五View=一个Universe — 同一节点，五种视角，联动高亮
R06: 每个节点是宇宙中心 — 无限展开，任意视角
R07: Marketplace是基石 — 产业地图的自然商业出口
R08: 子地图联动 — 选中节点在所有View中自动高亮
R09: 信誉数据驱动 — 不可人为干预
R10: Observation驱动演化 — 持续扫描→Event→Graph→Decision→地图刷新
```

## 九、交易平台（Marketplace）— 产业地图的商业出口

Marketplace不是附加功能，是产业地图的自然商业出口。

```
企业 GEO 诊断 → 发现能力缺口
       ↓
   生成需求 Demand
       ↓
   Matching Engine 检索候选服务商（candidates, 不是 winner）
       ↓
   展示匹配理由 + 能力证据 + 信誉分数（Intelligence Panel ⑦ 商业机会）
       ↓
   企业自主选择 → 发起连接 → 商业交易
       ↓
   交易数据回流 → Decision Engine → 地图更新
```

## 十、数据飞轮

企业加入 → GEO诊断 → 行业位置 → 认证背书 → 商业机会 → 交易连接 → 持续更新 → 价值增长

用户不是因为平台要求留下数据，而是因为留下数据能获得更多价值（数据 → 身份资产 → 产业信用）。
