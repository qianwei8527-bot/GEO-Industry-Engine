## 一、核心目标

**让每一个人在 AI 时代找到自己在产业中的位置。**

不是帮助企业优化搜索排名，不是做一个 GEO 工具，不是做 SaaS 平台。

而是：在这个技术每天在变、职业每月在变、产业每季度在变的时代，提供一个稳定的坐标系——让企业知道自己在哪里，让个人知道自己往哪走，让机构知道产业在怎么变。

---

## 二、服务对象

| 对象 | 核心问题 | 系统提供的价值 |
|------|---------|---------------|
| **企业** | 我在 AI 搜索中是什么形象？怎么改善？ | GEO 评分 + 优化建议 + 竞争位置 |
| **个人** | 我的技能在产业中值多少钱？下一步学什么？ | 能力画像 + 产业位置 + 发展路径 |
| **政府/园区** | 我们这的产业长什么样？缺什么？ | 产业地图 + 能力分布 + 趋势分析 |
| **投资机构** | 哪条赛道在涨？谁在领跑？ | Benchmark + 机会评分 + 产业雷达 |
| **服务商** | 谁需要我的服务？怎么找到他们？ | 客户发现 + 能力匹配 + 分析报告 |
| **研究者** | 产业数据在哪？趋势是什么？ | 结构化数据 + Index + API |

**不是一次性服务全部对象，而是架构上为每个对象预留了入口。第一阶段先服务企业和个人。**

## 四、技术建设原则

### 背景
GEO 产业处于剧烈变动中。今天的职业明天可能被 AI 替代，今天的技术栈明天可能消失，今天的行业分类明天可能被重新定义。系统必须为「变化」而设计。

### 原则 1：高可扩展
每个能力模块独立注册，不耦合。新增一个评分模型不需要改引擎代码。废弃一个 Agent 不影响其他模块。

### 原则 2：高可配置
权重、规则、Prompt、Agent 能力全部走 YAML 配置。不同行业加载不同配置。可热加载。

### 原则 3：可预测
相同输入产生相同输出。评分有明确原因链。禁止 LLM 直接生成评分。

### 原则 4：部分自动智能化
系统自动完成数据采集、基础评分、趋势检测。人工介入行业分类调整、异常处理、架构决策。系统给建议，人做决定。

### 原则 5：面向淘汰设计
每个模块假设自己 6 个月内可能被淘汰。不依赖特定 AI 模型、特定数据源、特定行业分类。核心价值在数据结构 + 关系网络 + 知识积累，不在技术选型。

### 原则 6：先跑通，再优化
功能先跑核心链路，再迭代。数据先有，再追求准确。配置先给默认值，再根据反馈调整。

## 最终使命

> GEO-Industry-Engine 不是一套技术引擎，而是一个让人在 AI 时代找到自己在产业中位置的基础设施。在这套基础设施上，企业和个人看到自己的产业坐标，发现下一步的方向，做出更好的决策。
