# 项目核心纲领 v3.2

> 最后更新：2026-07-30 | 状态：stable
> 替代：v3.1

---

## 一、项目定位

GEO Universe 是一个 **AI时代的产业信用网络 + 动态产业世界模型 + GEO产业社交网络 + AI产业导航系统**。

不是一个 GEO 工具集合，而是：
> 让每一个进入 GEO 产业的人，照见自己 → 找到位置 → 看清方向 → 获得路径 → 连接资源 → 拥抱未来。

---

## 二、三层认知入口

用户进入系统的第一眼，不是搜索框和菜单，而是三个认知入口：

```
GEO Industry Universe
├── 当前世界 → "我在哪？" → 查看产业全貌、竞争位置、GEO生态位
├── 成长路径 → "如何提升？" → 发现能力缺口、获取提升路径与资源
└── 未来世界 → "往哪去？" → 预测产业演化、提前布局增长点
```

---

## 三、六层架构

```
Layer 0: Rules        — Universe Rules（底层规则，所有层引用）
Layer 1: Node         — 统一节点 (Company/Provider/Industry/Person/Product/Capability/Resource/Agent/AI)
Layer 2: Graph        — 关系网络 (8种关系类型)
Layer 3: Dynamic      — 动态事件 (GeoEvent驱动变化)
Layer 4: Evolution    — 产业演化 (GrowthStage/ValueChain/FuturePath)
Layer 5: Intelligence — Agent OS + Intelligence Panel + Citation + Memory
```

---

## 四、五视图（Five Views）

不是五张独立地图，是一个 Universe + 五种 Camera View：

```
Ecosystem View     — 生态关系、上下游（Where am I?）
Business View      — 价值创造、商业模式（How is value created?）
Growth View        — 成长路径、能力提升（How to improve?）
Distribution View  — 区域分布、机会地图（Where are opportunities?）
Future View        — 产业演化、未来预测（Where to go?）
```

核心：节点在任一View中被选中，所有View中联动高亮。

---

## 五、Intelligence Panel（产业智能面板）

每个节点点击后打开统一的7栏智能面板：

1. **当前状态** — GEO评分、排名、认证状态
2. **能力测评** — 检测入口、能力评估
3. **发展方向** — 差距分析、行动建议
4. **学习成长** — 课程、路径、认证
5. **资源连接** — 专家、服务商、工具
6. **数据资产** — 证据、画像、竞争信息
7. **商业机会** — 候选服务商、市场机会

---

## 六、Universe Rules（宇宙规则 — 核心护城河）

10条规则驱动整个系统运行。所有评分、推荐、Agent解释必须引用规则编号，不可自由发挥。

```
R01: 能力飞轮       — 能力→证据→信誉→推荐→机会→数据→再提升
R02: AI推荐逻辑     — 能力+证据+信誉+关系+动态
R03: 地图自动演化   — 新能力→价值链变→关系重组→地图刷新
R04: 企业成长路径   — 学习→实践→案例→信誉→生态节点
R05: 五View=一个Universe
R06: 每个节点是宇宙中心
R07: Marketplace是基石
R08: 子地图联动高亮
R09: 信誉数据驱动，不可人为干预
R10: Observation驱动演化
```

---

## 七、Marketplace — 产业地图的自然商业出口

```
企业 GEO 诊断 → 发现能力缺口 → 生成需求 → Matching Engine → 候选服务商集 → 
展示匹配理由 → 企业自主选择 → 发起连接 → 交易数据回流 → 地图更新
```

核心：平台不替企业决策，只提供可信候选集和匹配依据。Agent角色是"服务商发现与能力匹配"，不是"推荐唯一赢家"。

---

## 八、数据飞轮

企业加入 → GEO诊断 → 行业位置 → 认证背书 → 商业机会 → 交易连接 → 持续更新 → 价值增长

用户不是因为平台要求留下数据，而是因为留下数据能获得更多价值。

---

## 九、开放生态策略

不闭门造车。借助 GPT、豆包、Kimi 等外部 AI 加速产业版图建设。Observation Agent 每日扫描变化，地图自动演化。

---

## 十、九大技术原则

1. **事实优先** — 代码 > 测试 > API > 配置 > 文档
2. **数据驱动** — 所有判断必须可追溯至数据源
3. **规则先行** — 所有评分/推荐/演化必须引用Universe Rules
4. **节点统一** — 所有实体共用一套Node模型
5. **View联动** — 五种View共享同一套数据，联动高亮
6. **AI解释不创造** — Agent只解释系统判断，不创造事实
7. **Candidate不Winner** — 平台只提供候选，不替用户决策
8. **动态非静态** — 地图持续演化，非一次生成
9. **开放不封闭** — 借助外部AI加速建设

---

> 核心命题：不要做 AI 能替代的撮合层，要做 AI 离不开的数据和认知层。
