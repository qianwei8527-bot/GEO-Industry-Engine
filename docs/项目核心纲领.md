# 项目核心纲领 v4.0（恒域世界）

> 最后更新：2026-08-11 | 状态：stable | 替代：v3.2（GEO Universe）
> 上位依据：恒域世界 V10.6 四阶段演进架构总纲 + 17-2 细节设计

## 一、项目定位

恒域世界是**由域主共同建设的世界操作系统**：以"域"为基本经营单元，帮助真实的人与组织完成资料收集、分析、计划、执行、问题处理、证据验证、成果复盘与能力沉淀，并在授权、确权和可信治理边界内复用或交易产业能力。

GEO-Industry-Engine 是当前仓库名；"恒域世界-GEO"是首个行业世界与第一阶段验证场。

## 二、最高原则

> Realm Owner Value & Evidence First：真实域主经营任务、真实客户需求与可信证据优先。架构服务于真实经营闭环，但不得以满足需求为由绕过权限、证据、隐私和治理边界。

## 三、当前阶段

第一阶段：单域真实经营闭环（一个垂直赛道、一个真实域主、一个核心产品、一类目标客户、一个主要转化目标）。

## 四、四个应用面

| 应用面 | 职责 |
|--------|------|
| 域主工作台 | 主产品：今日工作 / 客户与定位 / 项目与计划 / 执行与问题 / 结果与资产 / 工具与连接 |
| 公共世界与客户协作端 | /public /intake /client /market |
| 平台运营后台 | 平台运营与配置 |
| 治理审计台 | 权限、审批、审计、风险 |

四应用面共用一套 AppShell（WorkBuddy 式「对话 + 任务 + 工作面」）。

## 五、可信与治理边界

- node_memberships 是权限真相源；域主不得自造 verified。
- AI 提取默认 observed/inferred；unknown 不补造；simulation 不写入生产关系。
- Outcome 不直接改变 Reputation；completed 不等于已验证。
- 未批准不新增模型和迁移；外部动作分级授权，禁止动作不自动执行。

## 六、域能力资产化

SOP / Workflow / UI Preset / Skill / 工具模板 → 域能力包；域主确认后才成为资产；能力包不得包含客户原始数据、私密文件、密钥和未授权内容。

## 七、外部工具与源码主权

Codex/OpenClaw/Dify/n8n 等经 Provider Adapter/MCP/API 接入，不作为核心运行时；源码保存在本地或授权仓库，diff、测试、提交记录齐全。

## 八、开发原则

1. 真实闭环优先
2. 复用优先
3. 简洁优先（上传/粘贴 → AI 分析 → 域主确认）
4. 配置化与可控
5. 不制造事实
6. 范围匹配验证
7. 不提前铺开
8. 不自动发布
