# GEO-Industry-Engine SEO 与 AI 可见度策略

> 状态：架构设计 | 版本：v1.0 | 日期：2026-07-28

## 一、自身 SEO 策略

GEO-Industry-Engine 自身必须在 AI 搜索中高度可见——这是产品最好的案例。

### 1.1 技术 SEO

| 措施 | 实现 |
|------|------|
| SSR | Next.js App Router 默认 SSR |
| Metadata | 每页独立 title/description/og:image |
| Sitemap | 自动生成 + 提交 Google/Bing |
| Structured Data | JSON-LD: Organization, WebApplication, Dataset |
| Core Web Vitals | FCP<1.5s, LCP<2.5s, CLS<0.1 |
| URL 结构 | 语义化：/industries/ai-infrastructure /company/tencent-cloud |

### 1.2 AI 搜索优化

| 措施 | 目的 |
|------|------|
| 结构化企业数据 | 让 AI 搜索引擎准确理解每个企业 |
| 权威内容 | 发布 GEO 产业报告、方法论文章 |
| 实体关联 | 企业页面相互链接，建立知识图谱 |
| 引用体系 | 所有数据可追溯到来源，增强可信度 |
| 多模态 | 企业 Logo + 截图 + 数据可视化图表 |

### 1.3 内容策略

| 内容类型 | 目标 | 频率 |
|---------|------|:--:|
| GEO 产业月度报告 | 建立行业权威 | 月 |
| 企业 GEO 案例 | 产品证明 | 周 |
| 方法论文章 | 技术可信度 | 月 |
| GEO 指数发布 | 行业标准制定者定位 | 季 |

## 二、缓存策略

| 数据 | 缓存层 | TTL | 失效策略 |
|------|--------|:--:|---------|
| 产业统计数据 | Redis | 60s | 相关 Event 触发失效 |
| 企业身份卡（简版） | Redis | 300s | Entity 更新触发失效 |
| 评分结果 | Redis | 120s | Decision 重算触发失效 |
| 地图聚合数据 | Redis | 60s | 新 Entity 进入触发失效 |
| 认证等级定义 | 应用内存 | 启动加载 | PUT /admin/config 触发重载 |
| 前端静态资源 | CDN | 1y | 文件名 hash 变更 |
| API 响应（公开） | CDN | 60s | — |

缓存键格式：`cache:{domain}:{entity_id}:{version}`

## 三、前端状态管理

| 状态类型 | 管理方式 | 示例 |
|---------|---------|------|
| URL 参数 | Next.js useSearchParams | 搜索词、筛选条件、分页 |
| 用户会话 | JWT Cookie + Context | 登录状态、角色、套餐 |
| 页面级状态 | React useState | 表单输入、展开/折叠 |
| 跨页面状态 | React Context | 当前查看的企业 ID |
| 服务端状态 | fetch + Cache | API 数据（自动缓存） |
| 实时状态 | SSE / WebSocket | 评分变化通知 |

不引入 Redux/Zustand 等全局状态库——当前页面复杂度不需要。
