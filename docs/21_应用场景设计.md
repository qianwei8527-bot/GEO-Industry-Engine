# 应用场景设计

> 两个核心场景 + 一条商业闭环：B2B供应商在AI搜索中被推荐 → 买家找到供应商 → 交易发生。

---

## 一、核心理念

### 1.1 GEO-Engine = AI时代的"供应商上榜系统"

用户问AI"我需要一个XX供应商" → AI推荐 → 被推荐的企业获得商机。

这不是泛化的"品牌曝光"，而是精准的**供应商推荐占位**。

### 1.2 为什么选B2B供应商场景

| 原因 | 说明 |
|------|------|
| 商业价值极高 | 一个B2B订单几万到几千万 |
| 决策链短 | "找供应商"的意图明确，直接导向交易 |
| 付费意愿强 | 供应商花几万/年上榜ThomasNet/Alibaba，GEO是AI版 |
| 容易验证 | "上周AI搜索推荐您3次，带来2次询盘" 直接可测 |

## 二、场景一：AI供应商推荐（可见度系统）

### 2.1 用户视角

**买家**在AI搜索中提问：

```
"国内MES系统供应商有哪些？"
"工业机器人十大品牌"
"ERP系统推荐 制造业"
"深圳靠谱的SaaS服务商"
```

**AI回答**中列出供应商。**我们的目标**：让付费供应商出现在AI回答中，并且排在前列。

### 2.2 系统流程

```
供应商注册（添加企业信息、产品、案例、认证）
    ↓
系统扫描：该供应商在哪些查询中被AI提及？
    ↓
系统评估：当前AI推荐力（GEO评分）
    ↓
系统建议：补充哪些信息能提升被推荐概率
    ↓
供应商优化（上传白皮书、填写案例、通过认证）
    ↓
系统重扫：优化后的AI推荐变化
    ↓
持续监测：推荐量、询盘量、转化量
```

### 2.3 示例数据

| 供应商 | 行业 | 当前AI推荐力 | 可优化的查询 | 预估优化后提升 |
|--------|------|-------------|------------|-------------|
| 某MES厂商 | 制造业 | 62分 | ERP推荐/生产管理 | 提升至78分(+16) |
| 某机器人公司 | 工业 | 55分 | 焊接机器人/自动化产线 | 提升至72分(+17) |
| 某SaaS服务商 | 企业服务 | 45分 | CRM推荐/客户管理 | 提升至65分(+20) |

### 2.4 涉及的模块

| 模块 | 作用 |
|------|------|
| AI可见度增长系统 | GEO评分 + 推荐监测 |
| 实体智能图谱 | 供应商的数字身份与能力画像 |
| 信息供应链 | AI从哪里知道这家供应商 |
| AITrustScore | AI对供应商的信任评分 |
| 内容就绪度 | 供应商内容被AI引用的概率 |

## 三、场景二：B2B供应商交易（交易市场）

### 3.1 用户视角

**买家**通过AI搜索发现供应商后，进入平台：

```
看供应商详情（产品、案例、资质、评价）
比较3-5家供应商
发起询盘/联系
收到报价
成交
```

### 3.2 系统流程

```
买家通过AI推荐进入平台
    ↓
查看供应商档案（AI生成的完整画像）
    ↓
对比同类供应商（AI自动对比）
    ↓
发起询盘（平台内消息）
    ↓
供应商回复报价
    ↓
买家选择成交
    ↓
平台记录交易
    ↓
供应商GEO评分提升（交易信号）
```

### 3.3 商业模型

| 收入源 | 说明 | 参考 |
|--------|------|------|
| 供应商年费 | 被AI推荐的基础资格 | ThomasNet $5000/年 |
| 询盘费 | 每条询盘收费 | Alibaba 按询盘付费 |
| 交易佣金 | 成交额2-5% | Alibaba/1688 |
| 认证费 | AI信任认证收费 | 自有认证体系 |
| 广告位 | 搜索结果前排 | Google Ads |

### 3.4 涉及的模块

| 模块 | 作用 |
|------|------|
| GEO交易市场 | 需求发布、服务商匹配 |
| 认证体系 | 供应商信用背书 |
| 竞争情报 | 供应商间的AI可见度对比 |
| Agent OS | 自动匹配需求和供给 |

## 四、商业闭环

### 4.1 完整链路

```
AI搜索 → 供应商被推荐 → 买家到平台 → 看档案 → 询盘 → 成交 → 佣金
    ↑                                                           |
    └─────────────────── 供应商付费续费 ←───────────────────────┘
```

### 4.2 三方价值

| 角色 | 得到什么 | 付什么 |
|------|---------|-------|
| 买家 | 快速找到可信供应商 | 无（平台对买家免费）|
| 供应商 | 被AI推荐 + 获得询盘 | 年费 + 佣金 |
| 平台 | 交易撮合 + 数据沉淀 | 运营成本 |

### 4.3 为什么这个闭环成立

传统B2B平台（Alibaba/ThomasNet）的痛点是：
- 买家需要主动去平台搜索
- 平台流量依赖广告和品牌

我们的差异点是：
- **买家不需要来平台**，他们在AI搜索中自然发现供应商
- 平台作为"AI推荐的落地页"承接流量
- AI推荐 + 交易市场 = 从曝光到成交的全链路
