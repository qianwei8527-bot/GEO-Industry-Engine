## 一、企业场景

### 场景1: AI营销公司评估自身GEO表现

角色: 市场负责人
路径: 首页搜索公司名 -> 快速检测(30秒出简版) -> 查看完整四层报告 -> 发现"技术文档内容只有3篇，可见度低于行业平均" -> 获取行动建议 -> 补充数据资产 -> 申请认证

价值: 从"不知道自己在AI搜索中的位置"到"知道缺口+有路径提升"

### 场景2: 传统制造企业进入AI领域

角色: CEO/战略负责人
路径: 产业导航 -> 搜索"智能制造" -> 查看行业生态地图 -> 发现"智能质检"是空白机会 -> 查看机会评级(B+) -> 获取进入路线

价值: 用数据决定"该进入哪个细分方向"，而非拍脑袋

### 场景3: 企业监控竞争对手

角色: GEO负责人
路径: 检测中心 -> 竞争对比 -> 添加竞品 -> 查看多维对比(可见度/认证/内容/关系) -> 发现"竞品30天内可见度+15%" -> 收到黄色预警 -> 制定追赶计划

价值: 实时感知竞争变化，而非季度复盘才发现被超越

## 二、个人场景

### 场景4: SEO从业者转型GEO优化师

角色: 个人求职者
路径: 首页"个人"入口 -> 能力自评 -> 看到"GEO优化师"职业路径 -> 对比能力缺口(SEO强/AI内容弱) -> 获取学习建议 -> 申请L1个人认证

价值: 知道"我离GEO岗位差什么"和"怎么补"

### 场景5: AI咨询顾问建立个人品牌

角色: 自由职业者
路径: 认证中心 -> 个人认证 -> 提交案例+客户评价 -> AI自动审核 -> 获得L3专家认证(紫标) -> 在交易市场展示 -> 被企业搜索找到

价值: 用认证体系替代简历筛选，用系统信任替代关系介绍

---

## 三、服务商场景

### 场景6: GEO服务商获取客户

角色: 服务商
路径: 认证中心 -> 申报能力(case: AI内容优化/技术文档) -> AI审核+人工确认 -> 获得L2认证 -> 在交易市场"AI内容优化"分类下展示 -> 收到企业需求匹配通知 -> 提交方案

价值: 从"被动找客户"到"系统自动匹配需求"

---

## 四、政府/园区场景

### 场景7: 高新区评估AI产业实力

角色: 产业管理部门
路径: 产业导航 -> 地域地图 -> 选择"XX高新区" -> 查看: 企业密度/GEO平均分/认证率/能力分布 -> 导出区域产业报告 -> 与邻区对比

价值: 用产业数据替代汇报材料，辅助招商和政策制定

---

## 五、投资场景

### 场景8: VC发现AI赛道投资标的

角色: 投资经理
路径: 产业导航 -> 商业地图 -> 选择"AI营销" -> 查看: 市场增长趋势/玩家分布/能力图谱 -> 关注新兴高增长企业 -> 通过数据资产中心查看企业详细GEO表现 -> 导出投资分析

价值: 用产业数据验证投资判断，发现早期信号
