> 状态：架构设计 | 版本：v2.0 | 日期：2026-07-28

## 一、开放层次

### 1.1 三层开放模型

```
Layer 3: Developer Platform (未来)
  自定义Agent / 行业应用 / 第三方集成
         |
Layer 2: API & MCP (当前设计)
  REST API / MCP Protocol / Webhook
         |
Layer 1: 数据导出 (基础)
  JSON/CSV导出 / 嵌入Badge / 分享链接
```

### 1.2 开放原则

- 核心数据: 通过API授权访问，不直接开放数据库
- 产业知识图谱: 聚合数据可开放，个体数据需授权
- 评分算法: 通过API调用，算法细节可解释但不完全公开
- 认证数据: 公开认证级别，详细证据需授权

## 二、REST API

### 2.1 API版本策略

```
/v1/ 当前版本 (向后兼容)
/v2/ 未来版本 (breaking changes时启用)
```

### 2.2 公开API (无需认证)

| 端点 | 说明 | 限流 |
|------|------|:--:|
| GET /v1/entities/{id}/public | 实体公开信息 | 100/min |
| GET /v1/industries | 行业列表 | 100/min |
| GET /v1/rankings/public | 公开排行榜 | 100/min |
| GET /v1/certification/{id}/badge | 认证标识(SVG) | 无限制 |
| POST /v1/detection/quick | 快速检测(公开) | 10/min |

### 2.3 认证API (需JWT/API Key)

| 端点 | 说明 | 角色 |
|------|------|------|
| GET /v1/entities/{id}/full | 实体完整信息 | 授权 |
| POST /v1/decision/geo-score | GEO Score计算 | 授权 |
| GET /v1/marketplace/* | 交易市场 | 认证用户 |
| POST /v1/certification/apply | 认证申请 | 认证用户 |

### 2.4 开发者API (需API Key + 配额)

| 端点 | 配额 (月) | 用途 |
|------|:-------:|------|
| GET /v1/industry/data | 10000 | 行业数据查询 |
| POST /v1/agent/analyze | 5000 | Agent分析调用 |
| GET /v1/context/* | 10000 | Context Engine查询 |

## 三、MCP协议

### 3.1 MCP工具清单

| 工具名 | 描述 | 输入 | 输出 |
|--------|------|------|------|
| geo_context_query | 查询GEO实体上下文 | entity_id, query_type | EntityContext |
| geo_decision_calculate | 执行GEO决策计算 | entity_id, decision_type | DecisionResult |
| geo_agent_caller | 触发Agent分析 | query_text, agent_type | AgentResponse |
| geo_industry_search | 搜索产业信息 | industry, region, metric | IndustryData |

### 3.2 MCP接入流程

1. 开发者注册 -> 获取 API Key
2. 配置 MCP Client -> 指向 /mcp 端点
3. 调用工具 -> 返回结构化数据

## 四、Webhook

### 4.1 事件类型

| 事件 | 触发时机 | Payload |
|------|---------|---------|
| geo_score_changed | GEO Score变化 > 10% | entity_id, old, new, reason |
| certification_approved | 认证审核通过 | entity_id, level, certificate_url |
| competitor_alert | 竞品预警触发 | entity_id, competitor_id, alert_level |
| opportunity_detected | 新机会发现 | entity_id, opportunity_id, grade |
| data_completeness_changed | 数据完整度变化 | entity_id, completeness_score, gaps |

### 4.2 配置

用户可在设置页配置 Webhook URL + 订阅事件类型
