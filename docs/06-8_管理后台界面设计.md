### 2.3 审核状态流转

```
提交 → AI审核中 → AI通过 → 人工待审 → 人工审核中 → 通过/驳回
              ↘ AI驳回 → 通知用户(可修改重提)
              
驳回 → 30天冷却期 → 可重新申请
通过 → 即刻生效 → 更新Trust Score + 通知用户 + 更新身份卡
```

```
┌─────────────────────────────────────────────────────────────┐
│ 配置管理                                        [配置历史]   │

│ 配置目录      │                                              │
│              │  scoring/geo_visibility.yaml                  │
│ ▼ scoring/  │  ┌──────────────────────────────────────┐    │
│   geo_vis…  │  │ 1  weights:                           │    │
│   trust_sc… │  │ 2    entity_quality: 0.25             │    │
│   assessm…  │  │ 3    evidence_score: 0.25             │    │
│   visibili… │  │ 4    capability_match: 0.20           │    │
│   opportun… │  │ 5    relationship_density: 0.15       │    │
│   industry… │  │ 6    recency: 0.15                    │    │
│ ▼ certifi…  │  │ 7  thresholds:                        │    │
│ ▼ pricing/  │  │ 8    high: 80                         │    │
│ ▼ marketp…  │  │ 9    medium: 60                       │    │
│ ▼ competi…  │  │10    low: 30                          │    │
│ ▼ analyti…  │  └──────────────────────────────────────┘    │
│              │  ⚠ 权重总和: 1.00 ✅                         │
│              │  schema_version: 1.0 ✅                      │
│              │                                              │
│              │  [发布到 active/] [保存草稿] [恢复默认]       │
└──────────────┴──────────────────────────────────────────────┘
```

交互：
- 左侧目录树：点击展开/收起，点击文件加载编辑区
- 编辑区：语法高亮 + 实时校验（权重总和、字段类型、阈值范围）
- 校验通过显示绿色 ✅，不通过显示红色 ❌ + 错误信息
- [发布到 active/] → 二次确认 → ConfigRegistry.reload → 受影响引擎重算
- [保存草稿] → 存入 experiments/，不影响线上
