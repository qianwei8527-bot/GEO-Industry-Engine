# Universe 世界规则

> GEO Universe 不是随机构建的数据库。它是一个有规则的世界。这些规则定义了节点如何存在、关系如何形成、地图如何演化、信誉如何累积。

---

## 规则零：所有规则必须可被机器验证

Universe 的规则不是哲学宣言。每一条规则必须满足：

- 可以被代码实现（不是概念，是可执行的逻辑）
- 可以被数据验证（规则是否生效，必须可观测）
- 可以被 Agent 引用（任何 Agent 的解释必须引用规则编号）

---

## 规则一：每个节点都是世界中心

在 Universe 中，不存在 主节点 和 子节点。任何节点被选中时，整个 Universe 围绕它重新展开。

- 选中一家企业：展示它的供应链、竞争对手、服务商、能力
- 选中一个能力：展示拥有它的服务商、需要它的企业、关联的赛道
- 选中一个行业：展示企业分布、能力供给、成长阶段、未来趋势
- 选中一个人（远期）：展示技能画像、学习路径、职业机会

实现约束：Intelligence Panel 的 7 个 tab 对每个节点类型显示不同侧重，但数据结构共享同一套底座。

---

## 规则二：五个视角 = 一个 Universe

生态视图、商业视图、成长视图、分布视图、未来视图不是五张地图。它们是同一个 Universe 的五种观察角度。

- 节点在任一 View 中被选中，所有 View 中联动高亮
- View 切换时，数据不重新加载，只改变渲染方式
- 未来增加第六、第七种 View 时，不需要重新设计数据库

---

## 规则三：所有节点都有生命周期

每个节点经历：诞生 -> 成长 -> 成熟 -> 衰退/转型 -> 消失（或被新节点吸收）。

- 一个企业今天活跃，不代表它 3 年前存在或 3 年后仍存在
- 一个能力今天稀缺，不代表它 18 个月后仍有需求
- 一个赛道今天不存在，不代表下周不会出现

实现约束：Node Evolution 引擎必须追踪每个节点的阶段变化，GeoEvent 记录触发演化的关键事件。

---

## 规则四：能力 -> 证据 -> 信誉 -> 推荐 -> 机会 -> 数据 -> 能力

这是 Universe 的核心飞轮。

- **能力**：一个实体声明自己拥有什么能力
- **证据**：可验证的数据证明这个能力是真实的
- **信誉**：证据的累积形成可量化的信誉分数
- **推荐**：高信誉的实体被 AI 和系统优先推荐
- **机会**：推荐带来商业连接和交易机会
- **数据**：交易结果和评价回流为新的证据
- **再循环**：新的证据提升能力感知，飞轮加速

这个飞轮不能跳跃。不能没有证据就声称信誉。不能没有信誉就获得推荐。

---

## 规则五：评分必须可解释，解释必须引用证据

任何一个评分输出，必须同时输出：

- **分数本身**（GEO Score: 72）
- **评分理由**（Trust: 高 +18，Visibility: 低 -12）
- **引用的证据**（证据编号 #142, #238, #401）
- **改进建议**（建议补齐行业认证，预计提升 Trust +15）
- **引用的规则**（依据 R04 能力飞轮和 R09 信誉数据驱动）

没有解释的评分 = 不可信的评分。不可信的评分不应存在于 Universe 中。

---

## 规则六：Map 自动演化

当以下任何一种情况发生时，Universe 地图必须自动更新：

- 新能力出现 -> 价值链重组 -> 关系网络变化 -> 地图刷新
- 新企业加入 -> 竞争格局变化 -> 地图刷新
- GeoEvent 发生（融资、技术突破、政策变化） -> 趋势信号更新 -> 地图刷新
- AI Observation 发现新赛道 -> 新节点自动创建 -> 地图刷新

地图不是人工维护的。它是被事件驱动的。

---

## 规则七：Marketplace 是商业自然出口，不是附加功能

Universe 的价值链终点是商业连接。Position 让你看到自己，Growth 让你知道往哪走，Connection 让你找到对的伙伴。Marketplace 是 Connection 的产品化实现。

- 不是 搜索服务商 -> 购买 的电商逻辑
- 而是 诊断 -> 发现缺口 -> 匹配能力 -> 候选集合 -> 自主选择 -> 交易 -> 数据回流

---

## 规则八：信誉不可人为干预

信誉分数只能通过以下方式变化：

- 新证据提交并通过验证
- 交易完成并获得评价
- 第三方认证通过
- 时间衰减（长期无活动，信誉自然下降）

任何人（包括管理员）不能直接修改信誉分数。这是 Universe 信任的基石。

---

## 规则九：AI 加速，Universe 定义

AI 可以：观察、理解、解释、生成、预测。
AI 不可以：定义规则、修改信誉、决定推荐。

- Agent 解释评分时 -> 引用 Universe Rules（不是自由发挥）
- Agent 推荐候选时 -> 引用 Evidence + Reputation（不是黑箱判断）
- Agent 生成报告时 -> 引用 Context Engine + Decision Engine（不是凭空创造）

---

## 规则十：生态价值 > 节点价值之和

如果添加一个节点不能让整个网络的认知价值提升，那它只是一个数据条目，不是生态节点。

Universe 的价值不在于有多少企业，而在于：
- 企业的关系是否准确
- 信誉是否有时间深度
- 推荐是否有证据支撑
- 地图是否反映真实产业动态

---

> 十规则定义了 Universe 的运行规则。它们是 Layer 0 的实现依据。所有 Agent 输出、评分计算、地图渲染、推荐生成必须引用这些规则。
