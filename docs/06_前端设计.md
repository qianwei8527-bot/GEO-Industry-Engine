# GEO产业引擎 — 前端设计

> **共享契约遵循**：本文件所有页面设计均以 02_领域模型设计.md 为数据依据。
> 领域模型变动时，必须同步检查页面展示是否需要调整。

---

## 一、前端定位

用户看到的是 **GEO产业导航操作系统**，不是普通网站。核心理念：

- **信息即界面** — 产业地图本身即是主界面
- **数据驱动** — 所有页面核心位置都有数据可视化
- **AI贯穿** — 每个页面都有AI功能入口
- **参与共建** — 用户可评论、贡献、评价

## 二、用户角色

| 角色 | 核心任务 | 关键页面 |
|------|---------|---------|
| 企业用户 | 查看GEO评分、监测AI可见度、获取增长建议 | Dashboard、增长中心、企业画像 |
| GEO服务商 | 案例展示、客户获取、项目管理 | 服务商主页、交易市场、项目看板 |
| 投资机构 | 行业趋势、标的企业GEO评分 | 产业地图、数据中心、研究报告 |
| 行业研究者 | 产业地图浏览、数据下载、报告生成 | 产业导航、数据中心、研究工具 |
| 个人从业者 | 个人AI品牌管理、技能认证、学习 | 个人中心、认证中心、学习路径 |
| 平台管理员 | 用户管理、认证审核、数据管理 | 后台管理 |

## 四、状态管理

| 状态域 | 前端状态 | 后端来源 | 涉及页面 |
|--------|---------|---------|---------|
| 用户 | user, token, role, permissions | /api/v1/auth/* | 全部 |
| 企业 | company, geo_score, members | /api/v1/companies/* | 增长中心、企业页 |
| 行业 | industries, sectors, hierarchy | /api/v1/industries/* | 产业导航 |
| 地图 | maps, nodes, edges, layers | /api/v1/maps/* | 产业导航 |
| 交易 | requests, providers, transactions | /api/v1/marketplace/* | 交易市场 |
| 认证 | certifications, levels, scores | /api/v1/certification/* | 生态中心 |
| Agent | agent status, tasks, results | /api/v1/agents/* | 全部（后台调用）|

## 五、Agent交互入口

| 页面 | 调用的Agent | 触发方式 |
|------|-----------|---------|
| 企业画像页 | Company Agent → 分析企业GEO表现 | 页面加载时自动 |
| 产业地图 | Industry Agent → 分析产业态势 | 点击"AI分析"按钮 |
| 增长中心 | Scanner Agent → 执行扫描 | 点击"开始检测" |
| 内容优化 | Content Agent → 生成优化方案 | 输入关键词后 |
| 交易市场 | Market Agent → 智能匹配 | 发布需求后自动 |
| 数据中心 | Data Agent → 数据汇总 | 页面加载时自动 |

## 六、页面设计（原有UX内容）

> 以下页面设计来源于原始 UX 设计文档，已整合至此。
> 每个页面的数据字段定义详见 02_领域模型设计.md。

### 6.1 首页
- Hero区 + 实时GEO综合指数看板
- 五大核心入口 + 免费检测（企业/个人）
- 产业地图缩略图预览 + 认证快速申请入口

### 6.2 AI增长中心
- Dashboard：GEO评分趋势图 + AI提及热力图 + 三线预测图 + 竞争对标仪表盘(多企业对比) + ROI计算器(效果模拟)
- 企业/个人检测入口 + 曝光分析 + 内容优化

### 6.3 产业导航

- 5张交互地图（生态/商业/运营/地域/发展）
- 每层支持：监控面板 + 建议按钮 + 新增节点 + 评论
- GEO职业生态子页面（新增）：
  - 产业链地图：上中下游结构展示
  - 产业趋势视图：GEO产业生命周期、技术趋势时间线、市场规模TAM/SAM/SOM
  - 职业地图：7个岗位的可视化分布、需求量热力图、薪资区间对比
  - 技能图谱：L1-L4技能树、技能关联网络、学习路径推荐
  - 岗位墙：7个GEO岗位卡片展示（职责/技能/薪资/需求量）
  - 技能体系：L1-L4技能等级可视化
  - 成长路径：4条路径的交互式职业树
  - 趋势看板：市场TAM/SAM/SOM数据展示
  - 企业需求：按成熟度对应的人才匹配
- 5张交互地图（生态/商业/运营/地域/发展）
- 每层支持：监控面板 + 建议按钮 + 新增节点 + 评论

### 6.4 交易市场
- 分类导航 + 搜索/筛选 + AI推荐 + 热榜 + 最新上架

### 6.5 数据中心

- 行业/企业/个人数据库 + AI回答库 + 知识图谱 + 研究资料库 + 跨行业对比面板 + API数据服务管理 + **AI模型智能库**

#### AI品牌排名（核心输出页面）

| 视图 | 功能 |
|------|------|
| 综合排名 | 企业GEO评分总榜（支持按行业/地域筛选），排名变化趋势 |
| 模型对比 | 单企业在各模型的评分差异（雷达图），发现短板模型 |
| 行业榜单 | 行业内企业排名，竞品对比 |
| 趋势追踪 | 排名变化历史，上升最快/下降最快企业 |
| 报告导出 | 品牌排名报告PDF/Excel |

**定位**：AI时代的Alexa/SimilarWeb排名。数据中心的招牌页面，放在最显眼位置。

---

#### AI模型智能库（5层研究系统管理页面）

| 视图 | 功能 | 操作权限 |
|------|------|---------|
| 模型生态地图 | 全球模型+中国模型列表（GEO价值标注、生态定位） | 浏览 |
| 用户行为分析 | 查询意图分布、会话模式分析、任务-模型关联矩阵、格式偏好统计 | 浏览+导出 |
| 用户画像 | 各模型用户群体分析（谁在用、影响谁） | 浏览 |
| 行业热度矩阵 | 行业X模型热度排行、趋势变化 | 浏览 |
| Prompt知识库 | Prompt查询结果浏览（按模型/行业/时间筛选）| 浏览+导出 |
| AI品牌排名 | 综合排名展示页（数据中心的首页级展示） | 浏览 |
| 数据管理 | 新增模型、编辑、录入指标、调整行为模式 | 管理员 |
| 管道状态 | 自动采集管道运行状态、日志、手动触发 | 管理员 |

| 视图 | 功能 | 操作权限 |
|------|------|---------|
| 模型总览 | 全部模型列表（搜索/筛选/排序），模型总数统计 | 浏览 |
| 模型详情 | 基本信息 + 画像Tab + 指标Tab + 行为Tab + 来源Tab + 行业热度Tab | 浏览 |
| 模型对比 | 多模型横向对比（并排显示指标/行为/来源差异） | 浏览 |
| 查询结果 | 历史查询样本浏览（按模型/行业/时间筛选） | 浏览 |
| 数据管理 | 新增模型、编辑模型信息、删除模型、录入指标 | 管理员 |
| 管道状态 | 自动采集管道运行状态、最近执行时间、执行日志、手动触发 | 管理员 |
| 数据导出 | 模型数据库导出CSV/JSON | 认证用户 |

**可延展性**：
- 新模型出现时可手动新增或自动发现后确认入库
- 所有指标和评分可手动修正后覆盖自动计算结果
- 模型行为模式可手动调整和标注
- 来源偏好权重可手动校准
- 行业/企业/个人数据库 + AI回答库 + 知识图谱 + 研究资料库 + 跨行业对比面板 + API数据服务管理
- **AI模型智能库**：模型注册表、行为分析、来源偏好、行业热度矩阵、查询结果样本、管道状态看板
