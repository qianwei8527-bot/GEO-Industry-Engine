> 状态：架构设计 | 版本：v2.0 | 日期：2026-07-28

## 一、贡献者体系

### 1.1 贡献者角色

| 角色 | 定义 | 权益 |
|------|------|------|
| 数据贡献者 | 补充/校正产业数据 | 数据贡献积分 + 优先访问 |
| 审核志愿者 | 参与认证人工审核 | 审核积分 + 社区声望 |
| 内容创作者 | 撰写行业分析/GEO指南 | 内容曝光 + 专家标签 |
| Agent开发者 | 开发Agent插件 | 开发者市场分成 |
| 标准贡献者 | 参与GEO标准制定 | 标准署名 + L4加速 |

### 1.2 贡献激励机制

| 贡献类型 | 积分 | 兑换 |
|---------|:---:|------|
| 补充1条企业数据 | 5 | 免费评估次数 |
| 校正1条错误数据 | 10 | 认证费用折扣 |
| 提交1份审核意见 | 15 | API配额增加 |
| 发表1篇行业分析 | 50 | 专家标签 |
| 开发1个Agent插件 | 200 | 市场分成 |

## 二、开发者生态

### 2.1 开发者类型

| 类型 | 描述 | 工具支持 |
|------|------|---------|
| API集成开发者 | 将GEO数据集成到自己产品 | REST API + SDK |
| Agent插件开发者 | 开发行业专用Agent | Agent SDK + 沙箱 |
| 数据源开发者 | 接入新的数据源 | DataSource Plugin接口 |
| 前端主题开发者 | 定制行业版UI | 组件库 + 主题系统 |

### 2.2 开发工具链

| 工具 | 用途 | 状态 |
|------|------|:--:|
| Python SDK | 后端API调用封装 | P1 |
| TypeScript SDK | 前端/Node.js API调用 | P1 |
| Agent SDK | Agent插件开发框架 | P2 |
| CLI工具 | 项目管理/部署/测试 | P2 |
| Postman Collection | API调试 | P1 |
| OpenAPI Spec | API文档生成 | ✅ 已完成 |

### 2.3 沙箱环境

- 独立Staging环境: 完整功能 + 匿名化数据
- API Mock Server: 无后端依赖的前端开发
- 测试数据生成器: 创建模拟企业/行业数据

## 三、社区治理

### 3.1 治理结构

```
GEO标准委员会 (L4认证 + 选举)
  -> 制定GEO评分标准/认证规则
  -> 审议重大架构变更

社区维护者 (核心贡献者)
  -> Code Review
  -> 文档维护
  -> Issue分类

普通贡献者
  -> 提交PR/数据/内容
```

### 3.2 决策机制

- 技术决策: CTO + 核心团队
- 标准决策: 标准委员会投票 (2/3通过)
- 社区决策: RFC流程 (提案->讨论->投票->实施)

### 3.3 行为准则

- 尊重: 禁止人身攻击/歧视
- 诚信: 禁止数据造假/刷分
- 协作: 鼓励互助/知识分享
- 透明: 决策过程公开可查
