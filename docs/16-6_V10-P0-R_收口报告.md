# V10-P0-R 收口报告

> 状态：已实施 | 更新：2026-08-03
> 表述：V10-P0 域主价值链基础设施已落地，等待真实执行与运营验证。

## 1. Realm 唯一身份链

- `entities.id` 是统一 Realm ID；`companies.id`、`brands.id`、`products.id` 都是 `entities.id` 的一对一子类型外键。
- `realm_registry.entity_id` 唯一且外键到 `entities.id`，不允许同一实体重复注册。
- Evidence、Relationship、Asset、Authorization、Project、Artifact、Outcome 全部引用该统一 ID。
- `geo_projects.realm_entity_id`、`tool_execution_records.realm_entity_id` 新增实体外键。

## 2. 权限唯一真相源

- `node_memberships` 是操作权限唯一真相源。
- `realm_registry.owner_id` 只是缓存/投影，`list_mine` 只返回有 active membership 的域。
- 所有写操作通过 `realm_owner` / `realm_editor` 角色检查；reviewer/admin 才能执行治理审核。

## 3. 认领状态机

```text
创建新域 -> 创建者成为初始 node_owner
认领已有镜像域 -> realm_claims pending -> governance review -> approved/rejected
approved -> node_memberships 写入 node_owner + owner_id 缓存更新
rejected -> 可重新提交，不产生控制权
```

`realm_claims.deduplication_hash` 唯一，防止并发重复认领；同用户重复提交幂等。

## 4. 数据授权状态机

```text
active -> revoked（所有者撤销）/ expired（valid_until 过期）
```

授权主体支持 user/realm/project/provider/tool；外部 provider 必须 `ai_tools` scope 且 `allow_external_processing=true`。工具执行必须绑定 `authorization_id` 和 `authorization_hash`，执行前重新校验状态、有效期、scope、provider、tool。

## 5. 工具执行可信等级

| execution_source | 来源 | 允许状态 |
| --- | --- | --- |
| declared | 用户提交 | 仅 observed，execution_status=declared |
| system | 本地真实工具适配器 | success/failed，observed |
| callback | 可信回调（预留） | 需签名或治理确认 |

输入输出 manifest 只保存引用和哈希，敏感 key 会被 redact。

## 6. Outcome 相关性校验规则

不再使用“EvidenceClaim verified 即 Outcome verified”：

- Claim subject 必须等于 Outcome 所属 Realm ID。
- predicate 必须在 `outcome.predicates[outcome_type].allowed_predicates`。
- object_code 必须在 allowed objects。
- object_value 与 Outcome claim 一致。
- metadata 必须含 `project_id` 或属于该项目的 `artifact_id`。
- Evidence 与 Claim 均 verified、有效、`may_affect_real_metrics=true`。
- 校验版本与 config hash 固化到 Outcome。

无关 verified Claim 会被拒绝。
