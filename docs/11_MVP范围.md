# GEO产业引擎 — MVP开发范围

## 开发原则

- 不要一次开发全部功能，按照优先级推进
- 先设计文档，再写代码
- 所有模块服务商业闭环
- 所有数据可沉淀、所有功能考虑Agent调用

## 优先级定义

| 等级 | 定义 | 交付标准 |
|------|------|---------|
| P0 | 必须完成，不可跳过 | 可上线使用 |
| P1 | 核心差异化功能 | 可展示核心价值 |
| P2 | 增强型功能 | 提升用户体验 |
| P3 | 平台扩展功能 | 构建网络效应 |
| P4 | 智能自动化 | 提升效率 |
| P5 | 长期进化 | 持续迭代 |
