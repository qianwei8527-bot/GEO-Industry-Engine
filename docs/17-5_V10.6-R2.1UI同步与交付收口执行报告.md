## 5. 设计状态与实施状态的区别

- 设计状态表示设计稿是否冻结或规划。
- 实施状态表示真实代码是否实现并验证。
- 预览页面同时展示两者，避免把“已设计”误认为“已实现”。

## 6. 已知限制

- 设计预览为脱机 Mock，不代表真实接口可用性。
- 平台运营后台、治理审计台、客户协作端等页面仍以规划/部分实现为主。
- 本地 Redis 未运行；限流在生产环境启用 Redis 后才使用原子窗口。
- 公网部署前仍需处理 Origin/CSRF、访问日志 Token 脱敏、资料保留与删除策略。
