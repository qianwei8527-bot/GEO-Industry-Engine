# 恒域世界 UI 同步协议

> 任务编号：V10.6-R2.1-UI-DELIVERY-CLOSEOUT
> 目的：让每一轮任务都同步更新设计预览，避免设计与实现脱节。

## 1. 固定入口

设计预览主文件：`docs/v106-all-pages-design-preview.html`

每轮任务结束后必须同步更新该文件，不能只更新代码。

Web 访问地址：`/v106-all-pages-design-preview.html`

该地址由 Next 路由 `frontend/src/app/v106-all-pages-design-preview/route.ts` 从唯一真相源只读返回，不向 `frontend/public` 复制第二份完整文件。

## 2. 页面登记元数据

每个页面必须登记：

```text
taskId
release
designStatus
implementationStatus
dataMode
realRoute
featureFlag
lastUpdated
```

枚举：

- `designStatus`: planned / designed / frozen
- `implementationStatus`: not-started / partial / implemented / verified
- `dataMode`: mock / fixture / real

页面必须能明确区分“已经设计”和“已经实现”。

## 3. Mock 状态要求

设计预览中的所有数据均为 Mock 或 fixture：

- 不得标注“真实数据”“真实项目”“真实运行记录”“全部来自真实 API”。
- 未实现页面显示“规划中 / 未实现 / Feature Flag：hidden/reserved”。
- 中台和技术底座页面标记“内部架构设计视图”。
- 状态切换只操作本地 Mock 数据，不调用真实接口，不写入数据库。

## 4. 每轮更新步骤

1. 修改 `docs/v106-all-pages-design-preview.html`。
2. 为本轮受影响页面新增或更新 `PAGE_META`。
3. 为本轮受影响页面补充状态 Mock 数据。
4. 运行 `scripts/check-v106-preview.mjs`。
5. 更新执行报告中的设计状态与实施状态。
6. 将预览文件、检查脚本和报告纳入交付 ZIP。

## 5. 禁止事项

- 不得把 Mock 数据作为真实接口失败后的兜底数据。
- 不得在预览中展示 Token、API Key、客户隐私或 `.env` 内容。
- 不得删除 36 个主页面中的整体产品轮廓。
