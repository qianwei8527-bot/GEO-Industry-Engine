## 1. 修改内容

### 1.1 R2 状态机强制化

在 `backend/app/services/intake_service.py` 建立 `IntakeStateTransitionError`，所有客户与定位状态跳转统一收口：

```text
awaiting_review -> under_review
under_review -> needs_supplement / profile_confirmed
needs_supplement -> under_review / profile_confirmed
profile_confirmed -> positioning_draft
positioning_draft -> positioning_confirmed
positioning_confirmed -> project_created
project_created 为 R2 终态
```

非法跳转统一返回 HTTP 409，错误正文为 `invalid_state_transition`，不允许反向、跳步或终态修改。

### 1.2 权限与对象存在性

`backend/app/api/v1/intakes.py` 统一错误映射：

- `PermissionError` 与不存在对象统一返回 HTTP 404 `resource not found`，不泄露对象是否存在。
- 非法状态跳转返回 HTTP 409。
- 无效或过期 Token 返回原 Token 错误；文件过大返回 413。

新增 API 级跨 Realm 测试，覆盖工作台读取、开始审核、修改档案、确认档案、请求补充、生成定位、确认定位、创建项目 8 个端点。无权限对象与不存在对象返回相同的 404 正文。

### 1.3 项目创建并发幂等

`backend/app/services/geo_project_service.py::create_project_from_positioning` 增加无迁移幂等保护：

- 先执行 Realm 控制权限校验。
- 使用 `pg_advisory_xact_lock(hashtext('positioning_project:{intake_id}'))` 串行化同一 Intake 的触发。
- 使用确定性 `project_code = uuid5("positioning:{intake_id}")`。
- 唯一键冲突时回滚并返回已有项目。
- 并发双请求测试断言最终只有一个 GeoProject 且两个调用返回同一项目 ID。

### 1.4 唯一 UI 设计预览真相源

- 删除 `frontend/public/v106-all-pages-design-preview.html` 与 `frontend/public/v106-all-pages-design-preview-offline.html` 旧副本。
- 唯一真相源固定为 `docs/v106-all-pages-design-preview.html`。
- 新增 Next 只读路由 `/v106-all-pages-design-preview.html`，从唯一真相源返回页面，不复制第二份完整文件。
- 修正 `frontend/public/v106-all-links.html` 与 `docs/18-3_页面整合清单.md` 的失效公开路由引用。

### 1.5 脚本去绝对路径

`frontend/scripts/*.mjs` 不再包含用户目录或 Chrome 绝对路径：

- `PLAYWRIGHT_PATH` 指向 Playwright 入口。
- `CHROME_PATH` 指向浏览器可执行文件。
- 缺少环境变量时脚本明确报错，不做静默降级。

### 1.6 预览检查强化

`frontend/scripts/check-v106-preview.mjs` 已包含：

- 校验设计状态、实施状态、数据模式、Feature Flag 枚举。
- 校验客户与定位 7 种 Mock 状态切换。
- 扫描 ZIP 内 HTML，禁止残留旧术语和误导性文字。
- 窄屏无横向溢出检查。
