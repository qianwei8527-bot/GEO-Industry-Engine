# 合规与风险规范

> 批量调用LLM API的边界在哪里？爬虫合规吗？用户数据怎么保护？

---

## 一、LLM API调用合规

### 1.1 各模型服务条款

| 模型 | API调用 | 网页搜索 | 数据使用限制 | 备注 |
|------|---------|---------|------------|------|
| ChatGPT (OpenAI) | 允许（付费API） | 允许（SearchGPT） | 不得用于训练竞争模型 | 合规调用方式 |
| Gemini (Google) | 允许（Gemini API） | 允许（Google搜索） | 标准TOS限制 | 注意频率限制 |
| Claude (Anthropic) | 允许（API） | 有限 | 标准TOS | 注意成本 |
| Perplexity | 允许（API） | 产品核心功能 | 商业API需付费 | 有专门的企业API |
| DeepSeek | 允许（API） | 允许 | 开放 | 成本较低 |
| 通义千问 | 允许（API） | 允许 | 国内合规 | 国内合规 |

**核心原则**：使用官方API，遵守频率限制，不逆向工程，不用于训练竞争模型。

### 1.2 合规调用规范

| 规范 | 说明 |
|------|------|
| 使用官方API | 不使用非官方接口、反向代理 |
| 遵守频率限制 | 各API都有Rate Limit，遵守之 |
| 标识来源 | 调用时使用合法User-Agent |
| 不逆向工程 | 不尝试分析模型内部参数 |
| 数据隔离 | API返回数据不用于训练竞争AI产品 |

## 二、网络爬虫合规

### 2.1 爬虫基本原则

| 原则 | 说明 |
|------|------|
| 遵守robots.txt | 爬取前检查目标网站的robots.txt |
| 频率控制 | 请求间隔>=1秒，避免对源站造成压力 |
| 来源标识 | User-Agent明确标识爬虫身份 |
| 数据使用 | 不爬取受版权保护的全文内容 |
| 选择性爬取 | 只爬取企业公开信息，不爬取个人隐私 |

### 2.2 合规风险矩阵

| 数据源 | 风险等级 | 合规措施 |
|--------|---------|---------|
| 企业官网 | 低 | 公开信息，遵守robots.txt |
| 百科类(Wikipedia/百度) | 低 | 开放数据，遵守API限额 |
| 新闻网站 | 中 | 只爬取摘要，不爬全文 |
| 招聘网站 | 中 | 遵守TOS，控制频率 |
| 行业报告 | 中-高 | 购买正版，不爬取付费内容 |
| 社交媒体 | 中-高 | 只使用官方API |

## 三、数据隐私与保护

### 3.1 法律合规

| 法律 | 适用地域 | 核心要求 |
|------|---------|---------|
| 《个人信息保护法》(PIPL) | 中国 | 用户数据收集需告知、同意，可删除 |
| GDPR | 欧盟 | 数据可删除、可导出，用户明确同意 |
| CCPA | 加州 | 用户有权删除数据 |
| 一般隐私法 | 其他 | 行业最佳实践 |

### 3.2 数据分类与保护

| 数据类别 | 示例 | 保护级别 | 措施 |
|---------|------|---------|------|
| 企业公开数据 | 企业名称、官网 | L0 | 无特殊保护 |
| 企业注册信息 | 联系人、电话 | L1 | 加密存储，内部访问 |
| 用户个人信息 | 姓名、邮箱 | L2 | 加密存储，最小权限 |
| 认证材料 | 营业执照照片 | L3 | 加密存储，审计日志 |

### 3.3 数据留存策略

| 数据类型 | 留存期限 | 删除方式 |
|---------|---------|---------|
| 企业公开信息 | 持续保留 | 企业申请删除 |
| 用户账户数据 | 账户存续期间 | 用户可主动注销删除 |
| 认证材料 | 认证有效期+1年 | 到期自动匿名化 |
| AI查询结果 | 永久（匿名化后）| 不可逆匿名化 |
| 日志数据 | 180天 | 自动滚动删除 |
