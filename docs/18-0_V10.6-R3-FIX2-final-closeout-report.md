## 1. 来源选择修复

- 前端默认选择实际存在的 `platform-seed-blank`。
- 前端按所选 source 对象发送真实 `source_type`，不再硬编码 `platform_seed`。
- 后端要求请求 `source_type` 等于登记 `source_type`，否则返回 `source_type/source_id mismatch`。
- 生成成功提示按来源名称动态显示，不再固定为“平台通用模板”。

## 2. 工作流归属

- `realm_template` 因现有结构无法保存真实 Realm 归属，已从运行入口移除。
- 当前仅保留：`platform_seed` 空白结构 + `owner_defined` 域主提交。
- `owner_defined` 记录 `submitted_by`、`provenance`、`owner_confirmed`，不再把当前操作人写入计划 owner 冒充模板所有者。
- 后端对来源类型、来源 ID 严格校验；跨 Realm 模板不可展示、读取或使用。

## 3. 状态与进度

进度规则：

```text
planned = 0%
in_progress / blocked = 0-99%
completed = 100%
```

- 后端在草稿校验和任务更新时强制执行；进度变化会自动执行合法状态转换或拒绝。
- 前端真实使用 `taskCanTransition`、`taskStatusOptions`、`planCanUpdateTask`。
- 已完成任务与 `plan_completed` 的控件全部禁用。

## 4. 日期修复

- 非空但无法解析的日期返回 400。
- 所有日期统一为带时区 `datetime`；无时区输入按 UTC 归一化。
- 覆盖非法字符串、无时区/有时区混用和日期顺序。
