# V10-P0 实施与验收报告

> 恒域世界 V10-P0：架构归位与首条真实 GEO 域主价值闭环
> 日期：2026-08-03 | 分支：`agent/c6-reality-runtime`

## 1. 当前系统中“域”实际由哪些旧模型承载？

`entities` + `companies` 承载实体事实，`node_memberships` 承载人员权限，新增 `realm_registry` 承载域生命周期、认领状态与所有者。

## 2. 哪些旧能力被直接复用？

User、NodeMembership、AuditLog、Evidence、EvidenceClaim、Relationship、DemandEvent、ConnectionCandidate、Trust Foundation、World Projection/State、AgentCallLog、原有前端页面。

## 3. 新增了哪些模型、字段、服务、API、页面和配置？

- 模型：RealmRegistry、RealmClaim、RealmDataAuthorization、RealmDataAsset、Brand、Product、GeoProject、ProjectWorkItem、ProjectArtifact、ToolExecutionRecord、ProjectOutcome。
- 服务：`realm_service.py`、`geo_project_service.py`。
- API：`/api/v1/realm/*`、`/api/v1/geo-projects/*`。
- 页面：`/realm` 域主工作台；登录/注册改为真实后端对接。
- 配置：`config/universe/realm_governance.yaml`、`config/universe/geo_project.yaml`，均含 schema/version/config_hash。

## 4. 是否新增数据库表？为什么不能复用旧表？

是，共 11 张通用表。旧系统没有域认领、数据授权、GEO 项目、工具执行、项目产物、结果的可审计通用结构；直接往旧表塞这些状态会破坏 C6-C8 冻结边界。

## 5. 域主现在可以实际完成什么？

注册登录、创建/认领企业域和品牌域、建立域关系、授权自有数据、登记资产、导入 observed Evidence、创建 GEO 项目、记录工作项、工具执行、产物、结果，并查看成长时间线与资产清单。

## 6. 域主自己的数据如何授权和隔离？

通过 `realm_data_authorizations` 声明来源、所有者、使用范围、有效期、truth_status 与是否进入真实指标；synthetic 与 observed 默认隔离，`may_affect_real_metrics` 默认 false。

## 7. AI、Agent 和 Skill 调用如何审计？

通过 `tool_execution_records` 固化 provider、tool/model/version、输入输出 manifest、源事实、配置版本与哈希、成本、执行状态和引用。

## 8. 项目产物如何沉淀到品牌域？

`project_artifacts` 关联项目和 Realm；`realm_data_assets` 可关联项目，域工作台同时展示项目产物与品牌域资产。

## 9. 项目结果如何进入 EvidenceClaim？

`project_outcomes.evidence_claim_id` 挂接结构化 EvidenceClaim；只有 claim 已 verified 时 Outcome 才投影为 verified。

## 10. 是否存在绕过 Trust Foundation 的路径？

未发现。新增写操作不触发 Reputation 或 Law Mutation；Outcome 只反射 EvidenceClaim 状态。

## 11. synthetic/observed 是否可能进入生产指标？

不能。域主只能提交 observed/synthetic，`may_affect_real_metrics` 默认 false；Connection Candidate 的 C7.4-R 状态机继续隔离 synthetic。

## 12. 原有回归测试结果是什么？

后端全量回归：**255 passed**。

## 13. 新增定向测试结果是什么？

## 14. API 和前端冒烟结果是什么？

API 冒烟完整闭环通过：注册、企业域、授权、资产、证据、关系、GEO 项目、工作项、工具执行、产物、结果、时间线、资产清单均成功，测试数据已清理。前端 `next build` 通过，45 条路由存在；`/realm`、`/login`、`/universe/home` 冒烟返回 200。

## 15. 还缺什么才能接入第一个真实 GEO 域主？
