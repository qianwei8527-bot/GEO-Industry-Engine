## 一、服务架构

```
Frontend (Next.js)
    │ REST API / WebSocket

    │ Auth · Rate Limit · Router · Cache
    ┌──────────┬──────────┬──────────┬──────────┐
    ▼          ▼          ▼          ▼          ▼
Company   Industry   GEO       Knowledge   Marketplace
Service   Service    Score      Graph       Service
                     Service    Service
    └──────────┬──────────┘          │
               ▼                     │
         Agent Runtime               │
    ┌────┬────┬────┬────┬───┐        │
    │CEO │CTO │Prod│Ind │Scan│        │
    │Cont│Data│Mkt │Sales│QA  │        │
    └────┴────┴────┴────┴───┘        │
               │                     │
    ┌──────────┴──────────┬──────────┘
    ▼                     ▼
PostgreSQL            Neo4j / Vector DB / ES
(主数据)               (知识图谱/语义搜索)
```

## 三、核心业务流程

### 3.1 企业GEO检测流程
```
企业注册 → 完善资料 → 触发GEO扫描
    → Scanner Agent 扫描AI平台
    → GeoScore Service 计算评分
    → 生成检测报告
    → 存入历史记录（三线数据源）
```

### 3.2 产业地图更新流程
```
数据采集（爬虫/API/用户提交）
    → AI初筛 → 人工/社区审核
    → 更新 Industry + Sector + Company
    → 刷新 Neo4j 知识图谱
    → 通知关注者
```

### 3.3 三线预测流程
```
读取 GeoScore 历史记录
    → Prophet 拟合趋势模型
    → 生成预测线 + 置信区间
    → 实时数据流入 → 校准预测
    → 前端 ThreeLineChart 渲染
```

### 3.4 认证评估流程
```
用户提交认证申请
    → AI初审（自动）
    → 人工复审（L3-L4必须）
    → 公示期（社区反馈）
    → 社区投票（L2以上）
    → 颁发认证
    → 定期复审
```

## 四、数据访问层

| 数据库 | 访问方式 | 服务使用方 |
|--------|---------|-----------|
| PostgreSQL | SQLAlchemy (async) | Company/Industry/GEO Score/Marketplace/Certification |
| Neo4j | neo4j-driver | Knowledge Graph |
| Vector DB | chromadb/milvus SDK | Knowledge Graph (semantic search) |
| ElasticSearch | elasticsearch-py | Knowledge Graph (full-text) |
| Redis | redis-py | Cache/Queue/Session |

## 五、权限设计

| 角色 | 数据范围 | 操作权限 |
|------|---------|---------|
| 普通用户 | 个人+公开企业 | 浏览、评论、个人认证 |
| 企业用户 | 本企业+公开数据 | 企业信息管理、GEO检测、交易 |
| 服务商 | 本企业+客户授权 | 服务上架、项目管理 |
| 审核员 | 待审核数据 | 审核操作 |
| 管理员 | 全部 | 全权限 |

## 六、Agent集成方式

| 集成方式 | 说明 | 实现 |
|---------|------|------|
| Function Calling | Agent 通过函数调用触发服务 | 每个服务提供 tool 定义 |
| 事件驱动 | Agent 监听业务事件 | 消息队列 |
| 定时触发 | Agent 按计划执行 | Cron + Celery |
