## 一、统一 API 约定

### 1.1 基础信息

| 项目 | 约定 |
|------|------|
| 基础路径 | `/api/v1/` |
| 认证方式 | `Authorization: Bearer <JWT>` |
| Content-Type | `application/json` |
| 字符编码 | UTF-8 |
| 版本策略 | URL 路径版本化（/v1/, /v2/） |

### 1.2 统一响应格式

```json
{
  "success": true,
  "data": {},
  "error": null,
  "meta": {
    "page": 1,
    "page_size": 20,
    "total": 247,
    "total_pages": 13
  }
}
```

错误响应：
```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "ENTITY_NOT_FOUND",
    "message": "企业不存在",
    "detail": "id=xxx 在数据库中未找到"
  },
  "meta": null
}
```

### 1.3 统一错误码

| HTTP状态码 | 错误码 | 含义 | 触发场景 |
|-----------|--------|------|---------|
| 400 | `VALIDATION_ERROR` | 请求参数校验失败 | 缺少必填字段、类型错误 |
| 401 | `UNAUTHORIZED` | 未认证 | Token缺失或过期 |
| 403 | `FORBIDDEN` | 无权限 | 角色/套餐权限不足 |
| 404 | `ENTITY_NOT_FOUND` | 实体不存在 | 查询的ID无效 |
| 404 | `RESOURCE_NOT_FOUND` | 资源不存在 | 端点路径无效 |
| 409 | `CONFLICT` | 资源冲突 | 重复申请认证、重复注册 |
| 422 | `BUSINESS_RULE_VIOLATION` | 业务规则冲突 | 认证等级不足、配额用完 |
| 429 | `RATE_LIMITED` | 请求频率限制 | 超过 Rate Limit |
| 500 | `INTERNAL_ERROR` | 服务器内部错误 | 未预期异常 |
| 503 | `SERVICE_UNAVAILABLE` | 服务不可用 | Decision Engine 离线 |

### 1.4 分页约定

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | integer | 1 | 页码，从1开始 |
| `page_size` | integer | 20 | 每页条数，最大100 |
| `sort_by` | string | `created_at` | 排序字段 |
| `sort_order` | string | `desc` | `asc` 或 `desc` |

列表响应统一包含 `meta: { page, page_size, total, total_pages }`。

### 1.5 过滤约定

| 参数 | 类型 | 说明 |
|------|------|------|
| `q` | string | 全文搜索关键词 |
| `industry_id` | string | 行业筛选 |
| `region` | string | 地区筛选 |
| `certification_level` | string | 认证等级筛选(L0-L4) |
| `entity_type` | string | 实体类型筛选 |
| `date_from` / `date_to` | ISO date | 时间范围 |
