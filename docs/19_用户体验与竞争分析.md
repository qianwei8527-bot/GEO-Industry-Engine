## 一、用户体验原则

### 1.1 核心设计原则

| 原则 | 描述 | 体现 |
|------|------|------|
| 认知闭合 | 用户进入后必须能找到答案 | 检测中心四层报告闭环 |
| 渐进披露 | 先简后繁，按需深入 | 快速检测(30s)->完整报告->深度分析 |
| 角色适配 | 不同角色看到不同首页 | 7角色差异化首页 |
| 数据可视化 | 评分/排名用图表而非数字 | 雷达图/趋势线/热力图 |
| 行动导向 | 每个页面都有下一步 | 报告底部推荐动作 |

### 1.2 用户旅程

企业用户典型旅程: 首页搜索(30s) -> 简版身份卡(10s) -> 完整报告(2min) -> 补充数据(5min) -> 申请认证(3min) -> 持续追踪(每周)

个人用户典型旅程: 首页选择"个人" -> 能力自评(2min) -> 职业路径推荐(1min) -> 认证申请(3min) -> 交易市场展示

## 二、产业情报

### 2.1 竞品分类

| 类别 | 代表 | 我们的差异 |
|------|------|-----------|
| SEO工具 | Ahrefs/SEMrush | 他们做传统SEO，我们做AI搜索GEO |
| 企业数据库 | 天眼查/企查查 | 他们做企业信息，我们做产业生态+智能评估 |
| AI评分工具 | 各类AI排名网站 | 他们做一次性评分，我们做持续追踪+认证 |
| 行业地图 | IT桔子/36氪 | 他们做信息聚合，我们做GEO专用产业数字孪生 |
| 认证平台 | ISO/等保 | 他们做通用认证，我们做GEO专用认证 |
| B2B平台 | 猪八戒/Upwork | 他们做泛服务交易，我们做GEO服务精准匹配 |

### 2.2 差异化优势

| 维度 | 竞品 | GEO-Industry-Engine |
|------|------|-------------------|
| 定位 | 工具/平台 | 产业基础设施 |
| 数据 | 单一维度 | 多维知识图谱 |
| 智能 | 规则/统计 | Context+Decision+Agent |
| 信任 | 无/简单认证 | L0-L4多级认证 |
| 生态 | 封闭 | 开放API+MCP+开发者 |
| 持续 | 一次性 | 持续追踪+飞轮 |

### 2.3 竞争壁垒

- 产业知识图谱 (数据积累 -> 越来越准确)
- 认证体系 (信任网络 -> 迁移成本高)
- 配置化引擎 (可复制到不同行业)
- 决策反馈闭环 (使用越多越智能)
