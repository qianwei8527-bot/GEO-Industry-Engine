# GEO Universe V6 能力地图

> 不是功能列表。不是页面清单。是 Universe 的能力层定义。
> 这份文档桥接第一性原理与 V6 产品架构：它回答 Universe 有什么能力，而不是这些能力对应哪个页面。

---

## 第零章：能力层架构

V6 的能力不是平铺的，而是三层递进：

```
                 GEO Universe
                      |
        --------------------------------
        |              |               |
   世界认知层       智能增长层        价值连接层
   (Perception)    (Growth)        (Connection)
        |              |               |
   Universe Core   AI Engine       Ecosystem
```

三层对应第一性原理的三个命题：
- 世界认知层 -> Position（我在哪里）
- 智能增长层 -> Growth（如何提升）
- 价值连接层 -> Connection（和谁一起）

---

## 第一层：世界认知层（Perception Layer）

### 定位
让每一个进入 Universe 的存在，第一秒就照见自己。

### 包含的能力

#### 1.1 Universe Views（宇宙视图）—— 空间认知能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 产业导航 | Universe Views | 五个观察角度联动查看整个产业宇宙 |
| 五张地图 | Five Camera Views | 不是五个页面，是一个 Universe 的五面镜子 |

能力说明：不是导航菜单。是用户认识世界的空间入口。Ecosystem View 看关系，Business View 看价值，Growth View 看路径，Distribution View 看分布，Future View 看趋势。

#### 1.2 Position Engine（定位引擎）—— 自我认知能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 检测中心 | Position Engine | 输入一个存在，输出它在 Universe 中的精确位置 |

能力说明：不是评分工具。是回答第一性原理的 Position 命题。输入可以是企业、个人、产品、服务商——任何有产业身份的存在。输出包含：你是谁、你在哪个赛道、你的阶段、你的竞争位置、你的成长路线。

Position Engine 的工作流：
```
输入（实体标识）-> 搜索 Universe -> 定位节点 -> 
  返回：空间坐标 + 能力坐标 + 竞争坐标 + 时间坐标 + 信誉坐标
```

#### 1.3 Identity Center（身份中心）—— 身份认知能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| (新增) | Identity Center | 用户进入 Universe 时选择身份，系统按身份展开不同的宇宙视角 |

能力说明：这是 V6 新增的核心入口。不是传统用户中心。而是 Universe 的 我是谁 问题。进入 Universe 的第一步不是搜索，是选择身份——企业、服务商、个人、投资者、政府、AI Agent。然后 Universe 以你的身份为中心重新展开。

### 第一层的用户感知链

身份选择 -> 空间定位 -> 自我认知 -> 我知道我在哪了。

---

## 第二层：智能增长层（Growth Layer）

### 定位
让每一个存在知道自己下一步该做什么，并且每一步都可验证。

### 包含的能力

#### 2.1 Universe Memory（宇宙记忆）—— 时间深度能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 数据资产中心 | Universe Memory | 持续记录每一个节点的历史变化，形成可回放的产业记忆 |

能力说明：这是和 AI 最大的区别。AI 回答一次。Universe 记住。企业的成立、新增能力、认证、关系变化、信誉积累——全部记录在 Memory 中。这是长期资产。时间维度是 Universe 护城河公式的第四个因子。

#### 2.2 Growth Engine（成长引擎）—— 路径规划能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 学习成长 + 产业情报 | Growth Engine | 基于 Position 数据，生成可执行的成长路径 |

能力说明：不是课程推荐。是产业成长。从 Gap Analysis 到 Action Roadmap 到 Progress Tracking。Growth Engine 必须包含：起点（当前 Position）、终点（目标 Position）、路径（分阶段的行动计划）、验证（每阶段完成后的 Position 变化检查）。

#### 2.3 AI Decision Engine（智能决策层）—— 认知增强能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| Agent OS + Decision Engine | AI Decision Engine | Universe 的决策支持层，不替代人的判断，但提供所有决策所需的事实和推理 |

能力说明：AI 不创造事实。AI 加速理解。Context Engine 理解实体，Decision Engine 生成判断，Agent 解释判断。三者形成 AI Decision Pipeline，但每一步的输出必须引用 Universe Rules 和 Evidence。

#### 2.4 Reputation Layer（信誉层）—— 信任基础设施

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 认证中心 | Reputation Layer | Universe 的信任系统，基于证据、时间和网络共识 |

能力说明：AI 时代的核心问题不是信息，是信任。Reputation Layer 负责：认证（第三方验证）、背书（同行认可）、时间衰减（不是一劳永逸）、证据链（每一个信誉分数都可追溯）。它不是业务模块，是基础设施。

### 第二层的用户感知链

了解位置 -> 看到差距 -> 获得路径 -> 执行成长 -> 验证结果 -> 位置更新。

---

## 第三层：价值连接层（Connection Layer）

### 定位
让每一个存在找到对的伙伴，产生真实的商业价值。

### 包含的能力

#### 3.1 Connection Network（连接网络）—— 关系匹配能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| 交易市场 / Marketplace | Connection Network | 不是买卖撮合，是产业价值连接的发现和匹配系统 |

能力说明：Connection 不仅仅是交易。包括：需求发现、能力匹配、人才连接、资本连接、技术合作、服务对接。交易只是其中一种结果。Platform 不替用户选择，只提供基于证据的可信候选集。

#### 3.2 Ecosystem（生态）—— 网络效应能力

| 旧名 | 新名 | 能力定义 |
|------|------|---------|
| (隐性的) | Ecosystem Engine | 每增加一个节点，全网价值自动提升 |

能力说明：这不是一个显性功能。它是 Universe 的底层机制。当一个企业加入、一个服务商认证、一笔交易完成——Ecosystem Engine 自动重新计算全网的中心度、密度、信誉基准。用户看不到它，但能感受到 越用越聪明。

### 第三层的用户感知链

发现候选 -> 比较证据 -> 自主选择 -> 发起连接 -> 产生价值 -> 数据回流。

## 第五章：V6 不做什么

### 不废弃旧模块
旧模块不是错的。它们被放在了错误的层级（平级产品模块）。V6 把它们重新定位为 Universe 三层能力体系中的能力入口。

### 不新增没有 Universe 连接的独立功能
任何一个新能力必须满足：它可以被归入三层中的某一层，并且增强该层的 Position/Growth/Connection 命题。

### 不把页面当能力
一个页面不等于一个能力。Multiple 页面可以服务于同一个能力。同一个能力可以在多个页面中体现。能力地图定义 what，产品架构定义 how。
