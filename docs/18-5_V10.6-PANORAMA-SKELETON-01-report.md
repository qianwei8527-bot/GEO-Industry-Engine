## 2. 统一 Shell 与页面模板

- 新增真实路由 `/panorama`，使用统一 `AppShell`，不建立第二套 Shell。
- `PanoramaExplorer` 复用六类页面模板：workbench / list / detail / config / management / canvas。

- 全局 Header 对 `/panorama` 隐藏，避免 390px 横向溢出。
