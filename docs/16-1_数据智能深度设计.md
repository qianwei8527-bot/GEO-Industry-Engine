## 一、数据智能架构

```
原始数据层
  Entity / Event / Evidence / Relationship
      |
数据加工层
  清洗 -> 标准化 -> EntityResolution -> 去重 -> 关联
      |
特征工程层
  Entity特征 / 时序特征 / 关系特征 / 行业特征
      |
模型计算层
  Context Engine (理解) -> Decision Engine (决策) -> Agent (执行)
      |
输出层
  Score / Ranking / Recommendation / Alert / Report
```

## 二、特征工程

### 2.1 实体特征

| 特征类 | 特征 | 类型 | 来源 |
|--------|------|------|------|
| 身份特征 | entity_type, industry, region | 类别 | Entity |
| 规模特征 | employee_count, revenue_range | 数值/区间 | Company |
| 能力特征 | capability_count, capability_depth | 数值 | Capability |
| 关系特征 | relationship_count, network_centrality | 数值 | Relationship |

### 2.2 时序特征

| 特征 | 窗口 | 计算方式 |
|------|------|---------|
| 可见度变化率 | 30/90/180天 | (now - then) / then |
| 事件活跃度 | 30天 | event_count |
| 认证演进 | 全历史 | level_transitions |
| 内容产出趋势 | 90天 | 线性回归斜率 |

### 2.3 关系特征

| 特征 | 描述 |
|------|------|
| 入度 | 被多少实体关联 |
| 出度 | 关联多少实体 |
| 中介中心度 | 在关系网络中的桥接程度 |
| 关系多样性 | 关联类型数量 |
| 伙伴质量 | 关联实体的平均GEO Score |

## 三、智能能力

### 3.1 实体解析 (Entity Resolution)

- 同一企业在不同平台的名称统一
- 模糊匹配: Levenshtein距离 + 行业+地区约束
- 人工确认: AI自动匹配 + 人工审核边角案例

### 3.2 异常检测

| 检测类型 | 方法 | 应用 |
|---------|------|------|
| 评分异常 | Z-Score > 3 | 防作弊/数据质量告警 |
| 行为异常 | Isolation Forest | 刷分检测 |
| 数据异常 | 缺失率突增 | 数据源健康告警 |

### 3.3 趋势预测

| 预测目标 | 方法 | 时间窗口 |
|---------|------|:------:|
| GEO Score | ARIMA/Prophet | 3/6/12个月 |
| 行业增长 | 多元回归 | 6/12个月 |
| 认证升级概率 | 逻辑回归 | 6/12个月 |

### 3.4 智能推荐

| 推荐类型 | 方法 | 输出 |
|---------|------|------|
| 能力补充推荐 | 协同过滤 | "和你类似的企业补充了X能力" |
| 认证路径推荐 | 规则+相似度 | "建议L1->L2->L3, 预计6个月" |
| 服务商推荐 | 能力匹配+评价 | "适合你的3个服务商" |
| 机会推荐 | Opportunity Score | "你所在行业的3个黄金机会" |
