﻿# GEO产业引擎 — 产品架构PRD

## 一、AI可见度增长系统

企业级AI搜索可见性分析与优化平台。

| 模块 | 描述 |
|------|------|
| **企业AI检测** | 自动识别企业在各大AI搜索平台的提及与表现 |
| **GEO评分** | 多维度评分模型，量化企业/个人/产品的AI可见度（0-100分） |
| **AI曝光分析** | 品牌、产品、关键词在AI回答中的出现频率与上下文分析 |
| **内容优化** | AI驱动的GEO内容策略建议，优化Prompt覆盖 |
| **增长建议** | 基于数据的企业/个人增长路线图 |
| **持续监测** | 实时监控AI搜索表现变化，自动告警 |
| **趋势预测** | 基于历史数据自动生成GEO评分/曝光量的预测趋势线 |
| **竞争对标** | 与竞争对手的AI可见度对比分析，支持多企业对比，展示差距与提升机会，自动生成竞争策略建议 |
| **ROI计算器** | 量化GEO评分提升带来的AI曝光增量、流量预估、商业价值换算，支持情景模拟 |
| **一键优化** | 基于分析结果自动生成优化方案，确认后一键部署内容调整，支持定时执行，支持历史线/实际线/预测线三线对比 |

### 用户角色
- **企业市场团队** — 日常监测与优化
- **个人从业者** — 个人品牌AI可见度管理
- **GEO服务商** — 为客户提供优化服务
- **投资机构** — 行业趋势与标的分析

- **找到自己的位置** — 在GEO产业生态中的坐标
- **发现商业价值** — 看到生态中的机会与空白
- **学习成长** — 获取行业知识、职业路径、技能地图
- **收集信息** — 产业动态、政策变化、技术演进
- **连接与参与** — 展示、连接、评论、讨论，真正参与其中

随GEO行业变化**自动更新**，保持与产业同步演进。

### AI模型智能库影响说明

AI模型智能库不是独立系统，而是GEO数据资产中心的核心智能子模块。它影响：

- **GEO评分引擎**：模型成为评分变量——不同模型的引用行为、来源偏好、行业倾向直接影响企业的GEO评分
- **Scanner Agent**：根据行业+目标企业+模型权重选择扫描策略（如医疗企业重点扫描Claude/ChatGPT/Perplexity）
- **Content Agent**：针对不同模型偏好生成差异化内容策略
- **产业导航地图**：模型-行业热度矩阵为地图提供"哪个行业在哪个模型最火"的数据层

内部架构：

```
GEO数据资产中心
├── 数据层：行业/企业/Prompt/回答/研究资料
└── 智能层：AI Model Intelligence
    ├── Model Profile（模型画像）
    ├── Model Behavior（行为模式）
    ├── Industry Preference（行业偏好）
    ├── Source Preference（来源偏好）
    ├── Query Result（查询结果）
    └── Ranking Signal（排名信号）
```

### 6.1 监控与建议系统

每张地图的每一层都内置监控与建议能力：

**监控维度**
- 节点变化监控：新增、删除、合并的产业节点

- 生态健康度监控：节点活跃度、连接密度、参与度

**建议输出**
- 定位建议：根据企业/个人的数据推荐其在生态中的最佳定位
- 机会发现：自动识别市场空白、新兴领域、商业机会
- 风险预警：产业衰退、竞争加剧、政策变化提醒
- 成长路径：基于当前位置的个性化发展建议

### 6.2 可扩展机制

每张地图的每一层都支持用户创建和添加新内容：

**新增方式**
- 用户提交：通过新增节点入口提交新产业类目、新商业机会、新地域
- AI建议：系统自动识别新兴趋势、建议新增节点
- 管理员导入：批量导入行业标准分类

**审核流程**
用户提交 -> AI初筛 -> 社区投票 -> 管理员确认 -> 正式上线
审核周期：AI初筛即时、社区投票1-7天、管理员确认24小时内

**版本管理**
- 地图版本号：每次新增/修改节点产生新版本
- 变更日志：所有变更可追溯
- 回滚机制：支持回滚到任意历史版本
- 用户通知：关注的节点发生变化时自动通知

**扩展性保证**
- 节点类型可扩展：不限制节点类型的数量
- 关系类型可扩展：支持自定义节点间关系
- 层级深度可扩展：支持无限层级嵌套
- 跨地图连接可扩展：节点可出现在多张地图中

| 人才 | 招聘发布、简历投递、项目合作 | 企业、个人 |

### 交易流程

`
发布/上架 → 分类展示 → 搜索/浏览 → 选择洽谈 → 交易执行 → 评价完成
`

- **推荐**：AI匹配推荐，但不过度——保留**搜索、分类浏览、筛选**等自主选择能力
- **交易模式**：一口价 / 按项目 / 按时间 / 按量
- **担保机制**：平台担保交易，保障双方权益

### 供给端入驻

| 主体类型 | 入驻条件 | 收费模式 |
|---------|---------|---------|
| 企业服务商 | 企业认证 + 资质审核 | 免费入驻，交易佣金 |
| 个人开发者 | 个人认证 + 产品上架 | 免费入驻，交易佣金 |
| 独立专家 | 专家认证 + 服务上架 | 免费入驻，交易佣金 |
| 数据提供商 | 企业认证 + 数据验证 | 免费入驻，数据分成 |

### 需求端功能

- 发布需求（描述、预算、期限、行业）
- 浏览市场（分类、搜索、筛选、标签）
- 收藏对比（加入对比列表）
- 项目管理（在线协作、里程碑跟踪）
- 评价体系（多维度评价、信用积分）

﻿## 四、认证与全民评估体系（全新设计）

> 这是一套融合内部提升、审核审查、全民参与的综合性评估系统。
> 核心理念：**不仅是认证，更是生态信任的基础设施。**

### 4.1 体系总览

三维评估模型驱动认证体系：

```
                  ┌─────────────────┐
                  │     认证等级     │
                  │   L0 ─→ L4      │
                  └────────┬────────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ 能力维度  │ │ 信用维度  │ │ 贡献维度  │
        │Capability│ │  Trust   │ │Contribute│
        │ 0-100分  │ │ 0-100分  │ │ 0-100分  │
        └──────────┘ └──────────┘ └──────────┘
              │            │            │
              ▼            ▼            ▼
        ┌─────────────────────────────────────┐
        │         全民参与评估体系              │
        │   同行评审 · 社区投票 · 用户评价       │
        └─────────────────────────────────────┘
```

### 4.2 三维评估模型

#### 能力维度（Capability Score 0-100）

衡量专业知识、实战能力和行业影响力。

| 评分项 | 权重 | 评估方式 | 数据来源 |
|--------|------|---------|---------|
| 专业知识 | 30% | 在线考核 + AI面试 | 考核系统 |
| 实战案例 | 35% | 案例评审 + 效果数据 | 案例库 + 客户评价 |
| 持续学习 | 15% | 课程完成度 + 新技能获取 | 学习系统 |
| 行业认知 | 20% | 行业分析报告 + 研究产出 | 内容系统 + AI评分 |

**提升方式**：完成课程 → 通过考核 → 提交实战案例 → 获得行业认可

#### 信用维度（Trust Score 0-100）

衡量交易诚信、内容真实性和社区行为。

| 评分项 | 权重 | 评估方式 |
|--------|------|---------|
| 交易履约率 | 40% | 完成的交易 / 全部交易 |
| 内容真实性 | 25% | AI检测 + 用户举报 + 人工抽查 |
| 社区行为 | 20% | 违规记录、友善度 |
| 身份验证 | 15% | 多维度实名认证 |

**提升方式**：按时完成交易 → 获得好评 → 持续活跃 → 多平台验证

**扣分规则**：
- 交易违约：-10分/次
- 虚假内容：-20分/次
- 恶意行为：-30分/次
- 严重违规：归零+封禁

#### 贡献维度（Contribution Score 0-100）

衡量对社区的贡献和生态建设参与度。

| 评分项 | 权重 | 获得方式 |
|--------|------|---------|
| 问答贡献 | 25% | 回答问题、被采纳、获得赞 |
| 数据贡献 | 20% | 提交产业数据、纠错、补充信息 |
| 内容创作 | 20% | 发布分析文章、案例、评测 |
| 评审参与 | 20% | 参与同行评审、社区投票 |
| 活动参与 | 15% | 参加沙龙、讲座、分享会 |

**提升方式**：持续贡献 → 获得社区认可 → 累积影响力

### 4.3 内部提升路径

#### 等级与晋升条件

| 等级 | 能力分 | 信用分 | 贡献分 | 额外条件 | 典型用户 |
|------|--------|--------|--------|---------|---------|
| L0 注册 | - | - | - | 邮箱/手机验证 | 新注册用户 |
| L1 入门 | ≥20 | ≥60 | ≥10 | 完成基础培训 | 普通浏览者 |
| L2 专业 | ≥50 | ≥70 | ≥50 | 提交1个实战案例 | 从业者、服务商 |
| L3 专家 | ≥75 | ≥85 | ≥150 | 同行评审通过 | 行业专家、KOL |
| L4 权威 | ≥90 | ≥95 | ≥300 | 社区推选+委员会批准 | 行业领袖、学者 |

#### 晋升流程

```
L0 ─→ L1：系统自动审核（即时）
        条件满足自动升级

L1 ─→ L2：AI初审 + 人工抽查（1-3天）
        提交案例 → AI评估 → 人工抽查20%

L2 ─→ L3：同行评审 + 专家委员会（7-14天）
        提交申请 → AI初审 → 3位同行评审 → 委员会终审

L3 ─→ L4：社区推选 + 全员公示（30天）
        社区提名 → 资格审核 → 30天公示 → 委员会确认
```

#### 降级机制

| 触发条件 | 降级幅度 | 恢复方式 |
|---------|---------|---------|
| 连续90天不活跃 | 降1级（L1以上） | 重新活跃30天后恢复 |
| 信用分跌破等级要求 | 降至对应等级 | 信用分恢复后自动回升 |
| 被证实违规 | 降1-3级 | 申诉后视情节恢复 |
| 严重违规 | 直接L0 | 重新从L0开始 |

### 4.4 审核审查体系

#### 三级审核机制

```
申请提交
    │
    ▼
┌──────────────────────────────┐
│ 第一级：AI自动初审（秒级）      │
│  ├─ 材料完整性检查             │
│  ├─ 格式合规性校验             │
│  ├─ 信息交叉验证               │
│  └─ 历史记录关联               │
│  通过率：约80%                 │
└──────────┬───────────────────┘
           │ 通过
           ▼
┌──────────────────────────────┐
│ 第二级：人工复审（1-3天）       │
│  ├─ AI高风险标记项人工核查     │
│  ├─ 材料真实性判断             │
│  └─ 综合能力评估               │
│  L1-L2：抽查20%               │
│  L3-L4：100%人工              │
└──────────┬───────────────────┘
           │ 通过
           ▼
┌──────────────────────────────┐
│ 第三级：公示期（3-7天）         │
│  ├─ 社区可查看申请材料和结果    │
│  ├─ 社区可提出异议             │
│  └─ 异议由更高级审核员处理     │
│  L1：公示3天                   │
│  L2：公示5天                   │
│  L3-L4：公示7天                │
└──────────┬───────────────────┘
           │ 无异议
           ▼
        颁发认证
```

#### 审核员体系

| 角色 | 资格要求 | 审核范围 | 激励 |
|------|---------|---------|------|
| 初级审核员 | L2+用户+培训考核通过 | L1认证审核 | 每次+2贡献分 |
| 高级审核员 | L3+用户+100次审核经验 | L2-L3认证审核 | 每次+5贡献分 |
| 专家审核员 | L4用户+委员会任命 | L3-L4认证审核 | 每次+10贡献分 |
| 审核仲裁员 | 平台任命 | 异议处理、申诉复审 | 固定津贴 |

**审核质量监控**：
- 每名审核员的审核准确率公开可查
- 审核员之间互审（10%抽查）
- 审核准确率低于80%暂停资格
- 持续低质审核取消审核员资格

#### 申诉与仲裁

| 申诉类型 | 处理流程 | 处理时间 |
|---------|---------|---------|
| 认证被拒 | 提交补充材料 → 高级审核员复审 | 3个工作日 |
| 降级处罚 | 提交申诉理由 → 仲裁委员会 | 7个工作日 |
| 封禁解封 | 提交申诉 → 安全团队审核 | 14个工作日 |
| 评价争议 | 双方举证 → 仲裁员裁定 | 5个工作日 |

### 4.5 全民参与评估体系

#### 评估参与方式

| 参与方式 | 适用场景 | 权重计算 |
|---------|---------|---------|
| 同行评审 | L3-L4认证申请评估 | 基础权重×评审员等级系数 |
| 社区投票 | L2认证、新产业节点审核 | 权重×（信用分/100） |
| 用户评价 | 交易完成后互评 | 实名评价权重×2 |
| 内容评分 | 社区内容质量评估 | 按贡献等级加权（L1:0.5, L2:1, L3:2, L4:3） |
| 推荐人背书 | 新用户申请认证 | 推荐人L3+才有效，权重×推荐人等级 |

#### 投票权重计算公式

```
最终权重 = 基础权重 × (信用分/100) × (1 + 等级系数)
        其中等级系数：L0=0, L1=0.2, L2=0.5, L3=1.0, L4=2.0
```

例如：一位L3用户（信用分85）参与L2认证投票
```
最终权重 = 1 × (85/100) × (1 + 1.0) = 1.7
```

#### 防作弊机制

| 作弊行为 | 检测方式 | 处罚 |
|---------|---------|------|
| 刷分/刷好评 | 频率异常检测+IP关联分析 | 分数归零+30天禁评 |
| 小号围攻 | 设备指纹+行为模式匹配 | 关联账号全部封禁 |
| 刷票/互投 | 社交图谱分析+时间序列异常 | 相关投票作废+降级 |
| 虚假资料 | AI交叉验证+人工复核 | 直接降级至L0 |
| 利益相关方互评 | 交易关系图谱分析 | 评价权重降低50% |

### 4.6 认证类型详解
