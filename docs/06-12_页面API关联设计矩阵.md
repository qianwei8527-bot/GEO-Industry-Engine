## 逐页详细设计

### 1. 首页 `/`

**定位:** GEO产业生态入口广场，六大系统导航 + 快速评估搜索

**数据需求:**
- 不需要后端数据(纯展示)

**API调用:**
- 搜索框提交→ `/detection` (前端路由跳转)
- 未来: 搜索框可调用 `POST /api/v1/agent/analyze` 做即时查询

**交叉导航 (出链):**
- `/detection` — 检测中心入口
- `/certification` — 认证中心入口
- `/navigation` — 产业导航入口
- `/assets` — 数据资产入口
- `/marketplace` — 交易市场入口
- `/intelligence` — 产业情报入口(新增建议)

**缺失:**
- 缺少产业情报卡片(六大系统只有五个)
- 飞轮视觉为纯文字，建议改为SVG交互图
- 无角色分流(CTO协议 §4.3要求)

**设计建议:**
```
首页搜索框 → 支持输入企业名称/个人名称/品牌
  → GET /api/v1/context/query?q=xxx → 返回匹配Entity列表
  → 用户选择 → 跳转 /detection/result?id=xxx
```

---

### 2. 检测中心 `/detection`

**定位:** GEO战略评估入口，用户提交搜索获取评估报告

**数据需求:**
- 需要调用 `api.context.query()` 获取搜索结果列表
- 需要调用 `api.entities.list()` 获取可用实体

**API调用 (待接入):**
```
GET /api/v1/entities/?entity_type=company     → 企业列表
POST /api/v1/context/query { query: "xxx" }   → 搜索匹配
POST /api/v1/decision/analyze { query: "xxx" }→ AI分析
```

**交叉导航:**
- `/detection/result` — 查看评估结果
- `/certification` — 去申请认证
- `/assets` — 补充企业数据
- `/navigation` — 查看产业位置

**当前状态:** 搜索框存在但submit直接跳转/detection，未实际调用API

---

### 3. 检测结果 `/detection/result`  ★最完整页面★

**定位:** GEO评估报告四层展示(身份/机会/风险/路线)

**已接入API:**
```
GET /api/v1/context/company/{id}   → 企业上下文(公司信息/行业/能力/关系/证据/评分/机会)
GET /api/v1/decision/company/{id}  → 决策评估(位置/增长/机会/风险)
```

**四层Tab设计:**
| Tab | 数据来源 | 展示内容 |
|-----|---------|---------|
| 身份与位置 | context.company + decision.position | GEO等级、行业排名、可见度、可信度 |
| 机会雷达 | context.opportunities + decision.opportunities | 增长机会、能力缺口、关键词空白 |
| 风险预警 | decision.risks | AI可见度下降、竞品变化、行业风险 |
| 行动路线 | decision.roadmap | 分阶段行动建议、优先事项 |

**交叉导航:**
- `/certification/apply` — 基于评估结果去认证
- `/assets` — 补充缺失的数据
- `/navigation` — 查看产业定位
- `/intelligence` — 查看相关风险/机会详情

**缺失:**
- 机会详情点击应跳转 `/intelligence/opportunities?entity_id=xxx`
- 风险详情点击应跳转 `/intelligence/risks?entity_id=xxx`
- 身份卡片应链接到 `/certification/passport/{id}`

---

### 4. 企业对比 `/detection/compare`

**定位:** 多家企业GEO表现对比

**API调用 (待接入):**
```
POST /api/v1/decision/analyze { task: "compare", entity_ids: [...] }
GET /api/v1/context/company/{id} (并发多个)
GET /api/v1/decision/company/{id} (并发多个)
```

**数据需求:**
- 选择2-5个Entity → 并发获取context+decision → 生成对比表格/雷达图

**交叉导航:**
- `/detection/result?id={id}` — 查看单个企业详情

---

### 5. 认证中心 `/certification`

**定位:** GEO产业生态可信身份证明体系

**API调用 (待接入):**
```
GET /api/v1/certification/levels          → 认证等级体系
GET /api/v1/certification/status/{id}     → 某实体认证状态
GET /api/v1/certification/review/pending  → (admin)待审核列表
```

**数据展示:**
- L0-L4 认证等级体系(从YAML: config/certification/levels.yaml)
- 认证对象分类(企业/个人/服务商/机构)
- 认证类型(身份/能力/贡献)

**交叉导航:**
- `/certification/apply` — 申请认证
- `/detection` — 查看当前状态
- `/assets` — 补充认证证据
