# GEO产业引擎 — 数据库ER设计

## 一、用户体系

```
users
├── id (UUID, PK)
├── email (UNIQUE)
├── password_hash
├── name
├── role (admin / enterprise / provider / expert)
├── avatar_url
├── phone
├── created_at
├── updated_at
├── last_login_at
└── status (active / disabled / deleted)

user_profiles
├── id (UUID, PK)
├── user_id (FK → users.id)
├── company_id (FK → companies.id, nullable)
├── bio
├── expertise_tags (JSON)
├── linkedin_url
├── website
└── preferences (JSON)

user_credentials (OAuth)
├── id (UUID, PK)
├── user_id (FK → users.id)
├── provider (github / google / wechat)
├── provider_id
└── access_token (encrypted)
```

## 二、企业体系

```
companies
├── id (UUID, PK)
├── name
├── industry_id (FK → industries.id)
├── size (1-50 / 50-500 / 500+)
├── website
├── description
├── geo_score (INT, 0-100)
├── geo_score_updated_at
├── logo_url
├── contact_email
├── contact_phone
├── created_at
├── updated_at
└── subscription_tier (free / basic / pro / enterprise)

company_geo_scores (历史评分)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── score (INT, 0-100)
├── breakdown (JSON) — 各维度评分详情
├── scanned_at
└── data_source (JSON) — 扫描来源

company_ai_mentions (AI提及记录)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── ai_platform (chatgpt / perplexity / gemini / other)
├── query_text
├── response_snippet
├── sentiment (positive / neutral / negative)
├── detected_at
└── context_url
```

## 三、行业体系

```
industries
├── id (UUID, PK)
├── name
├── code
├── parent_id (FK → industries.id, nullable)
├── level (1 / 2 / 3)
├── description
├── icon_url
├── sort_order
└── status (active / deprecated)

industry_metrics
├── id (UUID, PK)
├── industry_id (FK → industries.id)
├── metric_name (avg_geo_score / ai_mention_count / total_companies)
├── metric_value (DECIMAL)
├── period (year_month)
└── calculated_at
```

## 四、产业地图体系

```
value_chain_layers (价值链层)
├── id (UUID, PK)
├── name (AI入口层 / 知识资产层 / 基础设施层 / 服务交付层 / 标准评价层)
├── description
├── sort_order
└── status

value_chain_nodes (价值链节点)
├── id (UUID, PK)
├── layer_id (FK → value_chain_layers.id)
├── name
├── description
├── type (company / product / service / standard)
├── entity_id (UUID, polymorphic)
├── parent_node_id (FK → value_chain_nodes.id, nullable)
└── relationships (JSON) — 节点间关系

business_model_map (商业赚钱地图)
├── id (UUID, PK)
├── buyer_type (enterprise / sme / investor / government)
├── product_line
├── price_tier
├── revenue_model
├── target_industry_id (FK → industries.id)
├── estimated_market_size (DECIMAL)
└── opportunity_description

operation_flow_stages (运营流程阶段)
├── id (UUID, PK)
├── stage_order (1-8)
├── stage_name (诊断 / 策略 / 知识建设 / 内容生产 / 发布 / 监测 / 优化 / 复购)
├── description
├── tools_used (JSON)
└── output_documents (JSON)
```

## 五、商业赚钱体系

```
products
├── id (UUID, PK)
├── name
├── description
├── category (saas / data / service / training)
├── price (DECIMAL)
├── billing_cycle (monthly / yearly / one_time)
├── features (JSON)
├── status (active / deprecated)
└── created_at

subscriptions
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── product_id (FK → products.id)
├── tier (free / basic / pro / enterprise)
├── started_at
├── expires_at
├── auto_renew (BOOLEAN)
├── status (active / expired / cancelled)
└── payment_info (JSON, encrypted)
```

## 六、交易体系

```
marketplace_requests (企业需求)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── title
├── description
├── budget_min (DECIMAL)
├── budget_max (DECIMAL)
├── industry_id (FK → industries.id)
├── status (draft / open / matched / in_progress / completed / cancelled)
├── created_at
├── updated_at
└── matched_provider_id (FK → users.id, nullable)

marketplace_providers (服务商)
├── id (UUID, PK)
├── user_id (FK → users.id)
├── company_id (FK → companies.id)
├── provider_type (agency / tool / expert / certifier)
├── service_categories (JSON)
├── certifications (JSON)
├── case_studies (JSON)
├── avg_rating (DECIMAL, 0-5)
├── total_projects (INT)
└── verification_status (pending / verified / rejected)

marketplace_transactions (交易记录)
├── id (UUID, PK)
├── request_id (FK → marketplace_requests.id)
├── provider_id (FK → marketplace_providers.id)
├── contract_value (DECIMAL)
├── platform_fee (DECIMAL)
├── status (pending / active / completed / disputed)
├── started_at
├── completed_at
└── rating (INT, 1-5)
```

## 七、数据资产体系

```
geo_index (GEO指数)
├── id (UUID, PK)
├── industry_id (FK → industries.id)
├── index_name
├── index_value (DECIMAL)
├── period
└── calculation_metadata (JSON)

ai_answer_db (AI回答数据库)
├── id (UUID, PK)
├── query_text
├── ai_platform
├── response_text
├── referenced_companies (JSON)
├── timestamp
├── category
└── relevance_score (DECIMAL)

prompt_patterns (Prompt数据库)
├── id (UUID, PK)
├── industry_id (FK → industries.id)
├── pattern_text
├── frequency (INT)
├── intent_category
├── sample_queries (JSON)
└── geo_opportunity_score (DECIMAL)

knowledge_graph_edges (知识图谱边)
├── id (UUID, PK)
├── source_entity_id (UUID)
├── source_entity_type
├── target_entity_id (UUID)
├── target_entity_type
├── relationship_type
├── weight (DECIMAL)
├── created_at
└── metadata (JSON)
```

## 八、Agent体系

```
agent_definitions (Agent定义)
├── id (UUID, PK)
├── name (CEO / CTO / Product / Industry / Scanner / Content / Data / Market / Sales / QA)
├── role_description
├── capabilities (JSON)
├── input_schema (JSON)
├── output_schema (JSON)
├── permission_level (1-5)
├── max_concurrency (INT)
└── status (active / paused / deprecated)

agent_execution_logs (执行日志)
├── id (UUID, PK)
├── agent_id (FK → agent_definitions.id)
├── task_id (UUID)
├── input
├── output
├── tools_called (JSON)
├── tokens_used (INT)
├── started_at
├── completed_at
└── status (running / success / failed)

agent_collaboration_records (协作记录)
├── id (UUID, PK)
├── from_agent_id (FK → agent_definitions.id)
├── to_agent_id (FK → agent_definitions.id)
├── message_type
├── message_content (JSON)
├── context (JSON)
├── created_at
└── response_at
```
