# GEO产业引擎 — UX页面设计需求

## 设计理念

不是后台工具，而是 **AI时代企业增长入口**。

设计语言：清晰、可信、智能、前瞻

## 一、首页

| 要素 | 描述 |
|------|------|
| **定位** | AI时代企业增长入口，第一屏即价值 |
| **Hero区** | GEO引擎的核心主张 + 实时GEO指数看板（动态数据） |
| **核心入口** | AI增长中心 / 产业导航 / 交易市场 / 数据中心 四个大卡片 |
| **实时数据流** | 滚动展示各行业GEO评分趋势 |
| **快速检测** | 嵌入"免费检测GEO评分"输入框 |
| **信任要素** | 合作企业Logo墙、成功案例、行业报告下载 |
| **底部CTA** | 注册/登录、服务商入驻、数据合作 |

## 二、AI增长中心

| 模块 | 设计要点 |
|------|---------|
| **Dashboard** | GEO评分趋势图、AI提及热力图、行业排名 |
| **企业检测** | 输入域名 → 自动扫描 → 输出GEO评分报告 |
| **AI曝光分析** | 按AI平台展示品牌提及、情感分析、竞争对比 |
| **内容优化** | 输入关键词 → AI推荐内容策略 → 一键生成优化方案 |
| **监测设置** | 监测关键词、频率、告警阈值 |
| **报告导出** | PDF/Excel报告，支持对比周期 |

## 三、产业导航

| 页面 | 设计要点 |
|------|---------|
| **产业地图首页** | 五层价值链的交互式可视化（力导向图/树图） |
| **价值链地图** | 点击层级展开细分子行业，展示企业分布 |
| **商业赚钱地图** | 买方-产品-服务的三栏交互矩阵，点击查看详情 |
| **运营流程地图** | 八阶段流程图，每一阶段展示工具、案例、服务商 |
| **行业深度页** | 选择行业 → 展示该行业的完整地图 + 数据 + 商机 |

## 四、交易市场

| 页面 | 设计要点 |
|------|---------|
| **市场首页** | 分类导航、推荐服务商、热门需求、AI匹配入口 |
| **发布需求** | 表单：需求描述、预算、行业、时间要求、附件上传 |
| **服务商列表** | 基于评价/案例/认证的排序，筛选，AI推荐标签 |
| **服务商详情** | 资质认证、案例展示、评价区、联系/预约 |
| **项目管理** | 在线看板、里程碑、文件共享、沟通记录 |
| **我的交易** | 需求管理、进行中项目、历史交易、评价入口 |

## 五、数据中心

| 页面 | 设计要点 |
|------|---------|
| **数据概览** | GEO总指数、行业分布、数据来源统计 |
| **行业数据库** | 多维度筛选、数据表格、导出、对比分析 |
| **企业数据库** | 企业GEO排行榜、搜索/筛选、对比、收藏 |
| **AI回答数据库** | 按平台/行业/时间查询AI回答样本，语义搜索 |
| **知识图谱** | 交互式图谱浏览器，节点展开/收起，关系路径查找 |
| **行业报告** | 报告列表、预览、下载（付费/免费） |

## 六、生态中心

| 页面 | 设计要点 |
|------|---------|
| **生态概览** | GEO服务商生态、认证体系、合作伙伴图谱 |
| **认证体系** | GEO认证标准介绍、认证流程、认证服务商列表 |
| **合作伙伴** | 数据合作伙伴、技术合作伙伴、渠道合作伙伴 |
| **社区/论坛** | 行业讨论、最佳实践、问答社区 |
| **培训中心** | GEO课程、认证培训、专家讲座 |

## 七、后台管理

| 页面 | 设计要点 |
|------|---------|
| **用户管理** | 用户列表、角色管理、权限配置、操作日志 |
| **企业审核** | 企业入驻审核、信息验证、资质审核 |
| **服务商审核** | 资质认证、评级管理、违规处理 |
| **内容管理** | 行业报告发布、首页内容管理、公告管理 |
| **交易管理** | 交易监控、纠纷处理、佣金结算 |
| **系统设置** | 定价配置、功能开关、API管理、告警规则 |
| **数据分析** | 平台整体数据看板、趋势分析、用户行为分析 |

## 交互原则

| 原则 | 说明 |
|------|------|
| **零认知负担** | 用户进入30秒内理解核心价值 |
| **数据驱动** | 每个页面核心位置都有数据可视化 |
| **渐进式引导** | 从免费检测到付费服务的自然转化路径 |
| **AI贯穿** | 每个核心页面都有AI功能入口 |
| **移动优先** | 响应式设计，核心功能移动端可用 |
