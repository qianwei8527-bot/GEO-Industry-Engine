## 二、共享组件目录（13 组件）

### IdentityCard（GEO 数字身份卡）

```
┌─────────────────────────────────┐
│ [L3徽章]                         │
│                                  │
│ 腾讯云                 GEO Score │
│ AI基础设施企业            78/A    │
│                                  │
│ 能力: 算力 模型服务 企业AI        │
│ 认证: L3 专业能力认证             │
│ 排名: AI基础设施 Top 5           │
│                                  │
│ [查看完整报告]  [对比]  [关注]    │
└─────────────────────────────────┘
```

Props: `entity`, `variant: 'brief'|'full'`, `onClick`
使用页面：首页、检测中心、认证通行证、企业深度、服务商详情

### ScoreGauge（得分仪表盘）

半圆形仪表盘，颜色从红(0)→黄(50)→绿(100)，指针指示当前分数，下方标注等级标签和历史变化箭头。

Props: `score`, `maxScore`, `label`, `trend: 'up'|'down'|'stable'`, `previousScore?`
使用页面：评估报告、资产首页

### TrustBadge（可信等级标识）

```
┌──────────┐
│   L3     │  颜色按等级: L0灰/L1灰/L2蓝/L3金/L4紫
│ 专业认证  │
└──────────┘
```

Props: `level: 'L0'|'L1'|'L2'|'L3'|'L4'`, `size: 'sm'|'md'|'lg'`
使用页面：身份卡、认证通行证、服务商列表、管理审核

### CapabilityTags（能力标签组）

水平排列的标签，每个标签显示能力名称+等级(Lv.1-5)

Props: `capabilities: [{name, level}]`, `maxDisplay?: number`
使用页面：身份卡、企业深度、认证申请、服务商详情

### EvidenceGallery（证据画廊）

网格布局展示证据缩略图，点击展开查看详情（来源、类型、可信度评分）

Props: `evidences`, `columns?: number`
使用页面：认证通行证、企业深度

### EventTimeline（事件时间轴）

垂直时间轴，每个节点显示事件类型图标+描述+时间。支持筛选事件类型。

Props: `events`, `filterable?: boolean`
使用页面：企业深度、认证通行证、审核进度

### IndustrySearch（产业搜索框）

带自动补全的搜索框。输入时实时查询企业/行业/地区。

Props: `onSelect`, `placeholder`, `types?: ['company','industry','region']`
使用页面：首页、检测中心、产业导航

### GapList（缺口/建议列表）

按影响力排序的卡片列表。每项显示：缺口名称、影响力评分、难度标签、[补充]按钮。

Props: `gaps`, `onAction`
使用页面：评估报告、数据完整度、数据补充

### CompletenessRadar（五维度雷达图）

五边形雷达图：完整度、准确度、时效性、可信度、来源等级。

Props: `dimensions: [{name, score}]`, `benchmark?: [{name, score}]`
使用页面：数据完整度

### TrendChart（趋势线图）

折线图，支持多条线叠加（历史趋势+三线预测）。

Props: `series: [{name, data: [{date, value}]}]`, `showPrediction?: boolean`
使用页面：评估报告、资产首页

### CompareTable（多维对比表）

横向对比表：行=维度，列=实体A/实体B/行业均值。差异列标红/标绿。

Props: `entities: [{name, dimensions: [{key, value}]}]`, `benchmark?`
使用页面：竞争对比

### YamlEditor（YAML 编辑器）

语法高亮的 YAML 编辑区 + 实时校验面板 + [发布]按钮。

Props: `value`, `onChange`, `schema`, `onPublish`
使用页面：配置管理

### ApprovalFlow（审核流程组件）

水平步骤条：提交→AI审核→人工审核→通过/驳回。当前步骤高亮。

Props: `steps: [{name, status, comment?}]`
使用页面：认证审核、审核进度
