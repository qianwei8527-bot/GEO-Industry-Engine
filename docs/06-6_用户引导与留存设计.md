## 一、用户生命周期管理

### 1.1 六阶段模型

```
阶段0: 未知 -> 不知道GEO是什么，不了解AI搜索对自己的影响
阶段1: 被发现 -> 进入检测中心，获得GEO数字身份和基础评估
阶段2: 被理解 -> 补充数据资产，形成企业/能力/关系画像
阶段3: 被认可 -> 进入认证体系，获得可信身份
阶段4: 被连接 -> 进入产业导航，发现合作伙伴和市场机会
阶段5: 被放大 -> 进入交易市场，获得商业机会
阶段6: 持续优化 -> 数据反哺 -> 重新评估 -> 循环上升
```

### 1.2 阶段跃迁触发

| 跃迁 | 触发条件 | 系统动作 |
|------|---------|---------|
| 0->1 | 用户首次搜索/评估 | 创建Entity + 生成初始GeoScore |
| 1->2 | 补充数据 > 60%完整度 | 解锁画像页 + 展示缺口列表 |
| 2->3 | 提交认证申请 | 触发审核流程 + 通知审核员 |
| 3->4 | 认证等级 >= L2 | 在产业导航中显示 + 解锁关系推荐 |
| 4->5 | 匹配到 >= 1 个需求 | 推送匹配通知 + 解锁交易功能 |
| 5->6 | 完成 >= 1 笔交易 | 开启持续监控 + 周期性报告 |

### 1.3 流失预警

| 信号 | 阈值 | 挽回动作 |
|------|------|---------|
| 7天未登录 | 7天 | 邮件: "你的GEO可见度可能有变化" |
| 30天未评估 | 30天 | 邮件: "行业新机会提醒" |
| 数据完整度下降 | -10% | 站内通知: "关键数据过期" |
| GEO Score下降 | -20% | 紧急通知: "竞争对手正在超越" |

## 二、首次用户体验 (Onboarding)

### 2.1 企业用户Onboarding流程

1. 首页搜索框输入企业名 -> 快速检测 -> 生成简版身份卡
2. 身份卡点击"查看完整报告" -> 四层评估报告
3. 报告底部推荐: "补充数据以获得更准确评分"
4. 引导注册 -> 完善企业信息 -> 获得完整度评分
5. 推送: "你的GEO可见度在行业中排名X%，建议申请L1认证"

### 2.2 个人用户Onboarding

1. 首页角色卡片"个人" -> 能力自评
2. 展示行业职业地图: "GEO优化师/内容策略师/AI训练师..."
3. 选择职业方向 -> 创建个人GEO身份
4. 推荐: "完成3项认证可提升行业可见度50%"

### 2.3 服务商Onboarding

1. 首页角色卡片"服务商" -> 能力申报
2. 上传案例 -> AI自动分析能力标签
3. 获得初始Trust Score -> 推荐认证等级
4. 引导: "认证后可展示在交易市场，面向X万家企业"

## 三、留存机制

### 3.1 周期性价值传递

| 触点 | 频率 | 内容 |
|------|------|------|
| GEO周报 | 每周 | 评分变化/行业动态/机会提醒 |
| 月度报告 | 每月 | 详细趋势分析/竞品变化/策略建议 |
| 季度review | 每季 | 全面评估 + 战略规划更新 |
| 事件通知 | 实时 | 竞争者变动/行业事件/认证到期 |

### 3.2 成长激励

| 等级 | 解锁 | 激励类型 |
|:----:|------|---------|
| L0 | 基础评估 | 好奇心 |
| L1 | 个人/企业主页 | 身份认同 |
| L2 | 认证标识 + 行业展示 | 社交认可 |
| L3 | 优先推荐 + 佣金折扣 | 商业利益 |
| L4 | 生态治理权 + 分红 | 归属感+经济 |

### 3.3 社交传播

- 一键分享GEO身份卡到社交媒体
- 认证标识可嵌入企业官网 (SVG badge)
- 行业排名可生成海报分享
