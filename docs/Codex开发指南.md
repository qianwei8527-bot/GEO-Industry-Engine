# GEO-Industry-Engine Codex Development Guide

> AI 开发团队的读取规则和开发规范。所有 Codex 实例在接手任务前必须阅读此文件。

---

## 一、项目启动读取顺序

接手 GEO-Industry-Engine 任务时，必须按此顺序阅读核心文档：

`
第1步 → 35_CTO架构冻结.md
        理解架构基线、禁止事项、扩展原则

第2步 → 00_项目宪章.md
        理解项目定位、7层架构、术语映射

第3步 → 对应领域的设计文档
        根据任务类型选择（见第二节）

第4步 → 08_API接口规范.md
        理解 API 风格和响应格式

辅助 → docs/INDEX.md
        查找相关文档
`

## 四、禁止事项

1. 不读取 status:draft 的文档作为架构依据
2. 不绕过 Context Engine 直接读数据库
3. 不在未查阅 35_CTO架构冻结 的情况下做架构决策
4. 不直接调用 LLM 替代决策模型
5. 不创建与现有文档 authority:primary 冲突的新定义
