# GEO用户行为与AI决策路径模型

> 为什么用户问AI？AI为什么回答某个企业？企业为什么需要GEO？
> 这个文档回答这三个问题，并定义支撑它们的数据模型。

---

## 一、为什么要研究用户行为？

### 1.1 GEO的真正本质

很多人理解GEO是"优化内容，让ChatGPT推荐我"。这个太浅。

**真正的GEO是企业争夺"AI决策入口"的可见度。**

传统用户决策路径：

```
用户需求 -> Google搜索 -> 访问网站 -> 比较 -> 购买
```

AI时代用户决策路径：

```
用户需求 -> 询问AI -> AI理解需求 -> AI筛选候选 -> AI给建议 -> 用户决策
```

关键变化：**AI代替了用户的部分筛选和比较过程。** 企业不能再直接向用户推广，而是需要被AI选中推荐给用户。

### 1.2 当前系统缺失了什么

当前系统理解的是：

```
企业 -> 行业 -> 模型 -> Prompt -> 回答 -> 排名
```

但还没有完整理解：

```
人为什么问AI？    ->   User Intent（用户意图）
AI为什么这样回答？ ->   AI Decision Path（AI决策路径）
AI如何影响购买？   ->   Conversion Value（转化价值）
```

这三层决定GEO的商业价值。 所以我们称之为 **GEO决策智能（GEO Decision Intelligence）**——预测哪些AI问题会产生商业价值，并指导企业占位。没有意图模型，我们就不知道哪些Prompt值得占位、哪些回答值得优化、哪些企业值得推荐。

## 二、GEO用户意图模型

### 2.1 五类用户意图

用户问AI不是随机的。不同意图对应不同的商业价值和GEO策略。

#### 意图一：Industry Discovery（行业探索型）

| 属性 | 内容 |
|------|------|
| **用户状态** | 不了解行业，想建立初步认知 |
| **典型问题** | "新能源汽车行业有哪些值得关注的企业？" |
| **购买阶段** | 认知（Awareness） |
| **商业价值** | ★★★ 低交易转化，高曝光价值 |
| **GEO目标** | 品牌进入AI认知池 |
| **用户画像** | 投资者、研究者、求职者、刚入行的从业者 |

**为什么重要**：虽然这个意图直接转化率低，但它是品牌的**第一印象入口**。AI第一次提到某个企业，用户会对该企业建立初始认知。

**行业示例**：
| 行业 | 典型问题 | GEO机会 |
|------|---------|---------|
| 新能源 | "中国储能电池行业格局" | 企业出现在行业综述中 |
| 医疗 | "基因治疗领域最新进展" | 企业研发被AI提及 |
| 半导体 | "国产EDA工具发展现状" | 国产厂商进入AI视野 |

---

#### 意图二：Comparison（竞品比较型）

| 属性 | 内容 |
|------|------|
| **用户状态** | 已有候选池，需要对比做出选择 |
| **典型问题** | "宁德时代和比亚迪哪个更值得投资？" |
| **购买阶段** | 评估（Evaluation） |
| **商业价值** | ★★★★ 高 |
| **GEO目标** | 进入比较列表，成为"被比较"的一方 |
| **用户画像** | 投资者、采购决策者、企业管理者 |

**为什么重要**：这个意图是**决策漏斗的腰部**。用户此时已经在认真比较，AI的推荐会直接影响选择。GEO的核心目标不是"被AI随便提到"，而是"在比较型问题中被推荐"。

**行业示例**：
| 行业 | 典型问题 | GEO机会 |
|------|---------|---------|
| 云计算 | "阿里云和华为云哪个更适合制造业？" | 进入云服务商比较列表 |
| 工业 | "ABB和发那科哪个机器人性价比更高？" | 成为推荐对比对象 |
| 金融 | "招商银行和建设银行哪个理财更好？" | 被AI列入推荐银行 |

---

#### 意图三：Vendor Selection（采购筛选型）

| 属性 | 内容 |
|------|------|
| **用户状态** | 准备采购，需要供应商列表 |
| **典型问题** | "国内工业机器人供应商有哪些？" |
| **购买阶段** | 决策（Decision） |
| **商业价值** | ★★★★★ 最高 |
| **GEO目标** | 成为AI推荐的供应商 |
| **用户画像** | 采购经理、企业决策者 |

**为什么重要**：这是**商业价值最高的意图**。用户在问这个问题时，已经准备花钱了。AI回答中列出的供应商名单，直接决定了用户联系谁、购买谁。

**行业示例**：
| 行业 | 典型问题 | GEO机会 |
|------|---------|---------|
| 制造 | "MES系统供应商推荐" | 进入供应商推荐列表 |
| 企业服务 | "企业级CRM系统哪家好？" | 被AI排在前三位推荐 |
| 物流 | "仓储自动化解决方案提供商" | 成为方案推荐者 |

---

#### 意图四：Solution Exploration（方案探索型）

| 属性 | 内容 |
|------|------|
| **用户状态** | 有需求但不确定最佳方案 |
| **典型问题** | "如何降低工厂自动化成本？" |
| **购买阶段** | 需求（Need） |
| **商业价值** | ★★★★ 高（长期价值） |
| **GEO目标** | 成为解决方案提供者 |
| **用户画像** | 技术负责人、企业管理者 |

**为什么重要**：用户在找方案而不是找供应商。如果AI给出的方案中提到某企业的产品或服务，该企业就在需求阶段建立了先发优势。

**行业示例**：
| 行业 | 典型问题 | GEO机会 |
|------|---------|---------|
| 制造 | "如何用AI提升产线良率？" | 企业的AI方案被推荐 |
| 零售 | "如何搭建全渠道会员体系？" | 企业的SaaS方案被引用 |
| 医疗 | "如何建设互联网医院？" | 企业的解决方案进入AI知识库 |

---

#### 意图五：Brand Verification（品牌验证型）

| 属性 | 内容 |
|------|------|
| **用户状态** | 已有目标品牌，需要验证可信度 |
| **典型问题** | "XX公司靠谱吗？"或"XX公司的产品评价如何？" |
| **购买阶段** | 验证（Validation） |
| **商业价值** | ★★★ 中等，但直接影响成交 |
| **GEO目标** | 建立AI信任，认证背书传递给AI |
| **用户画像** | 最终决策者、采购审核人 |

**为什么重要**：这是成交的最后一关。用户在付款前用AI验证品牌的可靠性。AI如果给出正面评价，成交率大幅提升。**这是认证体系与意图模型的连接点。**

**行业示例**：
| 行业 | 典型问题 | GEO机会 |
|------|---------|---------|
| 企业服务 | "XX SaaS公司值得买吗？" | AI正面评价影响成交 |
| 投资 | "XX公司财务是否健康？" | AI引用公开财务数据 |
| 招聘 | "XX公司工作环境如何？" | 雇主品牌验证 |

### 2.2 商业价值评分体系

每个意图-行业-问题组合都有一个商业价值评分。

| 维度 | 权重 | 评估方式 |
|------|------|---------|
| 购买阶段 | 40% | 决策 > 评估 > 需求 > 验证 > 认知 |
| 查询频率 | 25% | 该问题在AI搜索中出现的频率 |
| 客单价 | 20% | 该行业平均采购金额 |
| 竞争密度 | 15% | 当前已占位的企业数量（越少机会越大）|

**评分公式**：

```
Commercial Value = StageWeight x 0.4 + Frequency x 0.25 + TicketSize x 0.2 + CompetitionBonus x 0.15
```

**示例**：

| 意图 | 行业 | 阶段权重 | 频率 | 客单价 | 竞争密度 | 总分 | 评级 |
|------|------|---------|------|--------|---------|------|------|
| Vendor Selection | 工业制造 | 1.0 | 8000次/月 | 500万 | 低(3家) | 92 | ★★★★★ |
| Comparison | 云计算 | 0.7 | 15000次/月 | 200万 | 中(8家) | 78 | ★★★★ |
| Industry Discovery | 新能源 | 0.3 | 20000次/月 | - | 低(5家) | 52 | ★★★ |

## 三、AI决策路径模型

### 3.1 AI推荐机制

为什么AI推荐A企业，不推荐B企业？这不是随机的。

**AI回答一个采购问题时，内部的决策路径**（假设推理）：

```
用户提问："国内工业机器人供应商有哪些？"
    |
    v
1. AI理解意图 -> Vendor Selection（采购筛选）
    |
    v
2. AI检索知识库 -> 相关企业列表
    |
    v
3. AI评估候选 -> 根据多个因子排序
    |
    v
4. AI生成回答 -> 列出前5-10家
    |
    v
5. AI引用来源 -> 附上参考资料
```

**关键在第3步：AI如何评估候选？**

不同模型的评估因子不同：

**ChatGPT** 的推荐倾向：
| 因子 | 权重 | 说明 |
|------|------|------|
| 知识权威性 | 35% | 在训练数据中出现的频率和上下文 |
| 内容覆盖度 | 20% | 官网、百科、新闻等多来源覆盖 |
| 行业关联度 | 20% | 与企业所属行业的语义关联强度 |
| 来源可信度 | 15% | 引用来源的权威性（官网>新闻>论坛）|
| 时效性 | 10% | 最近出现在知识库中的时间 |

**Gemini** 的推荐倾向：
| 因子 | 权重 | 说明 |
|------|------|------|
| Google搜索排名 | 30% | 在Google索引中的权重 |
| 网页结构 | 25% | Schema标记、结构化数据 |
| 实体关联 | 20% | Knowledge Graph中的实体关系 |
| 用户信号 | 15% | 点击率、用户互动 |
| 时效性 | 10% | 新闻和近期内容优先 |

**Perplexity** 的推荐倾向：
| 因子 | 权重 | 说明 |
|------|------|------|
| 引用质量 | 40% | 引用来源的多样性和权威性 |
| 多源一致性 | 30% | 多个来源都提到同一企业 |
| 时效性 | 20% | 最近被引用的频率 |
| 用户评价 | 10% | Reddit等平台的用户讨论 |

**这一部分数据存在于 ai_model_behavior_patterns 表中的 source_preference 和 answer_style 字段**，但需要更结构化的方式来表达推荐因子。

### 3.2 品牌进入AI推荐路径

一个品牌从"不被AI知道"到"被AI推荐"，通常经历这些阶段：

```
阶段1：AI不可见
  - AI回答中不提及该品牌
  - GEO评分: 0-20

阶段2：AI认知（出现在知识库中）
  - AI在行业综述中间接提到
  - GEO评分: 20-40
  - 触发条件：有官网、百科条目、新闻覆盖

阶段3：AI提及（进入候选池）
  - AI在比较类问题中列为候选
  - GEO评分: 40-60
  - 触发条件：多来源提及、行业报告引用

阶段4：AI推荐（被优先推荐）
  - AI在采购类问题中推荐
  - GEO评分: 60-80
  - 触发条件：高权威性、多来源覆盖、用户验证

阶段5：AI首选（成为行业标杆）
  - AI在多数问题中首先推荐
  - GEO评分: 80-100
  - 触发条件：行业领导地位、持续内容建设、认证背书
```

**这个路径是 GEO 优化策略的底层逻辑。** 企业需要知道自己在哪个阶段，以及如何进入下一阶段。

---

### 3.3 引用分析

AI回答中的引用是GEO最直接的信号。

```
AI回答了"国内工业机器人供应商有哪些"
    |
    v
引用了：
  1. 企业A官网         -> 企业A获得1次品牌曝光 + 引用权重
  2. 行业报告(B站)     -> 行业报告平台上提到的企业获得间接曝光
  3. 维基百科          -> 维基百科上列出的企业获得基础曝光
  4. 新闻文章(X新闻)    -> 新闻中提到的企业获得时效性曝光
```

**企业可以通过分析AI引用来源，了解哪些内容渠道能提升被推荐的概率。**

## 五、商业应用



### 5.0 GEO决策智能在五大系统中的位置

GEO决策智能（GEO Decision Intelligence）不是一个独立系统，而是贯穿所有系统的核心逻辑：

| 系统 | 决策智能的应用 |
|------|-------------|
| AI可见度增长系统 | 不只看"是否被提到"，更看"在高价值意图中是否被提到" |
| 产业导航系统 | 增加"行业AI需求地图"层，显示该行业的高频问题 |
| 交易市场 | 增加"AI商机池"，推送未被占位的商业问题 |
| 认证体系 | 认证数据成为AI推荐因子 |
| 数据资产中心 | 增加用户意图数据库和商机数据库 |

### 5.1 对AI可见度增长系统的影响

不在改名，而是能力升级：

| 当前能力 | 升级后 |
|---------|--------|
| 检测企业是否被AI提到 | 检测企业是否在**高商业价值意图**中被提到 |
| GEO评分按模型计算 | GEO评分按**意图 x 模型 x 行业**加权 |
| 内容优化建议通用 | 内容优化建议**针对特定意图的Prompt** |

### 5.2 对产业导航系统的影响

产业导航的行业地图中增加：

```
行业AI需求地图
├── 该行业的高频用户问题
├── 每个问题对应的用户意图类型
├── 每个问题的商业价值评分
└── 当前已占位的企业
```

### 5.3 对交易市场的影响

增加"AI需求商机池"：

```
AI需求商机池
├── 系统识别高价值但低竞争的问题
├── 例如："某行业10000次/月搜索「推荐XX供应商」但无人占位"
└── 形成商机推送给服务商和企业
```

### 5.4 对认证体系的影响

认证不只是给人看的，更是给AI看的：

```
GEO Verified Entity（GEO可信实体）
├── 认证后的企业更可能被AI推荐
├── 认证数据结构化后喂入AI知识库
└── 验证型意图（"XX公司靠谱吗"）直接关联认证数据
```

## 六、GEO竞争动力学模型

### 6.1 核心问题

现有GEO评分是绝对分，不反映竞争格局。AI搜索只推荐5-8家企业，零和市场。SEO有关键词难度，GEO没有推荐席位难度。

### 6.2 模型定义

GEOSpaceScore = (AI席位总数 - 当前竞争企业数) / AI席位总数 * 100
配合评估维度：新进入难度、占位稳定性、替代成本。

### 6.3 领域对象
GEOSpaceScore: id, query_text, industry_id, total_slots, occupied_slots, churn_rate, entry_barrier, opportunity_score

## 七、AI信任评分模型

### 7.1 核心问题

企业认证(L1-L4)是人给企业的信用。AI有自己的隐性信任机制，它是GEO评分背后的暗物质。

### 7.2 模型定义

AITrustScore = 权威性信号(35%) + 一致性信号(25%) + 时效性信号(20%) + 验证性信号(20%)

不同模型对信任因子的敏感度不同。

### 7.3 领域对象
AITrustScore: id, company_id, model_id, authority_score, consistency_score, timeliness_score, verifiability_score, overall_trust_score

## 八、AI内容就绪度模型

### 8.1 核心问题

内容发布前就预测被AI引用的概率。AI需要结构化、可引用、可验证的内容。

### 8.2 模型定义

AIContentReadiness = 结构化程度(35%) + 可引用性(25%) + 权威信号(20%) + 时效性(10%) + 多源验证(10%)

### 8.3 领域对象
AIContentReadiness: id, content_id, url, structure_score, citability_score, authority_score, timeliness_score, verification_score, overall_readiness, suggested_improvements

## 九、GEO效果归因模型

### 9.1 核心问题

企业投了GEO优化，怎么知道是GEO带来了客户？没有归因模型，GEO投入无法被验证。

### 9.2 归因链

内容优化 -> AI引用增加 -> 用户通过AI发现品牌 -> 用户访问 -> 转化 -> 收入归因

### 9.3 归因模型类型
Last-Touch, Linear, Time-Decay, Position-Based

### 9.4 领域对象
GEOAttribution: id, company_id, campaign_id, attribution_model, ai_impressions, ai_clicks, website_visits, conversions, revenue_attributed, roi
