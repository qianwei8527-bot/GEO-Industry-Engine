# 工程实践与运维设计

> CI/CD、测试、安全、监控——让系统可运行、可维护、可信赖。

---

## 一、CI/CD 流水线

### 1.1 GitHub Actions 工作流

| 阶段 | 触发器 | 操作 | 耗时预估 |
|------|--------|------|---------|
| 代码检查 | push/PR | ESLint + TypeScript + Flake8 | 2min |
| 单元测试 | push/PR | pytest + Jest，覆盖率≥80% | 5min |
| 集成测试 | push/PR | API测试 + 数据库迁移测试 | 8min |
| 构建 | push main | 前端构建 + 后端Docker构建 | 5min |
| 部署到staging | push main | 自动部署到staging环境 | 3min |
| E2E测试 | 部署到staging后 | Playwright端到端测试 | 10min |
| 部署到production | 手动触发 | 蓝绿部署 | 5min |

### 1.2 分支策略

```
main         ← 生产就绪代码
  ├── develop  ← 集成分支
  │   ├── feature/xxx  ← 功能分支
  │   └── fix/xxx      ← 修复分支
  └── release/x.x.x  ← 发布分支
```

## 二、测试策略

### 2.1 测试金字塔

```
          /         /E2E\         5%  Playwright
        /-----       /集成  \       20%  pytest(API) + Jest(组件)
      /-------     /单元测试 \      75%  pytest(后端) + Jest(前端)
    /-----------```

### 2.2 测试类型

| 类型 | 框架 | 目标覆盖率 | 运行时机 |
|------|------|-----------|---------|
| 后端单元测试 | pytest + pytest-cov | 85% | 每次 push |
| 前端单元测试 | Jest + Testing Library | 80% | 每次 push |
| API集成测试 | pytest + httpx | 关键路径100% | 每次 PR |
| 组件测试 | Storybook + Playwright | 关键组件100% | 每次 PR |
| E2E测试 | Playwright | 核心流程100% | staging部署后 |
| 性能测试 | k6 + Locust | P95 < 500ms | 每周 |

## 三、安全设计

### 3.1 数据安全

| 层级 | 措施 |
|------|------|
| 传输层 | TLS 1.3，全站HTTPS |
| 存储层 | 密码bcrypt，Token JWT(RS256)，敏感字段AES-256 |
| API层 | Rate limiting(100req/min)，API key验证，CORS白名单 |
| 数据库 | 连接加密，定期备份，最小权限原则 |

### 3.2 合规

| 合规项 | 状态 | 说明 |
|--------|------|------|
| GDPR | 规划中 | 数据可删除、可导出、用户同意 |
| 数据本地化 | 支持 | 数据库可部署在指定区域 |
| SOC2 | 长期规划 | 企业版客户需求 |

## 四、可观测性

### 4.1 监控三支柱

| 支柱 | 工具选型 | 监控内容 |
|------|---------|---------|
| Metrics | Prometheus + Grafana | QPS、P95延迟、错误率、数据库连接数 |
| Logs | ELK / Loki | 应用日志、访问日志、错误日志 |
| Traces | Jaeger / OpenTelemetry | 请求链路追踪（API→DB→AI API→响应）|

### 4.2 告警规则

| 级别 | 条件 | 通知方式 |
|------|------|---------|
| P0 严重 | 服务宕机、数据库不可用 | 电话+Slack+邮件 |
| P1 高 | P95>1s、错误率>5% | Slack+邮件 |
| P2 中 | 磁盘>80%、API延迟上升 | 邮件 |
| P3 低 | 证书即将过期 | 邮件 |

| 环境 | 用途 | 配置 | 部署方式 |
|------|------|------|---------|
