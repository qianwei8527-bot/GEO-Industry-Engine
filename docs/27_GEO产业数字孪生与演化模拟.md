## 一、什么是 GEO 产业数字孪生

GEO 产业数字孪生不是一张静态地图，而是对现实 GEO 产业世界的**数字化动态建模**。它持续采集产业数据，形成可理解、可计算、可预测的虚拟产业镜像。

```
现实 GEO 产业世界
（企业、个人、服务商、技术、市场、政策）
        │
        ▼ 数据采集
Entity + Capability + Relationship + Event + Evidence
        │
        ▼ 数字化建模
GEO 产业知识图谱
        │
        ▼ 上下文理解
Context Engine
        │
        ▼ 智能决策
Decision Engine（评估 + 预测 + 推荐）
        │
        ▼ 用户行动
五大产品系统（检测/认证/导航/资产/交易）
        │
        ▼ 行为反馈
新的 Event + Evidence 进入系统
        │
        ▼ 模型更新
数字孪生持续演化
```

## 二、核心数据结构

### 2.1 空间维度（产业世界由什么构成）

| 元素 | 对应模型 | 说明 |
|------|---------|------|
| 实体 | Entity / Company / Person | 产业中的参与者 |
| 能力 | Capability | 参与者拥有什么能力 |
| 关系 | Relationship | 参与者之间的连接 |
| 事件 | Event | 产业中发生的事情 |
| 证据 | Evidence | 可验证的证明 |
| 信任 | Trust | 系统对参与者的可信度评估 |
| 位置 | Context (industry_position) | 参与者在产业价值链中的位置 |

### 2.2 时间维度（产业世界如何变化）

每个时间点，系统生成一个**产业快照**（Industry Snapshot）：

```yaml
snapshot:
  timestamp: "2026-07-28T00:00:00Z"
  entities: 15427
  relationships: 89123
  avg_geo_score: 52.3
  avg_trust_score: 48.7
  top_growing_industries: [AI基础设施, 智能驾驶]
  emerging_capabilities: [多模态内容生成, AI Agent开发]
```

快照序列构成产业演化历史，是趋势预测和风险评估的基础。

## 三、演化模拟引擎

### 3.1 三线预测模型

对任意产业或企业，系统生成三条发展路径：

| 路径 | 算法基础 | 用途 |
|------|---------|------|
| 保守线 | 历史趋势线性外推 | 基线预测 |
| 增长线 | 保守线 × 机会发现系数 | 可达目标 |
| 突破线 | 增长线 × 新兴赛道系数 | 天花板预测 |

### 3.2 What-If 模拟

用户可调整假设条件，系统重新计算预测：

```
假设：企业补充 5 条第三方证据 + 获得 L3 认证
    │
    ▼
Decision Engine 重新计算
    │
    ▼
输出：GEO Score 预计从 52 → 68（+16），行业排名从 #42 → #18
    │
    ▼
时间轴：30天后 score 58 → 60天后 score 65 → 90天后 score 68
```

### 3.3 产业级模拟

```
假设：AI基础设施行业年均增长 35%
    │
    ▼
模拟 12 个月后产业格局
    │
    ├ 新增企业：~450 家
    ├ 竞争强度：从 0.42 → 0.68
    ├ 人才缺口：L3+ 专家需求增加 280%
    └ 投资热点迁移：从算力 → AI应用
```

## 四、五张地图的数字孪生实现

五张地图共享同一个产业知识图谱，只是切换不同视图(View)：

| 地图 | 视图 | 核心查询 |
|------|------|---------|
| 产业生态地图 | 价值链 View | 按9层价值链聚合 Entity |
| 商业赚钱地图 | 象限 View | GEO Score × 增长率 散点分布 |
| 运营流程地图 | 阶段 View | 按8阶段分组 Entity |
| 地域生态地图 | 地理 View | 按省/市聚合 Entity |
| 发展方向地图 | 时间 View | 三线预测 Projection |

每张地图的数据更新实时反映数字孪生中的变化——一张地图的数据变更，所有视图同步刷新。

## 五、演化事件流

系统感知产业变化的事件类型：

```
EntityEvent:    企业注册 / 信息更新 / 能力变更 / 退出
RelationshipEvent: 建立合作 / 终止合作 / 投资 / 收购
CapabilityEvent:   新增能力 / 能力升级 / 能力淘汰
CertificationEvent: 申请 / 通过 / 降级 / 过期
MarketEvent:    新需求发布 / 交易达成 / 评价产生
ExternalEvent:  政策变化 / 技术突破 / 市场趋势
```

每个事件触发：
1. 写入 Event 表
2. Context Engine 更新相关实体的上下文
3. Decision Engine 重新计算受影响实体的评分
4. 如评分变化超过阈值 → 生成 Alert
5. 相关前端页面缓存失效

## 六、与五大系统的关系

| 系统 | 如何使用数字孪生 |
|------|----------------|
| 检测中心 | 读取当前快照 → 对比历史快照 → 展示变化趋势 |
| 认证中心 | 数字孪生中的 Trust/Evidence 数据驱动自动认证判定 |
| 产业导航 | 五张地图是数字孪生的可视化投影 |
| 数据资产 | 展示实体在数字孪生中的数据完整度和资产价值 |
| 交易市场 | 数字孪生中的能力/关系数据驱动供需匹配 |
