# GEO-Industry-Engine — Data Architecture

## Database Strategy

| Database | Purpose |
|----------|---------|
| PostgreSQL | Users, companies, transactions, content |
| Neo4j | Industry knowledge graph (entity relationships) |
| Vector DB | AI semantic search, Prompt matching |
| ElasticSearch | Full-text search, log analysis |

## Entity Relationship Overview

### User Domain
- users, user_profiles, user_credentials

### Enterprise Domain
- companies, company_geo_scores, company_ai_mentions

### Industry Domain
- industries, industry_metrics, value_chain_layers, value_chain_nodes

### Business Domain
- products, subscriptions, business_model_map

### Transaction Domain
- marketplace_requests, marketplace_providers, marketplace_transactions

### Data Asset Domain
- geo_index, ai_answer_db, prompt_patterns, knowledge_graph_edges

### Agent Domain
- agent_definitions, agent_execution_logs, agent_collaboration_records

### Certification Domain (NEW)
- certification_requests, certifications

### Regional Domain (NEW)
- regions, region_geo_data, region_entities

## Key Design Principles

1. All business data flows through unified data pipeline
2. Structured data -> PostgreSQL
3. Relationship data -> Neo4j
4. Vector data -> Vector DB
5. Full-text data -> ElasticSearch

## Data Flow

`
Data Collection -> Validation -> Storage -> Indexing -> API Service
     (crawl/API)   (cleanse)    (DB)     (search)    (REST/GraphQL)
`

## 一、用户体系

```
users
├── id (UUID, PK)
├── email (UNIQUE)
├── password_hash
├── name
├── role (admin / enterprise / provider / expert)
├── avatar_url
├── phone
├── created_at
├── updated_at
├── last_login_at
└── status (active / disabled / deleted)

user_profiles
├── id (UUID, PK)
├── user_id (FK → users.id)
├── company_id (FK → companies.id, nullable)
├── bio
├── expertise_tags (JSON)
├── linkedin_url
├── website
└── preferences (JSON)

user_credentials (OAuth)
├── id (UUID, PK)
├── user_id (FK → users.id)
├── provider (github / google / wechat)
├── provider_id
└── access_token (encrypted)
```

## 二、企业体系

```
companies
├── id (UUID, PK)
├── name
├── industry_id (FK → industries.id)
├── size (1-50 / 50-500 / 500+)
├── website
├── description
├── geo_score (INT, 0-100)
├── geo_score_updated_at
├── logo_url
├── contact_email
├── contact_phone
├── created_at
├── updated_at
└── subscription_tier (free / basic / pro / enterprise)

company_geo_scores (历史评分)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── score (INT, 0-100)
├── breakdown (JSON) — 各维度评分详情
├── scanned_at
└── data_source (JSON) — 扫描来源

company_ai_mentions (AI提及记录)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── ai_platform (chatgpt / perplexity / gemini / other)
├── query_text
├── response_snippet
├── sentiment (positive / neutral / negative)
├── detected_at
└── context_url
```

## 三、行业体系

```
industries
├── id (UUID, PK)
├── name
├── code
├── parent_id (FK → industries.id, nullable)
├── level (1 / 2 / 3)
├── description
├── icon_url
├── sort_order
└── status (active / deprecated)

industry_metrics
├── id (UUID, PK)
├── industry_id (FK → industries.id)
├── metric_name (avg_geo_score / ai_mention_count / total_companies)
├── metric_value (DECIMAL)
├── period (year_month)
└── calculated_at
```

## 四、产业地图体系

```
value_chain_layers (价值链层)
├── id (UUID, PK)
├── name (AI入口层 / 知识资产层 / 基础设施层 / 服务交付层 / 标准评价层)
├── description
├── sort_order
└── status

value_chain_nodes (价值链节点)
├── id (UUID, PK)
├── layer_id (FK → value_chain_layers.id)
├── name
├── description
├── type (company / product / service / standard)
├── entity_id (UUID, polymorphic)
├── parent_node_id (FK → value_chain_nodes.id, nullable)
└── relationships (JSON) — 节点间关系

business_model_map (商业赚钱地图)
├── id (UUID, PK)
├── buyer_type (enterprise / sme / investor / government)
├── product_line
├── price_tier
├── revenue_model
├── target_industry_id (FK → industries.id)
├── estimated_market_size (DECIMAL)
└── opportunity_description

operation_flow_stages (运营流程阶段)
├── id (UUID, PK)
├── stage_order (1-8)
├── stage_name (诊断 / 策略 / 知识建设 / 内容生产 / 发布 / 监测 / 优化 / 复购)
├── description
├── tools_used (JSON)
└── output_documents (JSON)
```

## 五、商业赚钱体系

```
products
├── id (UUID, PK)
├── name
├── description
├── category (saas / data / service / training)
├── price (DECIMAL)
├── billing_cycle (monthly / yearly / one_time)
├── features (JSON)
├── status (active / deprecated)
└── created_at

subscriptions
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── product_id (FK → products.id)
├── tier (free / basic / pro / enterprise)
├── started_at
├── expires_at
├── auto_renew (BOOLEAN)
├── status (active / expired / cancelled)
└── payment_info (JSON, encrypted)
```

## 六、交易体系

```
marketplace_requests (企业需求)
├── id (UUID, PK)
├── company_id (FK → companies.id)
├── title
├── description
├── budget_min (DECIMAL)
├── budget_max (DECIMAL)
├── industry_id (FK → industries.id)
├── status (draft / open / matched / in_progress / completed / cancelled)
├── created_at
├── updated_at
└── matched_provider_id (FK → users.id, nullable)

marketplace_providers (服务商)
├── id (UUID, PK)
├── user_id (FK → users.id)
├── company_id (FK → companies.id)
├── provider_type (agency / tool / expert / certifier)
├── service_categories (JSON)
├── certifications (JSON)
├── case_studies (JSON)
├── avg_rating (DECIMAL, 0-5)
├── total_projects (INT)
└── verification_status (pending / verified / rejected)

marketplace_transactions (交易记录)
├── id (UUID, PK)
├── request_id (FK → marketplace_requests.id)
├── provider_id (FK → marketplace_providers.id)
├── contract_value (DECIMAL)
├── platform_fee (DECIMAL)
├── status (pending / active / completed / disputed)
├── started_at
├── completed_at
└── rating (INT, 1-5)
```

```

├── category

## 八、Agent体系

```

├── completed_at

agent_collaboration_records (协作记录)

├── from_agent_id (FK → agent_definitions.id)

├── message_type

## 九、认证体系（新增）

### 认证申请表

certification_requests
- id (UUID, PK)
- applicant_type (enterprise / individual / product)
- applicant_id (UUID)
- certification_level (L1 / L2 / L3 / L4)
- certification_type (identity / professional / industry / endorsement)
- submitted_docs (JSON)
- status (pending / review / approved / rejected / revoked)
- reviewed_by (UUID, FK to users.id)
- review_comments
- approved_at
- expires_at
- created_at

### 认证记录表

certifications
- id (UUID, PK)
- request_id (FK to certification_requests.id)
- entity_type (enterprise / individual / product)
- entity_id (UUID)
- certification_level (L1 / L2 / L3 / L4)
- certification_type
- certificate_number (UNIQUE)
- issued_at
- expires_at
- status (active / expired / revoked)
- metadata (JSON)

### 地域定义

regions
- id (UUID, PK)
- name
- level (country / province / city / district)
- parent_id (UUID, FK to regions.id, nullable)
- region_code
- coordinates (JSON)
- status (active / deprecated)
- sort_order

### 地域GEO数据

region_geo_data
- id (UUID, PK)
- region_id (UUID, FK to regions.id)
- geo_index (DECIMAL)
- company_count (INT)
- certified_company_count (INT)
- certified_individual_count (INT)
- service_provider_count (INT)
- total_job_openings (INT)
- data_period
- calculated_at
- breakdown (JSON)

### 地域实体关联

region_entities
- id (UUID, PK)
- region_id (UUID, FK to regions.id)
- entity_id (UUID)
- entity_type (company / individual / service_provider)
- relationship_type (headquarter / branch / registered / active)
- verified (BOOLEAN)
- created_at
