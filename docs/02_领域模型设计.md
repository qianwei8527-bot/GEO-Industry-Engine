## 二、核心对象定义

### 2.1 Industry（行业）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | String | 行业名称 |
| code | String | 行业编码（MECE） |
| parent_id | UUID | 父级行业（支持多层嵌套） |
| level | Int | 层级深度（1/2/3...） |
| description | Text | 行业描述 |
| icon | URL | 行业图标 |
| geo_index | Decimal | 行业GEO综合指数 |
| status | Enum | active/deprecated |

**关系**：
- Industry → Sector (1:N)
- Industry → Company (1:N)
- Industry → Region (N:M，通过 region_entities)

**生命周期**：创建 → 活跃 → 分裂/合并 → 废弃

---

### 2.2 Sector（细分赛道）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| industry_id | UUID | FK → Industry |
| name | String | 赛道名称 |
| description | Text | 描述 |
| maturity | Enum | emerging/growth/mature/declining |
| company_count | Int | 赛道内企业数量 |
| avg_geo_score | Decimal | 平均GEO评分 |

**关系**：Sector → Company (1:N)，Sector → Industry (N:1)

---

### 2.3 Company（企业）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | String | 企业名称 |
| industry_id | UUID | FK → Industry |
| sector_ids | UUID[] | FK → Sector（可多赛道）|
| size | Enum | micro/small/medium/large |
| website | URL | 官网 |
| description | Text | 简介 |
| geo_score | Int | 当前GEO评分 |
| geo_score_history | JSON[] | 历史评分记录 |
| ai_visibility | JSON | AI可见度数据 |
| region_id | UUID | FK → Region |
| owner_id | UUID | FK → User |
| certification_level | Int | 当前认证等级 |
| subscription_tier | Enum | free/basic/pro/enterprise |
| is_verified | Bool | 是否已验证 |
| created_at | DateTime | |

**关系**：
- Company → Industry (N:1)
- Company → Sector (N:M)
- Company → Product (1:N)
- Company → Capability (N:M)
- Company → Region (N:1)
- Company → User (N:1 所有者)

**生命周期**：注册 → 资料完善 → GEO检测 → 优化 → 认证升级 → 持续监测

---

### 2.4 Product（产品/服务）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| company_id | UUID | FK → Company |
| name | String | 产品名称 |
| category | Enum | service/tool/data/knowledge/talent |
| description | Text | 描述 |
| price | Decimal | 价格 |
| geo_visibility | JSON | AI搜索中的产品可见度 |
| certification_level | Int | 产品认证等级 |

**生命周期**：上架 → 认证 → 交易 → 评价 → 迭代/下架

---

### 2.5 Capability（GEO能力标签）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| industry_id | UUID | FK → Industry |
| name | String | 能力名称 |
| category | Enum | 内容/技术/策略/数据 |
| level | Enum | basic/intermediate/advanced/expert |
| description | Text | 能力描述 |

**用途**：给企业和个人打标签，用于匹配服务商和机会

---

### 2.6 Visibility（AI可见度）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| company_id | UUID | FK → Company（可为空）|
| individual_id | UUID | FK → User（可为空）|
| platform | Enum | chatgpt/perplexity/gemini/copilot/其他 |
| mention_count | Int | 提及次数 |
| sentiment_score | Decimal | 情感分(-1~1)|
| context_snippet | Text | 上下文片段 |
| detected_at | DateTime | |

**时序数据**：每条可见度记录附带时间戳，用于生成历史线

---

### 2.7 GeoScore（GEO评分）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| entity_type | Enum | company/individual/product |
| entity_id | UUID | 关联实体ID |
| score | Int | 总分(0-100) |
| breakdown | JSON | 各维度细分评分 |
| confidence | Decimal | 置信度(0-1) |
| calculated_at | DateTime | |

**三线数据源**：历史评分记录 → 预测线(Prophet) → 实际线(实时数据)

### 2.13 AiModel（AI模型）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | String | 模型名称（ChatGPT/Gemini/Claude等）|
| provider | String | 提供商（OpenAI/Google/Anthropic等）|
| country | Enum | 所属国家/地区 |
| type | Enum | general_search/vertical_search/recommendation |
| access_type | Enum | GEO检测接入方式: official_api/web_only/third_party_api/unknown |
| release_date | Date | 发布日期 |
| api_available | Bool | 是否有公开API |
| search_enabled | Bool | 是否支持联网搜索 |
| last_updated | DateTime | 模型信息最后更新时间 |
| status | Enum | active/deprecated/beta |

**关系**：AiModel -> Industry (N:M 通过热度矩阵)，AiModel -> Company (N:M 通过查询结果)
