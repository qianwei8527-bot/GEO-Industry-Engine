# GEO竞争情报与增长实验模型

> 你和竞争对手比怎么样？你做的优化真的有效吗？

---

## 一、为什么需要竞争情报？

### 1.1 零和市场的底层逻辑

AI推荐是有限席位游戏。每个查询只推荐5-8家企业。你的品牌被提及，竞争对手就少一个露出的机会。

没有竞争情报，企业无法判断：
- 我在这条查询上处于什么位置？
- 谁是我的主要AI搜索竞争对手？
- 我在哪些模型上落后了？
- 竞争对手做了什么改变让排名上升了？

现有AIBrandRanking给出排名数字，但缺少**多企业多模型的对比分析**。

### 1.2 增长实验的底层逻辑

没有实验框架，GEO优化就是"猜"：

- 优化了内容，排名变化了吗？
- 排名变化是因为我的优化，还是其他原因？
- 这次优化学到的经验怎么应用到下次？

需要建立：假设 → 执行 → 测量 → 学习的完整实验闭环。

## 二、竞争矩阵模型

### 2.1 多企业多模型对比

核心数据产品：竞争矩阵

```
             ChatGPT  Gemini  DeepSeek  综合
比亚迪          90      85      95      90
宁德时代        88      82      90      87
小鹏汽车        70      80      75      75
行业平均        75      72      78      75
差距(比亚迪vs平均)+15     +13     +17     +15
```

### 2.2 可见度差距分析

| 分析维度 | 说明 |
|---------|------|
| 综合排名 | 跨模型的综合得分排序 |
| 模型差距 | 同一企业在不同模型的评分差异（发现短板模型）|
| 竞争对手差距 | 与主要竞争对手在各模型的对比 |
| 行业基准 | 与行业平均水平的偏离 |
| 趋势变化 | 排名变化的加速度 |

### 2.3 竞争情报数据源

| 数据源 | 频次 | 用途 |
|--------|------|------|
| Prompt回答库 | 每天 | 提取各企业被提及的频率 |
| 模型API查询 | 每天 | 最新推荐结果 |
| 品牌排名 | 每天 | 综合得分更新 |

## 三、增长实验闭环模型

### 3.1 实验闭环

```
[1] 发现问题
    ├── GEO评分下降
    ├── 竞争对手排名上升
    └── 新机会出现
        ↓
[2] 提出假设
    ├── "如果我们优化A内容，ChatGPT推荐率会提升"
    └── 定义实验变量和成功指标
        ↓
[3] 执行优化
    ├── 内容修改/Schema标记/来源建设
    └── 记录变更前后的基线数据
        ↓
[4] 重新扫描
    ├── 向AI重新发送查询
    └── 收集变更后的推荐数据
        ↓
[5] 效果评估
    ├── 推荐率变化统计
    ├── 置信度分析
    └── 是否达到预期
        ↓
[6] 学习沉淀
    ├── 成功经验写入知识库
    ├── 失败原因记录
    └── 建议下一步实验
        ↓
回到[1]
```

### 3.2 实验类型

| 实验类型 | 说明 | 典型周期 |
|---------|------|---------|
| 内容优化 | 修改特定内容后测量AI引用变化 | 1-4周 |
| 来源建设 | 增加权威来源后测量信任评分变化 | 2-8周 |
| Schema标记 | 添加结构化数据后测量实体清晰度变化 | 1-2周 |
| 多维组合 | 同时执行多个措施的组合实验 | 4-12周 |

### 3.3 实验结果评估

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| 推荐率变化 | 实验后 - 实验前 | 正向变化表示优化有效 |
| 置信度 | 统计显著性 | 样本量越大置信度越高 |
| 单次实验ROI | 效果变化 / 投入成本 | 指导资源分配 |
| 学习价值 | 实验结论可迁移性 | 能否应用到其他场景 |

## 四、领域对象设计

### 4.1 CompetitionSnapshot（竞争快照）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| industry_id | UUID | FK -> Industry |
| query_text | Text | 查询问题 |
| snapshot_date | Date | 快照日期 |
| rankings | JSON | 多企业在各模型的排名数据 |

### 4.2 VisibilityGap（可见度差距）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| company_id | UUID | FK -> Company |
| competitor_id | UUID | FK -> Company |
| model_id | UUID | FK -> AiModel |
| gap_score | Decimal | 差距分(-100~100) |
| gap_analysis | JSON | 差距原因分析 |

### 4.3 GEOExperiment（GEO实验）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| company_id | UUID | FK -> Company |
| experiment_type | Enum | content_optimization/source_building/schema/multi |
| hypothesis | Text | 实验假设 |
| baseline_data | JSON | 实验前基线数据 |
| status | Enum | active/completed/failed |
| started_at | DateTime | 开始时间 |
| completed_at | DateTime | 结束时间 |

### 4.4 ExperimentResult（实验结果）

| 属性 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| experiment_id | UUID | FK -> GEOExperiment |
| recommendation_rate_change | Decimal | 推荐率变化 |
| trust_score_change | Decimal | 信任评分变化 |
| confidence | Decimal | 置信度 |
| roi | Decimal | ROI估值 |
| learnings | Text | 经验总结 |
