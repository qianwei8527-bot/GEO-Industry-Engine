# GEO-Industry-Engine 竞争情报与增长实验模型

> 状态：架构设计 | 版本：v2.0 | 日期：2026-07-28

## 一、产业情报系统定位

产业情报系统是共享能力层，不属于独立产品入口。它为检测中心(第三层风险预警+第二层机会发现)、产业导航(趋势变化)、认证中心(竞品认证等级变化)提供数据支撑。

情报三方向: 竞争情报、机会情报、风险情报

---

## 二、竞争情报

### 2.1 竞品追踪维度

| 维度 | 数据源 | 更新频率 |
|------|--------|:------:|
| AI可见度变化 | Decision Engine 定期重算 | 24h |
| 内容产出节奏 | 外部爬取 + 手动输入 | 每周 |
| 认证等级变化 | Certification系统 | 实时 |
| 事件动态 | Event管道 | 实时 |
| 人才流动 | 招聘网站 + 公开信息 | 每月 |
| 融资/合作 | 新闻爬取 | 实时 |

### 2.2 竞争位置分析

```
竞争矩阵:
         AI可见度 ->
  高     | 领先者(守)  | 挑战者(追)
  认证  |-------------|-------------
  等级  | 沉睡者(唤醒)| 观望者(进入)
  低    |
```

### 2.3 预警触发

| 预警 | 条件 | 等级 |
|------|------|:--:|
| 竞品超车 | 竞品AI可见度30天增幅 > 20% 且 自身 < 5% | 红色 |
| 新进入者 | 同行业新增认证企业 > 5家/月 | 黄色 |
| 认证降级 | 自身认证到期未续 | 橙色 |

## 三、机会情报

### 3.1 机会发现来源

| 来源 | 检测方式 | 置信度 |
|------|---------|:----:|
| 关键词空白 | 行业高频搜索词 x 内容覆盖度 | 高 |
| 能力缺口 | 行业需求图谱 x 服务商能力 | 高 |
| 新兴赛道 | Event管道分析 x 增长趋势 | 中 |
| 政策红利 | 政策事件 x 行业匹配 | 中 |
| 合作关系 | 关系图谱 x 互补能力 | 中 |

### 3.2 机会评级

S级(>85): 高增长+低竞争+高匹配 -> 立即行动
A级(70-85): 中增长+低竞争+高匹配 -> 季度规划
B级(50-70): 中增长+中竞争 -> 持续跟踪
C级(30-50): 低增长/高竞争 -> 观察

## 四、风险情报

### 4.1 风险雷达

| 风险类型 | 监控指标 | 数据源 |
|---------|---------|--------|
| 技术风险 | 新技术出现/技术路线变化 | 行业Event + 论文 |
| 竞争风险 | 竞品AI可见度变化/新进入者 | 追踪系统 |
| 政策风险 | 监管变化/行业规范 | 政策爬取 |
| 市场风险 | 需求变化/行业萎缩 | 搜索趋势 |
| 自身风险 | GEO Score下降/数据过期 | Decision Engine |

### 4.2 风险矩阵

```
影响程度
  高 | 密切关注(黄)  | 紧急响应(红)
     |---------------|-------------
  低 | 记录观察(绿)  | 定期检查(黄)
     |
      低            高 发生概率
```

## 五、增长实验框架

### 5.1 实验设计

基于GEO Score的可实验变量:
- 内容策略: 发布频率 x 内容类型
- 关系策略: 合作伙伴类型 x 合作深度
- 认证策略: 认证等级 x 领域

### 5.2 实验度量

| 指标 | 测量方式 |
|------|---------|
| AI可见度变化 | 对照组 vs 实验组 |
| 认证通过率 | 不同认证等级的审核通过率 |
| 关系增长 | 新增关系数量+质量 |
