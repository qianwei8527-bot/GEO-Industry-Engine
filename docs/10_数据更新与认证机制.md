# GEO产业引擎 - 数据更新与认证机制

> 自动更新技术方案、认证体系开放接入、产业地图数据模型深化

---

## 一、数据自动更新管道

### 1.1 数据源接入

| 数据源类型 | 接入方式 | 更新频率 | 优先级 |
|-----------|---------|---------|--------|
| AI搜索平台API | API轮询 | 实时-每小时 | P0 |
| 行业公开数据库 | 定时爬虫 | 每天 | P1 |
| 政策信息源 | RSS/API | 每天 | P1 |
| 用户提交数据 | 事件触发 | 实时 | P0 |
| 第三方数据合作 | 批量导入 | 每周 | P2 |

### 1.2 更新策略

| 策略 | 适用场景 |
|------|---------|
| 实时同步 | AI搜索提及、用户提交 |
| 增量更新 | GEO评分、企业数据 |
| 全量更新 | 行业分类、标准数据 |
| 事件驱动 | 社区贡献、认证状态 |

### 1.3 数据质量保证

- 接入层：格式校验、必填项检查
- 处理层：去重、关联验证、异常检测
- 存储层：数据血缘追踪、变更审计日志
- 输出层：质量评分、数据完整性报告

## 二、产业地图数据模型（深化）

### 2.1 节点数据结构

每个节点包含：基础信息(id、名称、类型)、定位(所属地图、层级、父级)、数据(GEO指数、活跃度)、时间(创建、更新、版本)、元数据(来源、置信度、审核状态)、交互(评论数、关注数)

### 2.2 关系数据结构

| 关系类型 | 示例 | 说明 |
|---------|------|------|
| 包含 | 行业 > 子行业 | 层级关系 |
| 关联 | 企业 > 服务商 | 业务关系 |
| 竞争 | 企业A vs 企业B | 竞争关系 |
| 供需 | 需求方 > 供给方 | 交易关系 |
| 协作 | 服务商 > 工具商 | 合作关系 |
| 地理 | 企业 > 地域 | 位置关系 |

## 三、评估体系技术机制

### 3.1 三维评分引擎

| 维度 | 计分方式 | 更新频率 | 存储方案 |
|------|---------|---------|---------|
| 能力分 | 考核成绩x0.3 + 案例评分x0.35 + 学习x0.15 + 行业认知x0.2 | 考核触发 | PostgreSQL + Redis缓存 |
| 信用分 | 履约率x0.4 + 内容真实性x0.25 + 行为x0.2 + 验证x0.15 | 事件触发 | PostgreSQL + 历史表 |
| 贡献分 | 问答x0.25 + 数据x0.2 + 内容x0.2 + 评审x0.2 + 活动x0.15 | 每日汇总 | PostgreSQL + 定时任务 |

### 3.2 投票权重计算引擎

`python
# 伪代码逻辑
def calculate_vote_weight(user):
    base_weight = 1.0
    trust_factor = user.trust_score / 100.0  # 信用因子 0-1
    level_bonus = {0:0, 1:0.2, 2:0.5, 3:1.0, 4:2.0}[user.level]
    return base_weight * trust_factor * (1 + level_bonus)
`

### 3.3 审核分布式系统

| 组件 | 技术选型 | 功能 |
|------|---------|------|
| 审核队列 | Redis Queue | 按审核员负载分发任务 |
| AI初审服务 | FastAPI + ML模型 | 自动材料审核 |
| 人工审核台 | WebSocket实时推送 | 审核员接单+审核 |
| 公示系统 | PostgreSQL + 定时任务 | 到期自动生效 |
| 申诉系统 | 事件驱动 | 升级审核+通知 |

### 3.4 防作弊算法

| 检测项 | 算法 | 数据源 |
|--------|------|--------|
| 刷分检测 | 频率统计+IP聚类+设备指纹 | 行为日志 |
| 小号识别 | 社交图谱分析(SNA) | 关系数据库 |
| 刷票检测 | 时间序列异常检测 | 投票日志 |
| 虚假资料 | NLP+知识图谱交叉验证 | 用户资料+外部数据 |

### 3.5 审计链

所有认证操作记录不可篡改：
- 每次审核产生审核日志(审核员ID、时间、结果、理由)
- 所有评分变化记录历史版本
- 公示期社区反馈全部存档
- 审核员行为可回溯审计

## 四、监控数据管道

### 4.1 实时监控架构

数据采集 -> 流处理 -> 指标计算 -> 阈值判定 -> 告警触发 -> 建议生成

### 4.2 告警与通知

| 级别 | 触发条件 | 通知方式 |
|------|---------|---------|
| 信息 | 节点新增、轻微变化 | 站内通知 |
| 提示 | GEO指数显著变化 | 站内+邮件 |
| 警告 | 活跃度骤降、竞争加剧 | 站内+邮件+推送 |
| 严重 | 产业节点消失、数据异常 | 全渠道 |

### 4.3 报告生成

| 报告类型 | 周期 | 内容 |
|---------|------|------|
| 个人周报 | 每周 | 关注的节点变化汇总 |
| 行业月报 | 每月 | GEO指数趋势、新节点 |
| 企业季报 | 每季 | GEO评分变化、竞争分析 |
| 平台年报 | 每年 | 产业生态全景回顾 |
