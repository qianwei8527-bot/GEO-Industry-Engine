恒域世界 V10.6 后端基础设施设计

三个技术底座承载真实数据、运行和安全；四原语只是可配置执行层，不是业务真相源。

数据、事件与平台底座

组件职责
PostgreSQL主数据存储：Realm、Project、Evidence、Capability、World State。
对象存储文件、附件、原始资料。
搜索 / 向量 / 知识图谱检索、语义、实体关系。
缓存 / Queue / Scheduler性能、异步任务、定时任务。
Event Backbone / Notification事件流、提醒、通知。
Snapshot / 备份恢复World State 快照、数据回滚。

Agent 与工作流运行底座

组件职责
Agent Runtime执行 Agent，记录输入、输出、版本、引用、成本。
Workflow Runtime执行 Workflow 步骤、条件和人工确认点。
Tool Execution工具调用、重试、幂等、降级。
Memory / Citation上下文、引用和证据链。
Sandbox / Budget / Approval权限沙箱、成本上限、人工审批。
Observability日志、指标、可观测性。

外部连接与安全底座

组件职责
MCP / Adapter / API连接外部平台、工具和数据源。
Webhook / Callback异步回调和事件。
Credential / Secret密钥只存后端，不进前端。
Rate Limit / SSRF 防护限流和请求安全。
数据出境与权限策略数据跨域、跨机构受控。
外部连接审计每次连接和调用留痕。

四原语运行时原则

Agent可配置角色、工具、模型、预算、权限；执行记录完整。
Skills可配置技能包、版本、来源、授权；失败和复盘保留。
Workflows可配置步骤、条件、人工确认点；版本化。
MCP可配置连接、工具、资源、密钥策略；只作连接层。
目录 → 配置 → 授权 → 运行 → 记录 → 复盘 → 资产

统一执行与审计流

用户操作 → Feature Flag → 权限 → 页面 → 模块 → 中台 API → 四原语运行 → 底座持久化与审计 → 外部 Provider/数据/服务
环节必须记录
输入用户、Realm、项目、授权范围
执行Agent / Workflow / Tool / MCP 调用
输出结果、版本、引用、成本
可信truth scope：verified / observed / inferred / unknown / simulation
安全密钥脱敏、限流、SSRF、数据出境
审计Event Backbone / AuditLog，可回滚
