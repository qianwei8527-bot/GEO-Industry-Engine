# GEO-Industry-Engine 风险分级流程

> 版本：v1.0 | 2026-08-01
> 原则：按任务风险选择通道，不统一走重流程。

---

## 四条通道

| 通道 | 适用任务 | 流程 | 审批 |
|------|---------|------|------|
| L0 快速修复 | 拼写、编码、lint、小bug | 检查 → 修改 → 定向测试 → 摘要 | 无 |
| L1 普通功能 | 不改变领域模型 | 需求门 → 复用检查 → 实现 → 测试 | 无（CTO 抽查） |
| L2 架构变更 | 表、实体、权限、公共API、评分语义 | PM证据 → CTO → ADR → 实现 → 完整验证 | CTO |
| L3 战略决策 | 定位、新节点、新行业、重大路线 | 只研究并提出方案 | 用户决策 |

---

## 选择规则

1. 先判断是否改变领域模型 / 公共 API / 权限 / 评分语义。
2. 改变 → L2；只影响单点实现 → L1 或 L0。
3. 涉及产品定位、新节点、新行业 → L3，不直接编码。
4. 拿不准时按高一档通道执行，而不是按低一档。

---

## 各通道输出

| 通道 | 输出 |
|------|------|
| L0 | 变更摘要（改了哪、测试结果） |
| L1 | 需求门 + 复用报告 + 变更摘要 |
| L2 | PM 证据单 + CTO 审查 + ADR + 完整验证 |
| L3 | 研究方案（问题、证据、选项、建议），不写业务代码 |
