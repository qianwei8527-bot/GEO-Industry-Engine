# GEO-Industry-Engine 文档规则

> 所有文档创建和更新必须遵守的规则。

---

## 一、文档体系

```
docs/                  # 产品和技术文档
  ##_XXX.md           # 编号文档

.codex/
  AGENTS.md           # 开发 Agent 配置
  REFERENCES.md       # 文档-代码映射
  agents/             # Agent 角色定义
  workflows/          # 开发工作流
  rules/              # 开发规则
```

---

## 二、文档同步原则

**核心规则：代码变更必须在同一 Sprint 内同步到文档。**

### 文档-代码映射

| 代码变更 | 必须同步的文档 |
|---------|--------------|
| 新增/修改数据模型 | 02_领域模型设计.md, .codex/REFERENCES.md |
| 新增/修改 API | 08_API接口规范.md, .codex/REFERENCES.md |
| 新增/修改前端页面 | 06_前端设计.md |
| 架构变更 | 相关架构文档, 索引.md |
| 新增模块 | .codex/REFERENCES.md, 索引.md |

---

## 三、文档格式规范

- 使用 UTF-8 编码
- Markdown 格式
- 每个文档必须有文件头（状态、版本、日期）
- 引用其他文档使用相对路径
- 禁止直接复制代码到文档（使用代码引用）

---

## 四、文档质量要求

| 检查项 | 标准 |
|--------|------|
| 完整性 | 覆盖所有核心功能和模块 |
| 准确性 | 与代码实现一致，无过时信息 |
| 可读性 | 结构清晰，中英文一致 |
| 可维护 | 模块化文档，便于增量更新 |

---

## 五、文档版本管理

- 文档更新不需要单独版本号
- 但与代码关联的文档必须在代码变更时同步
- 架构冻结文档（35_CTO架构冻结.md）有独立版本管理
